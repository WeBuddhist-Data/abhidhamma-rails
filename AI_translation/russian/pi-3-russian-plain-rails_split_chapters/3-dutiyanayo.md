### Второй метод ^3-3-0

#### Разъяснение того, что исключено, по отношению к включённому ^3-3-1-0

Из скольких совокупностей, сфер восприятия и элементов исключены явления, которые включены вместе со сферой глаза… явления, которые включены вместе со сферой осязаемого… явления, которые включены вместе с элементом глаза… явления, которые включены вместе с элементом осязаемого по совокупностям, но не включены вместе с ним по сферам восприятия и по элементам? Эти явления исключены из четырёх совокупностей, двух сфер восприятия и восьми элементов. ^3-171

Явления, которые включены вместе с элементом зрительного сознания… явления, которые включены вместе с элементом слухового сознания… явления, которые включены вместе с элементом обонятельного сознания… явления, которые включены вместе с элементом вкусового сознания… явления, которые включены вместе с элементом осязательного сознания… явления, которые включены вместе с элементом ума… явления, которые включены вместе с элементом умственного сознания по совокупностям, но не включены вместе с ним по сферам восприятия и по элементам… эти явления исключены из четырёх совокупностей, одиннадцати сфер восприятия и двенадцати элементов. ^3-172

Явления, которые включены вместе со способностью зрения… явления, которые включены вместе со способностью слуха… явления, которые включены вместе со способностью обоняния… явления, которые включены вместе со способностью вкуса… явления, которые включены вместе со способностью осязания… явления, которые включены вместе со способностью женственности… явления, которые включены вместе со способностью мужественности по совокупностям, но не включены вместе с ней по сферам восприятия и по элементам… эти явления исключены из четырёх совокупностей, двух сфер восприятия и восьми элементов. ^3-173

Явления, которые включены вместе с существованием без восприятия… явления, которые включены вместе с существованием с одной составляющей по совокупностям, но не включены вместе с ним по сферам восприятия и по элементам… эти явления исключены из четырёх совокупностей, трёх сфер восприятия и девяти элементов. ^3-174

Явления, которые включены вместе со стенанием… явления, которые включены вместе с видимыми и способными к соударению явлениями по совокупностям, но не включены вместе с ними по сферам восприятия и по элементам… эти явления исключены из четырёх совокупностей, двух сфер восприятия и восьми элементов. ^3-175

Явления, которые включены вместе с невидимыми, но способными к соударению явлениями по совокупностям, но не включены вместе с ними по сферам восприятия и по элементам… эти явления исключены из четырёх совокупностей, десяти сфер восприятия и шестнадцати элементов. ^3-176

Явления, которые включены вместе с видимыми явлениями по совокупностям, но не включены вместе с ними по сферам восприятия и по элементам… эти явления исключены из четырёх совокупностей, двух сфер восприятия и восьми элементов. ^3-177

Из скольких совокупностей, сфер восприятия и элементов исключены явления, которые включены вместе с явлениями, способными к соударению… явления, которые включены вместе с производными явлениями по совокупностям, но не включены вместе с ними по сферам восприятия и по элементам? Эти явления исключены из четырёх совокупностей, одиннадцати сфер восприятия и семнадцати элементов.
Десять сфер восприятия, семнадцать элементов,
семь способностей, существование без восприятия, существование с одной составляющей;
стенание, видимое и способное к соударению,
невидимое, снова [вариант написания: punareva (Pī.)] способное к соударению и производное.
