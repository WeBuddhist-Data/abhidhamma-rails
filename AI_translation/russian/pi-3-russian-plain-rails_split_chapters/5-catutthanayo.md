### Четвёртый метод ^3-5-0

#### Разъяснение того, что включено, по отношению к включённому ^3-5-1-0

Явления, которые вместе с истиной о происхождении страдания… явления, которые вместе с истиной о пути включены по совокупностям, включены по сферам восприятия и включены по элементам; во сколько совокупностей, сфер восприятия и элементов включены явления, которые вместе с этими явлениями включены по совокупностям, включены по сферам восприятия и включены по элементам? Эти явления включены в одну совокупность, одну сферу восприятия и один элемент. ^3-191

Явления, которые вместе со способностью женственности… явления, которые вместе со способностью мужественности… явления, которые вместе со способностью удовольствия… явления, которые вместе со способностью боли… явления, которые вместе со способностью радости… явления, которые вместе со способностью уныния… явления, которые вместе со способностью невозмутимости… явления, которые вместе со способностью веры… явления, которые вместе со способностью усердия… явления, которые вместе со способностью осознанности… явления, которые вместе со способностью сосредоточения… явления, которые вместе со способностью мудрости… явления, которые вместе со способностью «я познаю непознанное»… явления, которые вместе со способностью высшего знания… явления, которые вместе со способностью того, кто обрёл высшее знание….
Явления, которые вместе с неведением… явления, которые вместе с формациями, обусловленными неведением… явления, которые вместе с контактом, обусловленным шестью сферами восприятия… явления, которые вместе с жаждой, обусловленной чувством… явления, которые вместе с цеплянием, обусловленным жаждой… явления, которые вместе с существованием как действием… явления, которые вместе с печалью… явления, которые вместе со стенанием… явления, которые вместе с болью… явления, которые вместе с унынием… явления, которые вместе с отчаянием….
Явления, которые вместе с основой осознанности… явления, которые вместе с правильным усилием… явления, которые вместе с безмерным состоянием… явления, которые вместе с пятью способностями… явления, которые вместе с пятью силами… явления, которые вместе с семью факторами пробуждения… явления, которые вместе с благородным восьмеричным путём… явления, которые вместе с контактом… явления, которые вместе с намерением… явления, которые вместе с решимостью… явления, которые вместе с вниманием….
Явления, которые вместе с явлениями-корнями… явления, которые вместе с явлениями, являющимися корнями и имеющими корни… явления, которые вместе с явлениями, являющимися корнями и связанными с корнями… влечениями… оковами… узами… потоками… ярмами… помехами… искажениями… цепляниями… явления, которые вместе с явлениями-омрачениями… явления, которые вместе с явлениями, являющимися омрачениями и подверженными омрачению… явления, которые вместе с явлениями, являющимися омрачениями и омрачёнными… явления, которые вместе с явлениями, являющимися омрачениями и связанными с омрачениями, включены по совокупностям, включены по сферам восприятия и включены по элементам; во сколько совокупностей, сфер восприятия и элементов включены явления, которые вместе с этими явлениями включены по совокупностям, включены по сферам восприятия и включены по элементам? Эти явления включены в одну совокупность, одну сферу восприятия и один элемент.
Две истины, пятнадцать способностей, одиннадцать пунктов взаимозависимого возникновения;
выше снова одиннадцать, а пунктов из групп здесь тридцать видов [вариант написания: tiṃsavidhanti (Pī.)].
