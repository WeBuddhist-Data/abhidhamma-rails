### Седьмой метод ^3-8-0

#### Разъяснение того, что не связано, по отношению к связанному ^3-8-1-0

Явления, которые связаны с совокупностью чувства… явления, которые связаны с совокупностью восприятия… явления, которые связаны с совокупностью умственных формаций… явления, которые связаны с совокупностью сознания… явления, которые связаны со сферой ума; явления, которые не связаны с этими явлениями, — со сколькими совокупностями, сферами восприятия и элементами эти явления не связаны? Эти явления не связаны с четырьмя совокупностями, одной сферой восприятия и семью элементами; частично не связаны с одной сферой восприятия и одним элементом. ^3-306

Явления, которые связаны с элементом зрительного сознания… явления, которые связаны с элементом ума… явления, которые связаны с элементом умственного сознания; явления, которые не связаны с этими явлениями… эти явления ни с одной совокупностью и ни с одной сферой восприятия не являются несвязанными; не связаны с одним элементом. ^3-307

Явления, которые связаны со способностью ума; явления, которые не связаны с этими явлениями… эти явления не связаны с четырьмя совокупностями, одной сферой восприятия и семью элементами; частично не связаны с одной сферой восприятия и одним элементом. ^3-308

Явления, которые связаны со способностью невозмутимости; явления, которые не связаны с этими явлениями… эти явления ни с одной совокупностью и ни с одной сферой восприятия не являются несвязанными; не связаны с пятью элементами. ^3-309

Явления, которые связаны с сознанием, обусловленным формациями… явления, которые связаны с контактом, обусловленным шестью сферами восприятия… явления, которые связаны с чувством, обусловленным контактом… явления, которые связаны с контактом… явления, которые связаны с чувством… явления, которые связаны с восприятием… явления, которые связаны с намерением… явления, которые связаны с умом… явления, которые связаны с вниманием; явления, которые не связаны с этими явлениями… эти явления не связаны с четырьмя совокупностями, одной сферой восприятия и семью элементами; частично не связаны с одной сферой восприятия и одним элементом. ^3-310

Явления, которые связаны с решимостью; явления, которые не связаны с этими явлениями… эти явления ни с одной совокупностью и ни с одной сферой восприятия не являются несвязанными; не связаны с одним элементом. ^3-311

Явления, которые связаны с явлениями, связанными с чувством ни болезненным, ни приятным… явления, которые связаны с явлениями, сопровождаемыми невозмутимостью; явления, которые не связаны с этими явлениями… эти явления ни с одной совокупностью и ни с одной сферой восприятия не являются несвязанными; не связаны с пятью элементами. ^3-312

Явления, которые связаны с явлениями с направленной мыслью и обдумыванием; явления, которые не связаны с этими явлениями… эти явления ни с одной совокупностью и ни с одной сферой восприятия не являются несвязанными; не связаны с одним элементом. ^3-313

Явления, которые связаны с явлениями, являющимися умом… явления, которые связаны с сопутствующими уму явлениями… явления, которые связаны с явлениями, связанными с умом… явления, которые связаны с явлениями, соединёнными с умом… явления, которые связаны с явлениями, соединёнными с умом и порождёнными им… явления, которые связаны с явлениями, соединёнными с умом, порождёнными им и сосуществующими с ним… явления, которые связаны с явлениями, соединёнными с умом, порождёнными им и следующими за ним; явления, которые не связаны с этими явлениями… эти явления не связаны с четырьмя совокупностями, одной сферой восприятия и семью элементами; частично не связаны с одной сферой восприятия и одним элементом. ^3-314

Явления, которые связаны с явлениями с направленной мыслью… явления, которые связаны с явлениями с обдумыванием; явления, которые не связаны с этими явлениями… эти явления ни с одной совокупностью и ни с одной сферой восприятия не являются несвязанными; не связаны с одним элементом. ^3-315

Явления, которые связаны с явлениями, сопровождаемыми невозмутимостью; явления, которые не связаны с этими явлениями, — со сколькими совокупностями, сферами восприятия и элементами эти явления не связаны? Эти явления ни с одной совокупностью и ни с одной сферой восприятия не являются несвязанными; не связаны с пятью элементами.
Четыре совокупности и одна сфера восприятия;
среди элементов — семь, и ещё две — из способностей;
три — из взаимозависимого возникновения, а также пятёрка во главе с контактом;
решимость и внимание; в тройках — три;
семь — из промежуточных, и две, связанные с умом;
направленная мысль, обдумывание, а также сопровождаемое невозмутимостью.
Конец седьмого раздела — разъяснения того, что не связано, по отношению к связанному. ^3-316
