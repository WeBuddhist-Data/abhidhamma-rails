### Одиннадцатый метод ^3-12-0

#### Разъяснение того, что связано и что не связано, по отношению к включённому ^3-12-1-0

Явления, которые вместе с истиной о происхождении страдания… явления, которые вместе с истиной о пути включены по совокупностям, включены по сферам восприятия и включены по элементам, — со сколькими совокупностями, сферами восприятия и элементами эти явления связаны? Эти явления связаны с тремя совокупностями, одной сферой восприятия и семью элементами; частично связаны с одной совокупностью, одной сферой восприятия и одним элементом. Со сколькими не связаны? Не связаны с одной совокупностью, десятью сферами восприятия и десятью элементами; частично не связаны с одной сферой восприятия и одним элементом. ^3-409

Явления, которые вместе со способностью женственности… явления, которые вместе со способностью мужественности включены по совокупностям, включены по сферам восприятия и включены по элементам, — со сколькими совокупностями, сферами восприятия и элементами эти явления связаны? Ни с какими. Со сколькими не связаны? Не связаны с четырьмя совокупностями, одной сферой восприятия и семью элементами; частично не связаны с одной сферой восприятия и одним элементом. ^3-410

Со сколькими не связаны? Не связаны с одной совокупностью, десятью сферами восприятия и десятью элементами; частично не связаны с одной сферой восприятия и одним элементом. ^3-411

Явления, которые вместе со способностью невозмутимости включены по совокупностям, включены по сферам восприятия и включены по элементам… эти явления связаны с тремя совокупностями, одной сферой восприятия и двумя элементами; частично связаны с одной сферой восприятия и одним элементом. Со сколькими не связаны? Не связаны с одной совокупностью, десятью сферами восприятия и пятнадцатью элементами; частично не связаны с одной сферой восприятия и одним элементом. ^3-412

Явления, которые вместе со способностью веры… явления, которые вместе со способностью усердия… явления, которые вместе со способностью осознанности… явления, которые вместе со способностью сосредоточения… явления, которые вместе со способностью мудрости… явления, которые вместе со способностью «я познаю непознанное»… явления, которые вместе со способностью высшего знания… явления, которые вместе со способностью того, кто обрёл высшее знание… явления, которые вместе с неведением… явления, которые вместе с формациями, обусловленными неведением… явления, которые вместе с контактом, обусловленным шестью сферами восприятия… явления, которые вместе с жаждой, обусловленной чувством… явления, которые вместе с цеплянием, обусловленным жаждой… явления, которые вместе с существованием как действием включены по совокупностям, включены по сферам восприятия и включены по элементам; эти явления связаны с тремя совокупностями, одной сферой восприятия и семью элементами; частично связаны с одной совокупностью, одной сферой восприятия и одним элементом. Со сколькими не связаны? Не связаны с одной совокупностью, десятью сферами восприятия и десятью элементами; частично не связаны с одной сферой восприятия и одним элементом. ^3-413

Явления, которые вместе с отчаянием… явления, которые вместе с основой осознанности… явления, которые вместе с правильным усилием… явления, которые вместе с безмерным состоянием… явления, которые вместе с пятью способностями… явления, которые вместе с пятью силами… явления, которые вместе с семью факторами пробуждения… явления, которые вместе с благородным восьмеричным путём… явления, которые вместе с контактом… явления, которые вместе с намерением… явления, которые вместе с решимостью… явления, которые вместе с вниманием… явления, которые вместе с явлениями-корнями… явления, которые вместе с явлениями, являющимися корнями и имеющими корни… явления, которые вместе с явлениями, являющимися корнями и связанными с корнями… явления, которые вместе с явлениями-влечениями… явления, которые вместе с явлениями, являющимися влечениями и подверженными влечениям… явления, которые вместе с явлениями, являющимися влечениями и связанными с влечениями… явления, которые вместе с явлениями-оковами… явления, которые вместе с явлениями-узами… явления, которые вместе с явлениями-потоками… явления, которые вместе с явлениями-ярмами… явления, которые вместе с явлениями-помехами… явления, которые вместе с явлениями-искажениями… явления, которые вместе с явлениями-цепляниями… явления, которые вместе с явлениями-омрачениями… явления, которые вместе с явлениями, являющимися омрачениями и подверженными омрачению… явления, которые вместе с явлениями, являющимися омрачениями и омрачёнными… явления, которые вместе с явлениями, являющимися омрачениями и связанными с омрачениями, включены по совокупностям, включены по сферам восприятия и включены по элементам, — со сколькими совокупностями, сферами восприятия и элементами эти явления связаны? Две истины, пятнадцать способностей, одиннадцать пунктов взаимозависимого возникновения;
выше — ещё одиннадцать, а пунктов из групп здесь — тридцать видов.
