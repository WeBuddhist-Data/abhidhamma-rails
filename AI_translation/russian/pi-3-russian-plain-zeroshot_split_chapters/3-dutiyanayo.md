### Второй метод ^3-3-0

#### Разъяснение того, что исключено, по отношению к включённому ^3-3-1-0

Явления, которые вместе со сферой глаза… явления, которые вместе со сферой осязаемого… явления, которые вместе с элементом глаза… явления, которые вместе с элементом осязаемого включены по совокупностям, но исключены по сферам восприятия и исключены по элементам, — из скольких совокупностей, сфер восприятия и элементов эти явления исключены? Эти явления исключены из четырёх совокупностей, двух сфер восприятия и восьми элементов. ^3-171

Явления, которые вместе с элементом зрительного сознания… явления, которые вместе с элементом слухового сознания… явления, которые вместе с элементом обонятельного сознания… явления, которые вместе с элементом вкусового сознания… явления, которые вместе с элементом осязательного сознания… явления, которые вместе с элементом ума… явления, которые вместе с элементом умственного сознания включены по совокупностям, но исключены по сферам восприятия и исключены по элементам… эти явления исключены из четырёх совокупностей, одиннадцати сфер восприятия и двенадцати элементов. ^3-172

Явления, которые вместе со способностью зрения… явления, которые вместе со способностью слуха… явления, которые вместе со способностью обоняния… явления, которые вместе со способностью вкуса… явления, которые вместе со способностью осязания… явления, которые вместе со способностью женственности… явления, которые вместе со способностью мужественности включены по совокупностям, но исключены по сферам восприятия и исключены по элементам… эти явления исключены из четырёх совокупностей, двух сфер восприятия и восьми элементов. ^3-173

Явления, которые вместе с существованием без восприятия… явления, которые вместе с существованием с одной составляющей включены по совокупностям, но исключены по сферам восприятия и исключены по элементам… эти явления исключены из четырёх совокупностей, трёх сфер восприятия и девяти элементов. ^3-174

Явления, которые вместе со стенанием… явления, которые вместе с видимыми и способными к соударению явлениями включены по совокупностям, но исключены по сферам восприятия и исключены по элементам… эти явления исключены из четырёх совокупностей, двух сфер восприятия и восьми элементов. ^3-175

Явления, которые вместе с невидимыми, но способными к соударению явлениями включены по совокупностям, но исключены по сферам восприятия и исключены по элементам… эти явления исключены из четырёх совокупностей, десяти сфер восприятия и шестнадцати элементов. ^3-176

Явления, которые вместе с видимыми явлениями включены по совокупностям, но исключены по сферам восприятия и исключены по элементам… эти явления исключены из четырёх совокупностей, двух сфер восприятия и восьми элементов. ^3-177

Явления, которые вместе со способными к соударению явлениями… явления, которые вместе с производными явлениями включены по совокупностям, но исключены по сферам восприятия и исключены по элементам, — из скольких совокупностей, сфер восприятия и элементов эти явления исключены? Эти явления исключены из четырёх совокупностей, одиннадцати сфер восприятия и семнадцати элементов.
Десять сфер восприятия, семнадцать элементов,
семь способностей, существование без восприятия, существование с одной составляющей;
стенание, видимое и способное к соударению,
невидимое, и снова [вариант: punareva (Pī.)] способное к соударению, и производное.
Конец второго раздела — разъяснения того, что исключено, по отношению к включённому. ^3-178
