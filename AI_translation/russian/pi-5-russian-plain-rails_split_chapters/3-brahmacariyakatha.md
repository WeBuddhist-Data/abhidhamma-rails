### Обсуждение вопроса о духовной жизни ^5-3-0

#### Обсуждение вопроса о духовной жизни без уточнений ^5-3-1-0

Среди богов нет духовной жизни? Да. Все боги тупы, глухонемы [вариант написания (Syā.): eḷamūgā], несведущи, объясняются жестами, неспособны понять смысл хорошо сказанного и сказанного плохо, все боги не доверяют Будде, не доверяют Учению, не доверяют общине, не навещают Будду, Благословенного, не задают вопросов Будде, Благословенному, не радуются, когда Будда, Благословенный, отвечает на вопросы, все боги наделены препятствием каммы, наделены препятствием омрачений, наделены препятствием созревания плодов, лишены веры, не имеют желания, лишены мудрости, неспособны вступить в определённость правильности в благих явлениях, все боги убивают мать, убивают отца, убивают архатов, проливают кровь Будды, раскалывают общину, все боги убивают живых существ, берут не данное, ведут себя недолжно в чувственных желаниях, лгут, клевещут, говорят грубо, болтают пустое, алчны, имеют злонамеренный ум, придерживаются ложных воззрений? Так говорить не следует…
Но ведь есть боги, которые не тупы, не глухонемы, сведущи, не объясняются жестами, способны понять смысл хорошо сказанного и сказанного плохо, есть боги, которые доверяют Будде, доверяют Учению, доверяют общине, навещают Будду, Благословенного, задают вопросы Будде, Благословенному, радуются, когда Будда, Благословенный, отвечает на вопросы, есть боги, которые не наделены препятствием каммы, не наделены препятствием омрачений, не наделены препятствием созревания плодов, имеют веру, имеют желание, мудры, способны вступить в определённость правильности в благих явлениях, есть боги, которые не убивают мать, не убивают отца, не убивают архатов, не проливают кровь Будды, не раскалывают общину, есть боги, которые не убивают живых существ, не берут не данное, не ведут себя недолжно в чувственных желаниях, не лгут, не клевещут, не говорят грубо, не болтают пустое, не алчны, имеют не злонамеренный ум, придерживаются правильных воззрений? Да.
Если есть боги, которые не тупы, не глухонемы, сведущи, не объясняются жестами, способны понять смысл хорошо сказанного и сказанного плохо… есть боги, которые доверяют Будде… придерживаются правильных воззрений, то, конечно же, не следует говорить – «среди богов нет духовной жизни». ^5-269

Среди богов есть духовная жизнь? Да. Там есть посвящение в монахи, бритьё головы, ношение шафрановых одежд, ношение чаши для подаяний, среди богов появляются полностью пробуждённые будды, появляются будды-одиночки, появляется пара главных учеников? Так говорить не следует…
Раз среди богов нет посвящения в монахи, то среди богов нет духовной жизни? Да. Где есть посвящение в монахи, только там есть духовная жизнь, а где нет посвящения в монахи, там нет духовной жизни? Так говорить не следует… Где есть посвящение в монахи, только там есть духовная жизнь, а где нет посвящения в монахи, там нет духовной жизни? Да. Кто принимает посвящение в монахи, только у того есть духовная жизнь, а кто не принимает посвящения в монахи, у того нет духовной жизни? Так говорить не следует…
Раз среди богов нет бритья головы, то среди богов нет духовной жизни? Да. Где есть бритьё головы, только там есть духовная жизнь, а где нет бритья головы, там нет духовной жизни? Так говорить не следует… Где есть бритьё головы, только там есть духовная жизнь, а где нет бритья головы, там нет духовной жизни? Да. Кто обрит наголо, только у того есть духовная жизнь, а кто не обрит наголо, у того нет духовной жизни? Так говорить не следует…
Раз среди богов нет ношения шафрановых одежд, то среди богов нет духовной жизни? Да. Где есть ношение шафрановых одежд, только там есть духовная жизнь, а где нет ношения шафрановых одежд, там нет духовной жизни? Так говорить не следует… Где есть ношение шафрановых одежд, только там есть духовная жизнь, а где нет ношения шафрановых одежд, там нет духовной жизни? Да. Кто носит шафрановые одежды, только у того есть духовная жизнь, а кто не носит шафрановых одежд, у того нет духовной жизни? Так говорить не следует…
Раз среди богов нет ношения чаши для подаяний, то среди богов нет духовной жизни? Да. Где есть ношение чаши для подаяний, только там есть духовная жизнь, а где нет ношения чаши для подаяний, там нет духовной жизни? Так говорить не следует… Где есть ношение чаши для подаяний, только там есть духовная жизнь, а где нет ношения чаши для подаяний, там нет духовной жизни? Да. Кто носит чашу для подаяний, только у того есть духовная жизнь, а кто не носит чаши для подаяний, у того нет духовной жизни? Так говорить не следует…
Раз среди богов не появляются полностью пробуждённые будды, то среди богов нет духовной жизни? Да. Где появляются полностью пробуждённые будды, только там есть духовная жизнь, а где не появляются полностью пробуждённые будды, там нет духовной жизни? Так говорить не следует… Где появляются полностью пробуждённые будды, только там есть духовная жизнь, а где не появляются полностью пробуждённые будды, там нет духовной жизни? Да. Благословенный родился в Лумбини, достиг полного пробуждения у подножия дерева бодхи, в Варанаси Благословенный привёл в движение колесо Учения; только там есть духовная жизнь, а в других местах нет духовной жизни? Так говорить не следует…
Раз среди богов не появляются будды-одиночки, то среди богов нет духовной жизни? Да. Где появляются будды-одиночки, только там есть духовная жизнь, а где не появляются будды-одиночки, там нет духовной жизни? Так говорить не следует… Где появляются будды-одиночки, только там есть духовная жизнь, а где не появляются будды-одиночки, там нет духовной жизни? Да. Будды-одиночки появляются в срединных областях, только там есть духовная жизнь, а в других местах нет духовной жизни? Так говорить не следует…
Раз среди богов не появляется пара главных учеников, то среди богов нет духовной жизни? Да. Где появляется пара главных учеников, только там есть духовная жизнь, а где не появляется пара главных учеников, там нет духовной жизни? Так говорить не следует… Где появляется пара главных учеников, только там есть духовная жизнь, а где не появляется пара главных учеников, там нет духовной жизни? Да. Пара главных учеников появилась в Магадхе, только там есть духовная жизнь, а в других местах нет духовной жизни? Так говорить не следует… ^5-270

Среди богов есть духовная жизнь? Да. Среди всех богов есть духовная жизнь? Так говорить не следует…
Среди людей есть духовная жизнь? Да. Среди всех людей есть духовная жизнь? Так говорить не следует…
Среди богов есть духовная жизнь? Да. Среди богов без восприятия есть духовная жизнь? Так говорить не следует…
Среди людей есть духовная жизнь? Да. В пограничных областях, среди варваров [вариант написания (Syā., Ka.): milakkhūsu], среди невежественных, куда не ходят монахи, монахини, миряне и мирянки, есть духовная жизнь? Так говорить не следует.
Среди богов есть духовная жизнь? Где-то есть, а где-то нет. Среди богов без восприятия духовная жизнь где-то есть, а где-то нет, среди богов, наделённых восприятием [вариант чтения (Ka.): asaññasattesu], духовная жизнь где-то есть, а где-то нет? Так говорить не следует.
Среди богов духовная жизнь где-то есть, а где-то нет? Да. Где есть, а где нет? Среди богов без восприятия нет духовной жизни, среди богов, наделённых восприятием [вариант чтения (Ka.): asaññasattesu], есть духовная жизнь. Среди богов без восприятия нет духовной жизни? Да. Среди богов, наделённых восприятием [вариант чтения (Ka.): asaññasattesu], нет духовной жизни? Так говорить не следует.
Среди богов, наделённых восприятием, есть духовная жизнь? Да. Среди богов без восприятия есть духовная жизнь? Так говорить не следует.
Среди людей есть духовная жизнь? Где-то есть, а где-то нет. В пограничных областях, среди варваров, среди невежественных, куда не ходят монахи, монахини, миряне и мирянки, духовная жизнь где-то есть, а где-то нет, в срединных областях духовная жизнь где-то есть, а где-то нет? Так говорить не следует.
Среди людей духовная жизнь где-то есть, а где-то нет? Да. Где есть, а где нет? В пограничных областях, среди варваров, среди невежественных, куда не ходят монахи, монахини, миряне и мирянки, нет духовной жизни, в срединных областях есть духовная жизнь. В пограничных областях, среди варваров, среди невежественных, куда не ходят монахи, монахини, миряне и мирянки, нет духовной жизни? Да. В срединных областях нет духовной жизни? Так говорить не следует.
В срединных областях есть духовная жизнь? Да. В пограничных областях, среди варваров, среди невежественных, куда не ходят монахи, монахини, миряне и мирянки, есть духовная жизнь? Так говорить не следует.
Среди богов есть духовная жизнь? Да. Но ведь Благословенный сказал – «Монахи, в трёх отношениях люди Джамбудипы превосходят людей Уттаракуру и богов Тридцати трёх. В каких трёх? Они храбры, наделены осознанностью, и здесь есть духовная жизнь» [a. ni. 9.21]? Такое наставление действительно есть? Да. Значит, среди богов нет духовной жизни.
Благословенный сказал в Саваттхи – «здесь есть духовная жизнь»? Да. Только в Саваттхи есть духовная жизнь, а в других местах нет духовной жизни? Так говорить не следует. ^5-271

У невозвращающегося пять оков, привязывающих к низшим мирам, устранены, а пять оков, привязывающих к высшим мирам, не устранены; где у него, умершего здесь и родившегося там, возникает плод? Именно там. Если у невозвращающегося пять оков, привязывающих к низшим мирам, устранены, а пять оков, привязывающих к высшим мирам, не устранены и у него, умершего здесь и родившегося там, плод возникает там, то, конечно же, не следует говорить – «среди богов нет духовной жизни».
У невозвращающегося пять оков, привязывающих к низшим мирам, устранены, а пять оков, привязывающих к высшим мирам, не устранены; где у него, умершего здесь и родившегося там, происходит сбрасывание ноши, где полное понимание страдания, где устранение омрачений, где осуществление прекращения, где постижение непоколебимого? Именно там. Если у невозвращающегося пять оков, привязывающих к низшим мирам, устранены, а пять оков, привязывающих к высшим мирам, не устранены и у него, умершего здесь и родившегося там, постижение непоколебимого происходит там, то, конечно же, не следует говорить – «среди богов нет духовной жизни».
У невозвращающегося пять оков, привязывающих к низшим мирам, устранены, а пять оков, привязывающих к высшим мирам, не устранены, и у него, умершего здесь и родившегося там, там возникает плод, там происходит сбрасывание ноши, там полное понимание страдания, там устранение омрачений, там осуществление прекращения, там постижение непоколебимого; в каком смысле ты говоришь – «среди богов нет духовной жизни»? Дело в том, что невозвращающийся путём, развитым здесь, осуществляет плод там [вариант написания (во многих изданиях): sacchikaroti]. ^5-272

#### Обсуждение вопроса о духовной жизни: сопоставление ^5-3-2-0

Невозвращающийся путём, развитым здесь, осуществляет плод там? Да. Вошедший в поток путём, развитым там, осуществляет плод здесь? Так говорить не следует.
Невозвращающийся путём, развитым здесь, осуществляет плод там? Да. Однажды возвращающийся, достигающий окончательного угасания здесь [вариант написания (?): idhaparinibbāyī], путём, развитым там, осуществляет плод здесь? Так говорить не следует.
Вошедший в поток путём, развитым здесь, осуществляет плод здесь? Да. Невозвращающийся путём, развитым там, осуществляет плод там? Так говорить не следует.
Однажды возвращающийся, достигающий окончательного угасания здесь, путём, развитым здесь, осуществляет плод здесь? Да. Невозвращающийся путём, развитым там, осуществляет плод там? Так говорить не следует…
У того, кто достигает завершения, оставив этот мир, путь развивается, а омрачения не устраняются? Да. У того, кто идёт к осуществлению плода вступления в поток, путь развивается, а омрачения не устраняются? Так говорить не следует…
У того, кто достигает завершения, оставив этот мир, путь развивается, а омрачения не устраняются? Да. У того, кто идёт к осуществлению плода однократного возвращения… у того, кто идёт к осуществлению состояния архата, путь развивается, а омрачения не устраняются? Так говорить не следует…
У того, кто идёт к осуществлению плода вступления в поток, одновременно и путь развивается, и омрачения устраняются? Да. У того, кто достигает завершения, оставив этот мир, одновременно и путь развивается, и омрачения устраняются? Так говорить не следует.
У того, кто идёт к осуществлению плода однократного возвращения… у того, кто идёт к осуществлению состояния архата, одновременно и путь развивается, и омрачения устраняются? Да. У того, кто достигает завершения, оставив этот мир, одновременно и путь развивается, и омрачения устраняются? Так говорить не следует.
Невозвращающийся, сделавший то, что следовало сделать, и завершивший развитие, перерождается там? Да. Архат перерождается? Так говорить не следует.
Архат перерождается? Да. У архата есть новое рождение? Так говорить не следует.
У архата есть новое рождение? Да. Архат переходит из существования в существование, из удела перерождения в удел перерождения, из круговорота перерождений в круговорот перерождений, из перерождения в перерождение? Так говорить не следует.
Невозвращающийся, сделавший то, что следовало сделать, завершивший развитие, но не сбросивший ношу, перерождается там? Да. Он снова развивает путь, чтобы сбросить ношу? Так говорить не следует.
Невозвращающийся, сделавший то, что следовало сделать, завершивший развитие, не понявший полностью страдание, не устранивший омрачения, не осуществивший прекращение, не постигший непоколебимое, перерождается там? Да. Он снова развивает путь, чтобы постичь непоколебимое? Так говорить не следует.
Невозвращающийся, сделавший то, что следовало сделать, завершивший развитие, но не сбросивший ношу, перерождается там и не развивает путь снова, чтобы сбросить ношу? Да. И он, не сбросив ношу, там окончательно угасает? Так говорить не следует.
Невозвращающийся, сделавший то, что следовало сделать, завершивший развитие, не понявший полностью страдание, не устранивший омрачения, не осуществивший прекращение, не постигший непоколебимое, перерождается там и не развивает путь снова, чтобы постичь непоколебимое? Да. И он, не постигнув непоколебимое, там окончательно угасает? Так говорить не следует. Как олень, пронзённый стрелой, уйдя даже далеко, умирает, точно так же невозвращающийся путём, развитым здесь, осуществляет плод там.
Как олень, пронзённый стрелой, уйдя даже далеко, умирает со стрелой в теле, точно так же невозвращающийся путём, развитым здесь, там окончательно угасает со стрелой в теле? Так говорить не следует…

#### Обсуждение вопроса об устранении по частям ^5-3-3-0
