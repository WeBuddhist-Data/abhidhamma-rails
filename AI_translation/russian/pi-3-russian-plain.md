Явления, которые не связаны с явлениями с восторгом… явления, которые не связаны с явлениями, сопровождаемыми восторгом… явления, которые не связаны с явлениями, сопровождаемыми счастьем… эти явления, если при подсчёте совокупностей не учитывать несотворённое, включены в пять совокупностей, двенадцать сфер восприятия и восемнадцать элементов. Из скольких исключены? Ни из одной совокупности, ни из одной сферы восприятия и ни из одного элемента они не исключены. ^3-513

Явления, которые не связаны с явлениями, сопровождаемыми невозмутимостью… эти явления, если при подсчёте совокупностей не учитывать несотворённое, включены в пять совокупностей, двенадцать сфер восприятия и тринадцать элементов. Из скольких исключены? Ни из одной совокупности и ни из одной сферы восприятия они не исключены; исключены из пяти элементов. ^3-514

Явления, которые не связаны с явлениями, относящимися к миру чувственности… явления, которые не связаны с явлениями, принадлежащими к кругам существования… явления, которые не связаны с явлениями, над которыми есть высшее… эти явления включены в четыре совокупности, две сферы восприятия и два элемента. Из скольких исключены? Исключены из одной совокупности, десяти сфер восприятия и шестнадцати элементов. ^3-515

Явления, которые не связаны с явлениями, не относящимися к миру чувственности… явления, которые не связаны с явлениями, не принадлежащими к кругам существования… явления, которые не связаны с явлениями, над которыми нет высшего… эти явления включены в четыре совокупности, две сферы восприятия и восемь элементов. Из скольких исключены? Исключены из одной совокупности, десяти сфер восприятия и десяти элементов. ^3-516

Явления, которые не связаны с явлениями, относящимися к миру тонкой формы… явления, которые не связаны с явлениями, относящимися к миру без формы… явления, которые не связаны с явлениями, ведущими к освобождению… явления, которые не связаны с предопределёнными явлениями… явления, которые не связаны с явлениями, сопряжёнными с борьбой… эти явления, если при подсчёте совокупностей не учитывать несотворённое, включены в пять совокупностей, двенадцать сфер восприятия и восемнадцать элементов. Из скольких исключены? Ни из одной совокупности, ни из одной сферы восприятия и ни из одного элемента они не исключены. ^3-517

Во сколько совокупностей, сфер восприятия и элементов включены явления, которые не связаны с явлениями, не относящимися к миру тонкой формы… явления, которые не связаны с явлениями, не относящимися к миру без формы… явления, которые не связаны с явлениями, не ведущими к освобождению… явления, которые не связаны с непредопределёнными явлениями… явления, которые не связаны с явлениями, свободными от борьбы? Эти явления включены в четыре совокупности, две сферы восприятия и два элемента. Из скольких исключены? Исключены из одной совокупности, десяти сфер восприятия и шестнадцати элементов.
Сфера умственных объектов, элемент умственных объектов, затем жизненная способность, психическое и материальное;
шесть сфер восприятия, рождение, старение и смерть; и два пункта в тройках не применимы.
В первом промежуточном разделе семь, в группах десять, в последнем промежуточном
четырнадцать и шесть в завершающей части; итак, вот эти сорок семь явлений
не применимы в этом разборе, поскольку вопрос о них оказывается пустым.
Конец четырнадцатого раздела: разъяснение того, что включено и исключено, по отношению к не связанному.
