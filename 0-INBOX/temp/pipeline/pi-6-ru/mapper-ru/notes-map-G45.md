# notes-map-G45: dhātu + sacca keyword values (4-dhatuyamaka, 5-01 … 5-03-saccayamaka)

Script: map_G45_ru.py (importable, writes nothing; DHATU, SACCA, MOMENTS, NOTES_KW, PJ3_FRAME / pj3_value(), G45_TABLE, exceptions_for(part)). Frames imported, not retyped: map_G2_ru (G2_FRAME, frame_value, frame_exceptions; G2_KHANDHA not imported) and map_G8_ru (TENSE, TIME, PERSONS). Translation file is the truth; builders build_4_ru.py, build_5-0N_ru.py; notes-4.md, notes-5-0N.md. Every case form and the -ti / -nti / -ñca / -ñceva / -pi / -mpi forms take the value of the base keyword.

## Dhātuyamaka members
cakkhudhātu … dhammadhātu (and -dhātū / -dhātūti / -dhātuṃ / -dhātuñca) = элемент глаза / уха / носа / языка / тела / видимых форм / звуков / запахов / вкусов / осязаемого / зрительного сознания / слухового сознания / обонятельного сознания / вкусового сознания / осязательного сознания / ума / умственного сознания / объектов ума (pi-2 ^2-183)
dhātu / dhātūti / dhātuñca = элемент («является элементом»; dhātūti is the quoted singular)
dhātū / dhātuyo = элементы («Элементы являются …», «Восемнадцать элементов»)
cakkhu / cakkhuṃ / Cakkhuñca / cakkhūti = глаз; sotaṃ = ухо; ghānaṃ = нос; jivhā / Jivhāpi / jivha (^6-4-15 slip) = язык; kāyo / Kāyañca = тело
rūpaṃ / rūpanti / Rūpañca = форма (bare word «Форма является элементом?»; not материальная форма)
saddo / saddaṃ = звук; gandho / gandhaṃ = запах; raso / rasaṃ = вкус; phoṭṭhabbo / phoṭṭhabbaṃ = осязаемое
X-viññāṇaṃ = зрительное / слуховое / обонятельное / вкусовое / осязательное / умственное сознание; mano / Manañca = ум
Dibbacakkhu = божественный глаз; paññācakkhu = глаз мудрости; Dibbasotaṃ = божественное ухо; taṇhāsotaṃ = поток жажды
Sīlagandho / samādhigandho / paññāgandho = запах нравственности / сосредоточения / мудрости; Attharaso / dhammaraso / vimuttiraso = вкус смысла / Учения / освобождения
ghānasadiso = такой же как нос («Звук такой же, как нос»); ghānadhātusadisā = такой же как элемент носа
cakkaṃ = круг («круг следует замкнуть»); paṇṇatti = обозначения (text plural «Как обозначения …»)
dhātuyamakaṃ / -yamake / -yamakassa / -yamakepi / -yamakampi = парные вопросы об элементах; āyatanayamaka- = парные вопросы о сферах восприятия
Suddhadhātuvāro = раздел об элементах как таковых; Suddhadhātumūlacakkavāro = круговой раздел на основе элементов как таковых
Sacakkhukānaṃ / acakkhukānaṃ / sasotakānaṃ / asotakānaṃ = с глазом / без глаза / с ухом / без уха («перерождается с глазом и без уха»; the phrase the text uses, «с / без» carries sa- / a-)

## Saccayamaka members
X-saccaṃ / -saccanti / -saccañca = истина о страдании / о возникновении / о прекращении / о пути
saccaṃ / saccanti / saccañca / saccañceva = истина; saccā / saccāni = истины («Истины являются …», «Четыре истины»)
dukkhaṃ = страдание; samudayo / Samudayaṃ = возникновение; nirodho / nirodhaṃ = прекращение; maggo / maggaṃ = путь
Kāyikaṃ dukkhaṃ = телесное страдание; cetasikaṃ dukkhaṃ = душевное страдание
avasesaṃ / avaseso / avasesā / Avasese = остальной («остальное», «остальные истины», «В остальном существовании»)
Saccayamakaṃ = парные вопросы об истинах; Suddhasaccavāro = раздел об истинах как таковых; Suddhasaccamūlacakkavāro = круговой раздел на основе истин как таковых; Paṇṇattivāra (stem) = раздел об обозначениях

## Sacca pavatti units (locative time phrase -> nominative without «в», comma dropped, as G8 TIME)
taṇhāvippayuttacittassa uppādakkhaṇe / bhaṅgakkhaṇe = момент возникновения / распада ума не связанного с жаждой
maggavippayuttacittassa … = … ума не связанного с путём; taṇhāvippayuttamaggavippayutta- = … ума не связанного с жаждой и не связанного с путём (reverse order likewise)
maggavippayuttataṇhāvippayuttacittassa (split keyword) = ум не связанный с путём и не связанный с жаждой
taṇhāvippayuttacitte = ум не связанный с жаждой («когда присутствует ум, не связанный с жаждой»); citte = ум; akusale citte = неблагой ум; vattamāne = присутствовать (pi-5)
taṇhāya uppādakkhaṇe / bhaṅgakkhaṇe = момент возникновения / распада жажды
upapatticittassa uppādakkhaṇe / bhaṅgakkhaṇe = момент возникновения / распада ума перерождения
uppādakkhaṇe / bhaṅgakkhaṇe (bare, after Aggamaggassa) = момент возникновения / распада (G8)
pavatte = течение жизни («в течение жизни»)
maggassa = путь; phalassa = плод; Aggamaggassa = высший путь; aggaphalassa = высший плод
cittassa = ум («сразу после данного ума», «этого ума»); anantarā = сразу после (pi-2 / pi-4 / pi-5)
aggamaggaṃ paṭilabhissanti (and ^6-5-74 slip paṭilabhissānti) = обрести высший путь (presence exception, self-checked: «обретёт высший путь»)
Aggamaggasamaṅgīnaṃ = обладающий высшим путём; arahantānaṃ = архаты (pi-5; Pāli and Russian plural)
Abhisametāvīnaṃ / anabhisametāvīnaṃ = постигший истины / не постигший истины («у (не) постигших истины»; participle masc. sg.)
āpāyikānaṃ = существа низших миров; Apāye = низшие миры («В низших мирах»)
caññe = другой («у других, кто обретёт путь»; ca has no word)
pañcavokāre in «В остальном существовании с четырьмя составляющими и с пятью составляющими» = существование … с пятью составляющими (^6-5-30 override)
asaññattā (^6-5-76 slip) = существа без восприятия; nirujjhiti (^6-5-125 slip) = прекращаться
Yassa yattha = у кого где («У кого где …»)

## Editorial notes
Yatthakaṃ / Yatthakampi = раздел с «где»; yatthakā = разделы с «где»; Yassakampi = раздел с «у кого»; yassayatthakampi / yassayatthakepi = раздел с «у кого где»
yatthakasadisaṃ = такой же как в разделе с «где»; yassayatthakasadisaṃ = так же как раздел с «у кого где»
uppādepi / uppādavāre(pi) = раздел о возникновении; nirodhepi / nirodhavāre(pi) = раздел о прекращении; uppādanirodhepi / uppādanirodhavārepi = раздел о возникновении и прекращении (harmonise_apply edit 3: «в разделе о …»)
anulomampi = утвердительная … форма («и в утвердительной, и в отрицательной форме»); paccanīkampi = отрицательная форма
pucchā = вопросы («вопросы о прошлом»); nirodhasamāpannānanti = вошедший в медитативное достижение прекращения (G8)

## pajahati (5-03 pariññāvāra; present from G7)
pajahati / pajahatīti = устранять; pajahittha / pajahitthāti = устранить («устранил»); pajahissati / pajahissatīti = устранить («устранит»)
nappajah- = «не» + the verb where that tense is negated in the segment's Russian (не устранять / не устранить), else the positive verb (denied negative «но устранил / устранят»; pj3_value, same rule as G2 pv_neg_value)
parijān- = G2 pj_value (полностью понимать / понять; понимать полностью where only «не понимают полностью»)
