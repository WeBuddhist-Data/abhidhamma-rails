# notes-map-G7: anusaya keyword values (7-01 … 7-11; frame-setter for the anusaya frames)

Script: map_G7_ru.py (importable, writes nothing; ANUSAYA_NAMES, ANUSAYA_TABLE = YM + anusaya values, NEG_RULES, context_value(bid, kw, ru_text), exceptions_for(part)). The translation file is the truth; builders build_7-0N_ru.py, notes-7-0N.md. Every case form of a keyword takes one value; -ti / -ñca fold to the base form.

## The seven tendencies (every case form: -o, -ā, -aṃ, -añca, -ena = the nominative name; pi-2 / pi-5)
kāmarāgānusayo = скрытая склонность к чувственной страсти (also the slip kāmārāgānusayo)
paṭighānusayo = скрытая склонность к неприязни
mānānusayo = скрытая склонность к самомнению
diṭṭhānusayo = скрытая склонность к воззрениям
vicikicchānusayo = скрытая склонность к колебанию
bhavarāgānusayo = скрытая склонность к страсти к существованию
avijjānusayo = скрытая склонность к неведению
X-ānusayena (of «X-ena sānusayo / niranusayo» = «имеет / не имеет скрытую склонность к X») = the same nominative name
anusayā = скрытые склонности (plural: «сколько скрытых склонностей», «семь скрытых склонностей»)
sattānusayā = семь скрытых склонностей
anusayayamakaṃ = парные вопросы о скрытых склонностях

## Verbs (finite verb in the text -> infinitive; short participle -> full form)
anuseti / anusenti = залегать («залегает / залегают»)
nānuseti / nānusenti = не залегать (segment has «не залегает»); залегать where the text only says the denied negative plainly («no ca tassa Y nānuseti» = «но у него залегает Y»)
sānusayo / sānusayā = иметь («имеет / имеют скрытую склонность к X»)
niranusayo / niranusayā = не иметь («не имеет скрытой склонности к X»); иметь where only «но имеет …» renders it
pajahati / pajahanti = устранять
nappajahati / nappajahanti = не устранять (or устранять where only «но он устраняет …»)
parijānāti / parijānanti = полностью понимать; понимать полностью where the segment has it only as «не понимает / понимают полностью» (G2's rule; matched on the stem, since place sections use the generic plural «Где полностью понимают …» with a singular Pāli verb: 6 segments, ^6-7-234 … ^6-7-256)
pahīno / pahīnā = устранённый («устранена / устранены»; masc. sg. as pi-1 participles)
appahīno / appahīnā = не устранённый (or устранённый where only «но у него устранена …»)
uppajjati = возникать; nuppajjati = не возникать (or возникать, same rule; G2 PV_FRAME)
upapajjati / upapajjantassa = перерождаться («перерождается»); upapajjamāno = перерождаясь (gerund the text uses)
upapatti / upapattināma = перерождение («перерождения … не бывает»; nāma has no word)
bhaṅgā = подлежать разделению (7-10 «подлежит разделению», presence exception: 2nd conjugation -ит; 7-11 «подлежащих разделению»; one value for both, coordinator BHANGA_RU)
natthi = такого нет («Такого нет.»; YM still has нет: overridden)

## Persons (nominative; adjectives / participles masc. sg., as G2 / G8)
anāgāmissa / anāgāmī = невозвращающийся
puthujjanassa / puthujjano = обычный человек
arahato / arahā = архат; arahato in the Namo line (^6-7-349) = Достойный (CORE)
puggalassa / puggalo = личность («у этой же личности», «Эта же личность»); puggalānaṃ / puggalā = личности
aggamaggasamaṅgī / -iṃ / -iñca = обладающий высшим путём (G2)
anāgāmimaggasamaṅgī / -iṃ / -iñca = обладающий путём невозвращения
maggasamaṅgīnaṃ / -ñca = обладающий путём («Кроме двух обладающих путём»; participle masc. sg., as G8 cittasamaṅgīnaṃ)
aṭṭhamako / aṭṭhamakañca = личность восьмой ступени (pi-5)
avasesā = остальной; ṭhapetvā = кроме

## Places (nominative, without «в»)
kāmadhātuyā / kāmadhātuṃ = мир чувственных желаний; rūpadhātuyā / rūpadhātuṃ = мир форм; arūpadhātuyā / arūpadhātuṃ = мир без форм (also in «Kāmadhātuyā cutassa» = «умерев в мире чувственных желаний»)
kāmadhātuṃyeva = только … мир чувственных желаний («только в мире чувственных желаний»)
dvīsu vedanāsu = два вида чувства; tīsu vedanāsu = три вида чувства; dukkhāya vedanāya = болезненное чувство

## Headings and closings (heading phrase, label / number dropped, lower-case first letter)
uppattiṭṭhānavāro = раздел о месте возникновения; mahāvāro = большой раздел
anusayavāro / -vāra / -vāre = раздел о скрытых склонностях
sānusayavāro / -vāra / -vāre = раздел об имеющих скрытые склонности
pajahanavāro / -vāra / -vāre (also the slip pajahanāvāre) = раздел об устранении
pariññāvāro / -vāra / -vāre = раздел о полном понимании
pahīnavāro / -vāra / -vāre = раздел об устранённом
uppajjanavāro = раздел о возникновении
dhātupucchāvāro = раздел вопросов об элементах; dhātuvisajjanāvāro / dhātuvisajjavāro = раздел ответов об элементах
anulomapuggalo / anulomaokāso / anulomapuggalokāsā = утвердительная форма по личности / по месту / по личности и месту; paṭiloma- = отрицательная форма …
anulomaṃ / paṭilomaṃ (closing «Anusayavāre anulomaṃ.») = утвердительная / отрицательная форма
kāmadhātumūlakaṃ / rūpadhātu- / arūpadhātu- = на основе мира чувственных желаний / мира форм / мира без форм
nakāmadhātumūlakaṃ … = на основе не мира чувственных желаний (не мира форм, не мира без форм; «… и не мира …» for the double ones)
