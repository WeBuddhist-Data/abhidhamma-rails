## Persons of the future units (10-05 … 10-12)
purisā = мужчины; itthiyo = женщины («у тех мужчин / женщин, которые, пройдя в этом же состоянии несколько существований, достигнут …»; Pāli and Russian plural; itthīnaṃ / purisānaṃ of «перерождается (не) женщиной» stay женщина / мужчина, G10a)
sacakkhukā = с глазом; saghānakā = с носом (prepared) («тех, кто, переродившись с глазом и с невозмутимостью, …»; G3 sacakkhukānaṃ pattern)
somanassasampayuttapacchimacittaṃ = последний ум связанный с радостью; upekkhāsampayuttapacchimacittaṃ = последний ум связанный с невозмутимостью («сразу после данного ума возникнет последний ум, связанный с …»; comma dropped)
somanassasampayuttapacchimacittasamaṅgīnaṃ / upekkhāsampayutta- = обладающий последним умом связанным с радостью / с невозмутимостью («у обладающих последним умом, связанным с …»; G8 pacchimacittasamaṅgīnaṃ + the -sampayutta phrase)
Pacchimacittasamaṅgīna (^6-10-314 slip) = обладающий последним умом
anantarā = сразу после; cittassa (yassa cittassa anantarā) = ум; citte = ум; vattamāne = присутствовать (G45)
upapatticittassa (split keyword before a separate uppādakkhaṇe, ^6-10-276) = ум перерождения; upapatticittassa uppādakkhaṇe / bhaṅgakkhaṇe = момент возникновения / распада ума перерождения (G45)
cittassa uppādakkhaṇe / bhaṅgakkhaṇe = момент возникновения / распада ума where the Pāli segment has the plain unit; момент возникновения / распада … ума where it has only «tassa cittassa …» («в момент возникновения этого ума»; G9 citta_moment rule)
cavantīnaṃ = умирать (feminine of cavantānaṃ); cavantāna (^6-10-361 slip) = умирать
Itarāsaṃ = остальной (feminine of itaresaṃ)
Pacchimabhavikānaṃ before itthīnaṃ upapajjantīnaṃ / purisānaṃ upapajjantānaṃ = в последний раз («кто в последний раз перерождается женщиной / мужчиной»; G2 pacchima_value extended to the feminine and the two-word gap); elsewhere жить последней жизнью (no segment has both readings)
uppajjantānaṃ (^6-10-398 «Pacchimabhavikānaṃ purisānaṃ uppajjantānaṃ», kept as written «в последний раз возникает мужчиной») = возникать (as G10a uppajjantīnaṃ); pacchima_value counts it as «в последний раз» (decided on the exact-case Pāli occurrences, as G2: at ^6-10-398 only the lower-case «rūpāvacare … pacchimabhavikānaṃ» is listed = жить последней жизнью)
upapajjissati (^6-10-309 «no ca tesaṃ … na upapajjissati», kept as written «но у них переродится способность радости») = переродиться (override; G3's ^6-3-212 upapajjissati = возникнуть because that Russian has «возникнет»)
Ghānandriyamūlakaṃ (^6-10-336 slip) = на основе способности носа
