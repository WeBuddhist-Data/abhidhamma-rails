## Family B: pavattivāra
Verbs (PV_VERBS, agreement with the Russian subject):
uppajjati = возникает; uppajjittha = возникал / возникала / возникало / возникали (imperfective past: "has ever arisen"); uppajjissati = возникнет
nirujjhati = прекращается; nirujjhittha = прекращался / прекращалась …; nirujjhissati = прекратится
nuppajjati / na nirujjhati = не возникает / не прекращается
Questions (7-01 shape, verb before subject, PV_PRED «{v} {x}»):
yassa X V tassa Y V? = У кого возникает X, у того возникает Y?
yattha … tattha …? = Где возникает X, там возникает Y?
yassa yattha … tassa tattha …? = У кого где возникает X, у того там возникает Y?
… vā pana … = (б) А у кого / А где …
Answers: Āmantā. = Да.; Natthi. = Такого нет. [7-01]; Uppajjati. / Uppajjittha. / Uppajjissati. = Возникает. / Возникала. / Возникнет.; Nirujjhati. / Nirujjhittha. = Прекращается. / Прекращалась.
Partial answers:
<persons> tesaṃ X V1, no ca tesaṃ Y V2. = У <persons>, возникает X, но у них не возникает Y.
<persons> tesaṃ tattha … = У <persons>, там возникает X, но у них там не возникает Y.
