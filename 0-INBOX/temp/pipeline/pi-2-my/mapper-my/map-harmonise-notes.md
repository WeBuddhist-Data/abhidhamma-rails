   - dhammā kusalā «သဘောတရား … ကုသိုလ်» → «ကုသိုလ် သဘောတရား» (12, 13: 7): the pi-1 value (204 uses) and ch6, 7,

     jhānaṃ (bahubbīhi, rule 3), as ch4 / ch11 for the same text; the jhāna-factor noun ^2-580 keeps the noun.
