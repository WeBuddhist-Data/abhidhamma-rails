## 5. Departures from the Hindi pi-3/4/5 termbases (and choices between them)

- pāpakānaṃ akusalānaṃ dhammānaṃ (hirī/ottappa strings) = बुरी और हानिकर परिघटनाओं (pi-4 ^4-53/73: अवस्थाओं). Reason: dhamma = परिघटना (style rule), and akusalā dhammā is the matrix item हानिकर परिघटनाएँ. The rest of the pi-4 wording is kept verbatim.
- paggāha = तत्परता (pi-5 termbase: सहारा). Reason: the Dhammasaṅgaṇī defines paggāha by the energy string (^1-56); «सहारा» (support) would mislead.
- anabhijjhā = लालच का अभाव (pi-4: लालच न करना, a verbal context). Reason: noun form parallel to लोभ / द्वेष / मोह का अभाव in the same list.
- vedayitaṃ (sukha string) = अनुभव (pi-5: vedayita = अनुभूति). Reason: vedanā = अनुभूति stands in the same string.
- samāpatti (meditative, pair 120) = ध्यान-अवस्था (pi-5) rather than pi-4 ध्यान-उपलब्धि.
- yoniso = उचित ढंग से (pi-4) rather than pi-5 सही ढंग से. Reason: सही is reserved for sammā.
- khaya = क्षय (pi-5) rather than pi-4 नाश / नष्ट होना.
- paññatti (pair 108) = नामकरण (pi-5, which renders the same adhivacana/nirutti/paññatti-patha triple); pi-4 uses विवरण only in book and chapter titles (Puggalapaññatti), which is a different use.
- appamāṇa = अपरिमित and mahaggata = उन्नत (pi-3, the matrix anchor) rather than pi-5 असीम / विस्तृत. appamaññā (the four boundless states) stays असीम भाव.
- bālā / paṇḍitā dhammā = मूर्खतापूर्ण / बुद्धिमत्तापूर्ण परिघटनाएँ (pi-4 मूर्ख, pi-5 नासमझ / बुद्धिमान are said of persons). Reason: adjectives for phenomena.
- ottappa = बुराई का डर (pi-4 noun) rather than pi-5 बुराई से डरना (verbal).
- sammāsaṅkappa / saṅkappa = सही संकल्प / संकल्प (no Hindi anchor found). Reason: cetanā = इरादा in the same list.
- kāya in kāyapassaddhi … kāyujukatā = मानसिक काया. Clarification by wording: the text itself defines it as the feeling, perception and mental-formations aggregates; plain «काया» would be read as the physical body.
- dhammārammaṇa = मन का विषय, matching hindi-style's dhammāyatana = मन के विषयों का इंद्रिय-क्षेत्र.
- sallakkhaṇā (paññā string, pi-4 verbatim) = पहचानना, which also renders sañjānanā in the saññā string. Kept to reuse the approved pi-4 string unchanged; flag if the user wants them split.
