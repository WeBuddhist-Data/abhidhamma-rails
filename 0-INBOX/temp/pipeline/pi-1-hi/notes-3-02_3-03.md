## Frame
Katamaṃ taṃ rūpaṃ X? = वह भौतिक रूप कौन-सा है जो X है?
… – idaṃ taṃ rūpaṃ X. = … – यह वह भौतिक रूप है जो X है।
Idaṃ taṃ rūpaṃ upādā. / no upādā. (closing lines) = यह वह भौतिक रूप है जो व्युत्पन्न है। / … जो व्युत्पन्न न होने वाला है।
Two terms: two plain adjectives share one «है» (आंतरिक और व्युत्पन्न है); otherwise «A है और B है / नहीं है»; if either term already contains «और», «A है तथा B है».
…pe… chain of items: «X… Y… Z है»; negative chain: «X नहीं… Y नहीं… Z नहीं है».
Contact chains: every member takes «का»: आँख के संपर्क से उत्पन्न अनुभूति का… पहचान का… इरादे का… आँख की चेतना का आधार (as 3-01).

## Departures / choices to review
- upacaya = वृद्धि (pi-5: संचय): ācaya = संचय in the matrix (^1-M1-10), and ^1-641 defines upacaya by ācaya.
- viññatti = प्रकट अभिव्यक्ति (pi-5, as 3-01). It overlaps with nirutti = अभिव्यक्ति (^1-M2-107); flag if the user wants viññatti kept apart (e.g. संकेत).
- kāya as sense organ = शरीर (pi-3); kāya- in kāyapassaddhi etc. stays मानसिक काया (terms file).
- pasāda = संवेदनशीलता (no Hindi anchor; pi-4/5 pasāda = trust is a different sense).
- dhātūnaṃ sannighātasaddo = वस्तुओं के आपस में टकराने की ध्वनि (dhātu here = things, not तत्व).
