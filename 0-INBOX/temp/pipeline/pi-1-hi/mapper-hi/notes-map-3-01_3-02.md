## Material form: rūpa
rūpaṃ = भौतिक रूप (every segment, including the eye/visible-form definitions where rūpaṃ is also the seen object; the frame «वह भौतिक रूप कौन-सा है …» carries it)
rūpa (stem) = सूक्ष्म भौतिक (segment has rūpāvacara-)
rūpa (stem) = दृश्य रूप (segment has rūpāyatanaṃ / rūpadhātu; Rūpa in ^1-656 etc. too)
rūpa / Rūpa (stem, otherwise) = भौतिक रूप (headings, X-vidhena rūpasaṅgaho lists)
rūpamhi = दृश्य रूप (^1-598, only the seen object)
rūpasaṅgaho = भौतिक रूप का वर्गीकरण; saṅgaho = वर्गीकरण; vidhena = प्रकार (Catubbidhena = चार प्रकार, Chabbidhena = छह प्रकार)
rūpaṃ sappaṭighaṃ = भौतिक रूप टकराव वाला (contiguous); = भौतिक रूप … टकराव वाला (^1-658 question frame); same for rūpaṃ appaṭighaṃ / cittasamuṭṭhānaṃ / cittasahabhu / cittānuparivatti
rūpassa X = भौतिक रूप का हल्कापन / की मृदुता / की कार्य-योग्यता / की वृद्धि / की धारा / का बुढ़ापा / की अनित्यता; rūpassa na X = … नहीं
rūpassa upacayo = भौतिक रूप की … वृद्धि (^1-642 / ^1-736 «भौतिक रूप की जो वृद्धि है»)
rūpīnaṃ dhammānaṃ = भौतिक परिघटना (life faculty)

## Matrix predicates (masc. sg., as 1-matika)
upādā / Upādā / upādāya = व्युत्पन्न (no upādā: positive part); upādāya rūpaṃ = व्युत्पन्न भौतिक रूप; upādāya pasādo = व्युत्पन्न संवेदनशीलता
upādiṇṇaṃ / upādiṇṇa = कर्म से उत्पन्न; anupādiṇṇupādāniyaṃ = कर्म से उत्पन्न न होकर भी आसक्ति का विषय बनने वाला
sanidassanaṃ = दिखाई देने वाला; anidassana(ṃ/no/ena/mhi) = दिखाई न देने वाला; sappaṭigha(ṃ/o/mhi) = टकराव वाला; appaṭighaṃ = टकराव से रहित
anidassano sappaṭigho (all cases) = दिखाई न देने वाला और टकराव वाला (masc. even where the Hindi agrees with आँख / ध्वनि in the feminine)
samuṭṭhānaṃ = उत्पन्न; cittasahabhu = मन के साथ-साथ होने वाला; anuparivatti = अनुसरण करने वाला
niyataṃ / niyatameva = निश्चित (of aniyataṃ «अनिश्चित»: positive part of a fused negative; presence check misses it)
cetasikaṃ = मन का सहचर (of acetasikaṃ); ārammaṇaṃ = विषय (of anārammaṇaṃ)
hetukaṃ = मूलों वाला (ekaka list, ahetukaṃ / pahātabbahetukaṃ); = कारण होने वाला (cittahetukaṃ, ^1-666 / ^1-667)
apariyāpannaṃ = अस्तित्व के लोकों में न समाई हुई परिघटना (the Hindi keeps the matrix item with परिघटना)
uppannaṃ = उत्पन्न हो चुका (^1-584); = उत्पन्न होकर (^1-594)
gāmi = की ओर ले जाने वाला; abhibhūtaṃ = ग्रस्त (jarābhibhūtaṃ); kiriyā = केवल क्रिया रूपी (as 2-05)
X-meva (Ekakaniddesa ^1-594) = the Hindi of X; eva = ही

## Great elements, bases, faculties
bhūtā / bhūtaṃ / bhūtānaṃ / bhūtehi = महाभूत (the Hindi has the one word महाभूत; same as mahābhūta-)
kāya (and kāyo, kāyaṃ, kāyena, kāyamhi, kāyassa) = शरीर (sense organ / body; not मानसिक काया)
cakkhu / sota / ghāna / jivhā = आँख / कान / नाक / जीभ (all cases)
X-āyatanaṃ = X का इंद्रिय-क्षेत्र; X-dhātu = X का तत्व; X-samphassassa / -samphasso = X का संपर्क; X-samphassajā(ya) = X के संपर्क से उत्पन्न; X-viññāṇa(ssa/ṃ) = X की चेतना; X nissāya = X के सहारे; nissāya = सहारा
itthi = स्त्रीत्व (of itthindriyaṃ); = स्त्री (^1-632 / ^1-714 itthiliṅgaṃ …, itthiyā); purisa likewise पुरुषत्व / पुरुष
pathavī / āpo / tejo / vāyo / ākāsa = पृथ्वी / जल / अग्नि / वायु / आकाश; X-dhātu = X तत्व
dhātu = तत्व; dhātūnaṃ = वस्तु (dhātūnaṃ sannighātasaddo)
dhamma = मन के विषय, dhammāyatana = मन के विषयों का इंद्रिय-क्षेत्र (^1-593)
viññatti = प्रकट अभिव्यक्ति; viññāpanā = प्रकट करना; vacī = वाणी
kabaḷīkāro = कौर-कौर खाया जाने वाला; āhāro = भोजन

## Verbs (passi/suṇi/… paṭihaññi formulas, uppajji …)
aorist (paṭihaññi, suṇi, ghāyi, sāyi, phusi, uppajji) = the Hindi perfect: टकरा चुका, सुन चुका, सूँघ चुका, चख चुका, छू चुका, उत्पन्न हो चुका
present (paṭihaññati, suṇāti, ghāyati, sāyati, phusati, uppajjati) = infinitive (as pi-5): टकराना, सुनना, सूँघना, चखना, छूना, उत्पन्न होना
future (paṭihaññissati, suṇissati, ghāyissati, sāyissati, phusissati, uppajjissati) = टकराएगा, सुनेगा, सूँघेगा, चखेगा, छुएगा, उत्पन्न होगा
sappaṭighaṃ / sappaṭigho paṭihaññi = टकराव वाला … टकरा चुका
-antassa participles (abhikkamantassa …) = infinitive: आगे बढ़ना, पीछे हटना, सामने देखना, इधर-उधर देखना, अंग सिकोड़ना, अंग फैलाना
