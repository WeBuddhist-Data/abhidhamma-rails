# Map notes: 3-03-rupakandam (new recurring decisions; script map_3-03_hi.py)

kāya = शरीर (sense organ, kāyāyatana / kāyaviññatti; not मानसिक काया)
āhāro = भोजन (kabaḷīkāro āhāro); kabaḷīkāro = कौर-कौर खाया जाने वाला
rūpaṃ = भौतिक रूप (frame «वह भौतिक रूप कौन-सा है जो …»); rūpa / Rūpa (of rūpāyatana, rūpadhātu) = दृश्य रूप
upādā / upādāya = व्युत्पन्न (also in «व्युत्पन्न न होने वाला», no upādā)
upādiṇṇaṃ / upādiṇṇa = कर्म से उत्पन्न (also inside anupādiṇṇaṃ «… न होने वाला»)
sappaṭighaṃ = टकराव वाला; appaṭighaṃ = टकराव से रहित
X sappaṭighaṃ / X appaṭighaṃ (bāhiraṃ, upādā, upādiṇṇaṃ, rūpaṃ) = «X और Y» where the Hindi has it; «X … Y» where «न होने वाला» or the question frame intervenes
bhūtaṃ / bhūtānaṃ / bhūtehi = महाभूत (fragment of mahābhūta; Hindi has one word)
samuṭṭhānaṃ = उत्पन्न; cittajaṃ = मन से जन्मा; hetukaṃ = के कारण होने वाला (cittahetukaṃ)
cittasahabhu = मन के साथ-साथ होने वाला; anuparivatti = अनुसरण करने वाला (negated forms: «न होने वाला» / «न करने वाला»)
kammassa katattā = किए गए कर्म के कारण (list lead «Kammassa katattā …:»); कर्म किए जाने के कारण (inside «yaṃ vā panaññampi …» and «Na kammassa katattā»); kammassa = कर्म
rūpassa na X = भौतिक रूप का/की X नहीं (lahutā हल्कापन, mudutā मृदुता, kammaññatā कार्य-योग्यता, upacayo वृद्धि, santati धारा, jaratā बुढ़ापा, aniccatā अनित्यता)
X-samphassassa = X का संपर्क; X-samphassajāya = X के संपर्क से उत्पन्न; X-viññāṇassa = X की चेतना; vedanāya / saññāya / cetanāya = अनुभूति / पहचान / इरादा
Itthi / purisa = स्त्रीत्व / पुरुषत्व (of itthindriya / purisindriya); in the itthiliṅga / purisaliṅga strings (1-838, 1-841) itthi = स्त्री, purisa = पुरुष
liṅgaṃ = आकृति; nimittaṃ = चिह्न; kuttaṃ = आचरण; ākappo = ढंग
gataṃ (ākāsagata, āpogata …) = की प्रकृति वाला
bhedo = टूटना (aniccatā string); फूटना (vacībhedo, 1-850)
abhikkamantassa … pasārentassa = infinitive of the Hindi participle (आगे बढ़ना, पीछे हटना, सामने देखना, इधर-उधर देखना, अंग सिकोड़ना, अंग फैलाना)
āsiyaṃ = खाना; vikhādanaṃ = चबाना; ajjhoharaṇīyaṃ = नीचे उतारना; vitthambhanaṃ = भरना; ojāya = पोषक सार; yāpenti = जीवित रहना
saṃhāni = घटना (आयु का घटना); paripāko = पूरी तरह पक जाना
X-viññeyyaṃ rūpaṃ multiword keys = the contiguous Hindi run (e.g. āyatanaṃ cakkhuviññeyyaṃ rūpaṃ = इंद्रिय-क्षेत्र आँख से जाना जा सकने वाला भौतिक रूप)
saṅgaho = वर्गीकरण; rūpasaṅgaho = भौतिक रूप का वर्गीकरण; vidhena = प्रकार; vibhatti = वर्गीकरण; niddeso = व्याख्या
Dasakaṃ / Ekādasakaṃ = दस-दस / ग्यारह-ग्यारह के वर्गीकरण
dhamma (of dhammāyatana, 1-984) = मन के विषय
