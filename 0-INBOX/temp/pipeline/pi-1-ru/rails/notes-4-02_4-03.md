## Decisions and termbase misfits (reported)

Natthi (termbase «ничего не значить», nihilist view): «ничего не значит» for dinnaṃ, yiṭṭhaṃ, hutaṃ, loko, mātā, pitā; «нет» where existence is denied (phalaṃ vipāko, sattā opapātikā, samaṇabrāhmaṇā), as pi-4 ^4-62; atthi = «имеет значение» / «есть» (pi-4 ^4-82).
vipāko (natthi … phalaṃ vipāko) = «результат»: the termbase has only «результат действий» (compound member) and «являющийся результатом».
nāmaṃ in the naming list (^1-1313 … 1315) = «имя»: the termbase has only «умственное» (nāmarūpa).
byañjanaṃ (^1-1313 … 1315) = «словесная форма», assaddhā «лишены веры», appassutā «мало слышали», sambhatti «привязанность», ajjavatā «прямодушие», pariyonāho «полная окутанность», līyitattaṃ «состояние косности», kukkuccāyitattaṃ «состояние мучения угрызениями», anubyañjana «детали», aṭṭhitakiriyatā «безостановочность действий», anolīnavuttitā «неослабевающая деятельность», sucarita «благое поведение»: not in the termbase (pi-4 models where it has them).
paccayā in ṭhāna / aṭṭhāna (^1-1344, 1345) = «условия» (noun); the termbase has only «обусловленный» (dependent origination, used in ^1-1343).
yāpanāya (^1-1355) = «поддержание»: the termbase «сохранение» is given to ṭhitiyā in the same phrase.
