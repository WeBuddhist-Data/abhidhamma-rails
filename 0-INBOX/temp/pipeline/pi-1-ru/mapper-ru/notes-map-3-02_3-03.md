## Frame and predicates

upādā / upādāya = производный; upādāya pasādo = чувствительность производная; upādāya vaṇṇanibhā = производный … цвет и облик

anupādiṇṇupādāniyaṃ = не охваченный цеплянием но служащий его объектом
sanidassanaṃ = видимый; anidassanaṃ / anidassano / anidassanena = невидимый; sappaṭighaṃ = способный к соударению; appaṭighaṃ = не способный к соударению
anidassano sappaṭigho (all cases) = невидимый и способный к соударению; sanidassanaṃ sappaṭighaṃ = видимый и способный к соударению
rūpaṃ X (question frame) = материальная форма + X in the agreeing form (материальная форма не способная к соударению; … порождённая умом; … сосуществующая с умом; … следующая за умом)
two-term keywords (upādā sappaṭighaṃ, bāhiraṃ appaṭighaṃ, upādiṇṇaṃ sappaṭighaṃ …) = «A и B» in masculine (производный и способный к соударению)
rūpassa na X = не … X материальной формы («не является лёгкостью материальной формы»)
ajjhattikaṃ = относящийся к внутреннему; bāhiraṃ = относящийся к внешнему; bahiddhā = внешний (earth-element strings)
oḷārikaṃ = грубый; sukhumaṃ = тонкий; mahābhūtaṃ = великий элемент; bhūtaṃ = элемент; mahābhūtānaṃ / -ehi = великие элементы; bhūtānaṃ / -ehi = элементы
cittasamuṭṭhānaṃ = порождённый умом; samuṭṭhānaṃ = порождённый; cittasahabhu = сосуществующий с умом; anuparivatti = следующий за; cittajaṃ = рождённый умом; hetukaṃ = имеющий корнем
kammassa katattā = вследствие совершённых действий (the participle «возникший» is added by the Russian); kammassa = действие
ārammaṇaṃ = объект (является объектом …)
