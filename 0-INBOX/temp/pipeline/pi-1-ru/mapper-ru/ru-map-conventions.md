# pi-1 Pāli→Russian keyword map: conventions settled on the sample (preamble, 1-matika, 2-01)

Read with `..\ru-mapper-sample-brief.md`. These are the decisions the sample applied. Map the other parts the same way, so that one Pāli word in one sense gets one Russian value across the book. Examples come from the sample's `*.mapped.md` files. The Russian translation is final; the value is always the word or phrase found in THAT segment's Russian.

## Tooling (reuse it)
- `map_common_ru.py` (importing it writes nothing):
  - `read_keywords(part)`, `read_russian(part)`, `read_pali(part)`.
  - `present(value, text)`: presence check. It strips endings to a stem (ё = е) and tolerates regular inflection: «нн» ~ «н» (связанный ~ связаны), participle ~ finite verb (служащий ~ служат), -овать ~ -ует (следовать ~ следует), reflexive -ся, fleeting о/е (корень ~ корни, проступок ~ проступках), a glued «не» (отступный ~ неотступное, проявление ~ непроявление) and a separate «не» between two words. Commas, dashes, quotes and variant brackets are ignored. Parts joined by " … " or " / " are checked one by one.
  - `CORE` (preamble / frame), `CH2` + `ch2_value(kw, kws)` (cittuppāda chapters, with context rules), `MATRIX` (matrix items as settled in 1-matika).
  - `build_part(part, resolver)` writes `<part>.mapped.md`. It stops on any unmapped keyword and refuses ", " inside a value.
  - `verify(part)`: the brief's structural check plus the presence check.
- Pattern for a part script (see `map_sample_ru.py`): `OVERRIDES[bid][kw]` first, then your own table, then `ch2_value`. Extend `CH2` only in your own script (`table = {**CH2, ...}`; `ch2_value(kw, kws, table)`). Do not edit `map_common_ru.py`; the other agents import it at the same time.
- Lookup is case-insensitive on the first letter only (Vedanā, Phasso, Mana, Saddhindriyaṃ, Koṭṭhāsa use the lower-case entry).

## Value form
- Nouns: nominative. Singular for a singular concept: dhamma (stem) = явление, vedanā = чувство (also inside «совокупность чувств»), hetu = корень, āsava = влечение.
- **Plural kept where the Pāli form and the concept are plural** (as in the approved pi-5 map): `dhammā` = **явления**, khandhā = совокупности, āyatanāni = сферы восприятия, dhātuyo = элементы, indriyāni = способности, balāni = силы, hetū = корни, āhārā = виды питания, āsavā = влечения, kilesā = омрачения, oghā = потоки, yogā = ярма, nīvaraṇā = помехи, parāmāsā = искажения, upādānā = цепляния, cittāni = виды ума; saṅkhāra = формирующие факторы. Plurale tantum: saṃyojana(ā) = оковы, gantha(ā) = узы.
- Adjectives and participles alone: nominative masculine singular. kusalā = благой, sampayuttā = связанный, vippayuttā = не связанный, sahagatā = сопровождаемый, pahātabbā = устраняемый, samuppannā = возникший, niyatā = предопределённый (text «предопределённо», «Непредопределённые»).
- **In a phrase with `dhammā`, the whole phrase is nominative plural, in the Russian word order, without commas:** kusalā dhammā = благие явления, vipākadhammadhammā = явления способные приносить результаты, sahagatā dhammā = явления сопровождаемые, samuppannā arūpino dhammā = нематериальные явления возникшие, akusalānaṃ dhammānaṃ = неблагие явления.
- Verbs: infinitive (uppannaṃ = возникать, hirīyati = стыдиться, ottappati = бояться, uppādino = возникнуть, pahātabba (in «чьи корни устраняются») = устраняться, yathā = следовать), or the participle the text uses (ārabbha = имеющий объектом, niṭṭhitā = завершённый, ṭhapetvā = кроме).
- A noun phrase that the text builds around its head keeps its government: abhiniropanā = направление … на объект, anusandhānatā = непрерывная связь … с объектом, samāpattiyā = допускать в себе, dhāraṇatā = способность удерживать в памяти.
- Discontinuous Russian: join the parts with " … ": samaye phasso = в это время … контакт, samuppannā arūpino = нематериальный … возникший, passambhitattaṃ = состояние … утихания.
- Never ", " inside a value: drop the comma (adukkhamasukhaṃ = ни болезненный ни приятный; Yo = то что). The sample needed no " / ".
- `(no direct equivalent)`: for a particle with no Russian word, a word that survives only inside a variant bracket kept in Pāli, and (user 2026-11-14, see the end of this file) a fragment whose positive part is not a Russian word or a keyword with no word of its own in the Russian.

## Compounds and their members
Whole compound = whole Russian phrase; each member = the Russian part that renders it:
- cittamudutā = мягкость ума, mudutā = мягкость, citta = ум; kāya (of kāyapassaddhi … kāyujukatā) = умственное тело
- somanassasahagataṃ = сопровождаемый радостью, somanassa = радость, sahagataṃ = сопровождаемый
- ñāṇavippayuttaṃ = не связанный со знанием, ñāṇa = знание; saṅkhārena (sasaṅkhārena) = побуждение
- kāmāvacaraṃ = относящийся к миру чувственных желаний, kāma = чувственные желания, avacaraṃ = относящийся к миру (rūpāvacarā = относящийся к миру форм, rūpa = форма; arūpāvacarā = относящийся к миру без форм, arūpa = без форм)
- paṭiccasamuppannā = возникший в зависимости от условий, paṭicca = в зависимости от условий; paṭiccasamuppannā arūpino = нематериальный … возникший в зависимости от условий
- manoviññāṇadhātu = элемент умственного сознания, manoviññāṇa = умственное сознание, dhātu = элемент, tajjā = соответствующий; samphassajaṃ = рождённый контактом; cetosamphassajaṃ/-jā = рождённый контактом ума
- vedanākkhandho / -khandhaṃ / -khandhassa = совокупность чувств (saññā- восприятия, saṅkhāra- формирующих факторов, viññāṇa- сознания), khandho / khandhassa = совокупность
- paññāsatthaṃ = меч мудрости, satthaṃ = меч (pāsādo башня, āloko свет, obhāso сияние, pajjoto светоч, ratanaṃ сокровище)
- kusalamūlaṃ = благой корень, mūlaṃ = корень, kusala = благой
- `dhamma` as a stem: dhammārammaṇa = **объект ума**; in a segment that also has dhammāyatanaṃ or dhammadhātu = **объекты ума** (dhammāyatanaṃ = сфера объектов ума, dhammadhātu = элемент объектов ума). `ch2_value` applies this.
- citta / cittassa / cetaso / mānasatā / mana = ум; mano = разум in the citta string, умственный where the segment has manosañcetanā (manosañcetanā = умственное намерение). sañcetanā = проявление намерения in the cetanā string, намерение where it occurs only inside manosañcetanā.
- ṭhiti = устойчивость (samādhi string); сохранение in the jīvita string (segment with āyu). jīvita = жизненный (жизненная способность); жизнь in the jīvita string.
- cetasikaṃ = душевный (душевная отрада, душевное счастье); душевное состояние in «cetasikaṃ neva sātaṃ nāsātaṃ» (segment with adukkhamasukhaṃ).
- ujukatā = прямота (name of the factor); прямизна in the string «ujutā ujukatā …» = «прямота, прямизна …».
- cittaṃ = ум; **вид ума** where the only cittaṃ is the colophon «Paṭhamaṃ/Tatiyaṃ/… cittaṃ» (1-145, 1-148, 1-155, 1-158: overrides). Where the segment also has «kusalaṃ cittaṃ», ум.
- Matrix fragments: uttarā (of lokuttarā) = надмирский; raṇā (of saraṇā/araṇā) = борьба; antara = промежуточный; pathā = путь; upamā = подобный; Piṭṭhi = заключительный; Suttantika = наставления.

## Fragments that lost a negative prefix: the positive part
pilāpanatā = поверхностность, sammussanatā = забывчивость, lubbhanā = проявление жадности, sārajjanā = проявление страсти, dussanā = проявление злобы, byāpajjo = неприязнь (abyāpajjo = отсутствие неприязни), dandhanatā = медлительность, vitthanatā = скованность, kakkhaḷatā = грубость, kathinatā = жёсткость, jimhatā = кривизна, vaṅkatā = изогнутость, kuṭilatā = извилистость, gutta = охранение, mattaññutā = знание меры, niyatā dhammā (of aniyatā) = предопределённые явления, sampajaññañca = ясное понимание, vacassatā = принимать наставления. A fragment that keeps its a- maps with the negative: asithila = неослабевающий, avisāhaṭa = нерассеянность, anuppāde = невозникновение.

## Question frames, relatives, particles
- `Yo / Yā / Yaṃ` = **то что** (Russian «То, что …»). `ye / Ye` (ye vā pana … «какие есть в это время») = какой. `yaṃ yaṃ` (yaṃ yaṃ vā panārabbha) = что бы то ни было.
- `samaye X` = **в это время … X**, always with " … ": samaye cittaṃ = в это время … ум, samaye takko = в это время … мышление, samaye cetasikaṃ = в это время … душевный.
- The sample's lists had no Katame/Katamo/ime/ayaṃ/idaṃ/hoti. If they occur: Katame («Какие явления являются благими?») = какой; Katamo/Katamā/Katamaṃ in «Что в это время является X?» = что; ime/ayaṃ/idaṃ = это (Russian «это и есть»); hoti = the verb the segment uses (есть / являться), else (no direct equivalent).
- na / no = не (1-M2-13). eva: «и есть» / «именно» only where the Russian has such a word, else (no direct equivalent).

## Matrix item names (1-matika; full table: `MATRIX`)
- mātikā = **матрица** everywhere (Матрица, Матрица троек / пар, Матрица пар из наставлений, Матрица завершена). duka/dukaṃ = пары; antaradukaṃ = промежуточные пары.
- Cluster names: the stem is the singular core term (Hetu корень, Āsava влечение, Ogha поток, Yoga ярмо, Nīvaraṇa помеха, Parāmāsa искажение, Upādāna цепляние, Kilesa омрачение; Saṃyojana оковы, Gantha узы); the plural form is plural (āsavā влечения …).
- X-niyā = «подверженный X-ам» (sāsavā подверженный влечениям, saṃyojaniyā подверженный оковам, ganthaniyā узам, oghaniyā потокам, yoganiyā ярмам, nīvaraṇiyā помехам; saṃkilesikā подверженный омрачению; parāmaṭṭhā затронутый искажениями; upādāniyā служащий объектом цепляния, but «служащий его объектом» in 1-M1-4); anāsavā свободный от влечений; X-vippayuttā = не связанный с X-ами. The closing pairs repeat the noun in Russian, so no pronoun is needed there.
