# Notes: pi-1 Russian plain zero-shot, part 3-01 (Rūpakaṇḍa: Uddeso, Mātikā, Ekakaniddeso)

Builder: build_3-01_ru.py (imports build_matika_ru as M; sentence frames with fixed predicate strings, structure as ref/en_build_3-01.py). check_matrix() asserts that every predicate taken from the matrix equals M.PRED changed only from plural to singular feminine (явления -> материальная форма).
Format: Pāli = Russian, one per line.

## Frames
Atthi rūpaṃ A, atthi rūpaṃ B. = Есть материальная форма, которая A, и есть материальная форма, которая B.
Yaṃ taṃ rūpaṃ A, taṃ P. = Та материальная форма, которая A, P.
Yaṃ taṃ rūpaṃ A, taṃ atthi P, atthi Q. = Та материальная форма, которая A, отчасти P, отчасти Q.
X…pe… Y…pe… Z (chain) = X… Y… Z («…» attached to the preceding word); 'na X…pe… na Y' = не является X… не является Y
<N>vidhena rūpasaṅgaho – = Классификация материальной формы по <N> –
Evaṃ <N>vidhena rūpasaṅgaho. = Такова классификация материальной формы по <N>.
(<N> as in the approved headings: по одному, по два … по одиннадцать)
Tattha katamaṃ sabbaṃ rūpaṃ? = Что здесь является всей материальной формой?
sabbaṃ rūpaṃ = вся материальная форма
idaṃ vuccati X = это называется X (after the Pāli «–»)
Cattāro ca mahābhūtā, catunnañca mahābhūtānaṃ upādāya rūpaṃ = Четыре великих элемента и материальная форма, производная от четырёх великих элементов
-meva (^1-594) = несомненно <predicate>
Ekaka lists (^1-584, ^1-594): items separated by «;» because several items contain commas.

## Uddeso ^1-583
Kusalākusalānaṃ dhammānaṃ vipākā kāmāvacarā rūpāvacarā arūpāvacarā apariyāpannā = Результаты благих и неблагих явлений, относящиеся к миру чувственных желаний, к миру форм, к миру без форм и не принадлежащие к кругам существования
ye ca dhammā kiriyā neva kusalā nākusalā na ca kammavipākā = и те явления, которые являются функциональными, не являются ни благими, ни неблагими и не являются результатами действий
asaṅkhatā dhātu = необусловленный элемент

## Predicates (singular feminine; matrix ones from M.PRED)
upādā / no upādā = является производной / не является производной
upādiṇṇaṃ / anupādiṇṇaṃ = охвачена цеплянием / не охвачена цеплянием
upādiṇṇupādāniyaṃ / anupādiṇṇupādāniyaṃ = охвачена цеплянием и служит его объектом / не охвачена цеплянием, но служит его объектом
sanidassanaṃ / anidassanaṃ = является видимой / является невидимой
sappaṭighaṃ / appaṭighaṃ = способна к соударению / не способна к соударению
indriyaṃ = способность (является способностью)
mahābhūta = великий элемент
viññatti = внешнее выражение (pi-5); kāyaviññatti = телесное внешнее выражение; vacīviññatti = речевое внешнее выражение
cittasamuṭṭhānaṃ / cittasahabhu / cittānuparivatti = порождена умом / сосуществует с умом / следует за умом
ajjhattikaṃ / bāhiraṃ = относится к внутреннему / относится к внешнему
oḷārikaṃ / sukhumaṃ = является грубой / является тонкой (pi-5 грубый / тонкий)
dūre / santike = находится далеко / находится близко
vatthu (of contact, consciousness) = основа (является основой …)
ārammaṇaṃ / nārammaṇaṃ = является объектом … / не является объектом …
cakkhu / sota / ghāna / jivhā / kāya (sense) = глаз / ухо / нос / язык / тело (genitive: глаза, уха, носа, языка, тела)
cakkhusamphassa … kāyasamphassa = контакт глаза … контакт тела
cakkhusamphassajā vedanā = чувство, рождённое контактом глаза (as cetosamphassajā = рождённое контактом ума)
cakkhuviññāṇa / sota- / ghāna- / jivhā- / kāyaviññāṇa = зрительное / слуховое / обонятельное / вкусовое / осязательное сознание (pi-3)
cakkhāyatana … kāyāyatana = сфера глаза / уха / носа / языка / тела (pi-3)
rūpāyatana / saddā- / gandhā- / rasā- / phoṭṭhabbāyatana = сфера видимых форм / звуков / запахов / вкусов / осязаемого (pi-3)
cakkhudhātu … phoṭṭhabbadhātu = элемент глаза … элемент видимых форм / звуков / запахов / вкусов / осязаемого (pi-3)
cakkhundriya / sotindriya / ghānindriya / jivhindriya / kāyindriya = способность глаза / уха / носа / языка / тела
itthindriya / purisindriya = способность женственности / способность мужественности (pi-3 itthi, purisa)
pathavī- / āpo- / tejo- / vāyodhātu = элемент земли / воды / огня / ветра (pi-5)
ākāsadhātu = элемент пространства
rūpassa lahutā / mudutā / kammaññatā = лёгкость / мягкость / работоспособность материальной формы (terms file)
rūpassa upacayo = рост материальной формы (not «накопление»: ācaya = накопление in the matrix, and 3-02 defines upacaya by ācaya)
rūpassa santati = непрерывность материальной формы (not pi-5 «поток»: ogha = поток)
rūpassa jaratā = старение материальной формы (pi-5 jarā); jarābhibhūtaṃ = подвластна старению
rūpassa aniccatā = непостоянство материальной формы (pi-5); aniccaṃ = является непостоянной
kabaḷīkāro āhāro = съедаемая пища (pi-5)

## Ekaka list extras (^1-584)

## Lists (^1-586 … ^1-593)
