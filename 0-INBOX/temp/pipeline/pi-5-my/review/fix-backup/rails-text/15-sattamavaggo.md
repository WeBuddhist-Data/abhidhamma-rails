တွေ့ထိမှုသည် ကံ၏ အကျိုး ဖြစ်သည်၊ တွေ့ထိမှုသည် သာယာသော ခံစားမှုကို ဖြစ်စေတတ်သော၊ နာကျင်သော ခံစားမှုကို ဖြစ်စေတတ်သော၊ မနာကျင် မသာယာသော ခံစားမှုကို ဖြစ်စေတတ်သော၊ သာယာသော ခံစားမှုနှင့် ယှဉ်တွဲသော၊ နာကျင်သော ခံစားမှု… မနာကျင် မသာယာသော ခံစားမှုနှင့် ယှဉ်တွဲသော၊ တွေ့ထိမှုနှင့် ယှဉ်တွဲသော၊ ခံစားမှုနှင့် ယှဉ်တွဲသော၊ မှတ်သိမှုနှင့် ယှဉ်တွဲသော၊ စေ့ဆော်မှုနှင့် ယှဉ်တွဲသော၊ စိတ်နှင့် ယှဉ်တွဲသော၊ အာရုံ ရှိသော အရာ ဖြစ်သည်၊ ထိုအရာ၌ စိတ်ကို လှည့်ဆောင်ခြင်း… ဆုတောင်းခြင်း ရှိသလော။ ဟုတ်ပါသည်။ မြေသည် ကံ၏ အကျိုး ဖြစ်သည်၊ မြေသည် သာယာသော ခံစားမှုကို ဖြစ်စေတတ်သော၊ နာကျင်သော ခံစားမှုကို ဖြစ်စေတတ်သော၊ မနာကျင် မသာယာသော ခံစားမှုကို ဖြစ်စေတတ်သော၊ သာယာသော ခံစားမှုနှင့် ယှဉ်တွဲသော၊ နာကျင်သော ခံစားမှု… မနာကျင် မသာယာသော ခံစားမှုနှင့် ယှဉ်တွဲသော၊ တွေ့ထိမှုနှင့် ယှဉ်တွဲသော၊ ခံစားမှုနှင့် ယှဉ်တွဲသော၊ မှတ်သိမှုနှင့် ယှဉ်တွဲသော၊ စေ့ဆော်မှုနှင့် ယှဉ်တွဲသော၊ စိတ်နှင့် ယှဉ်တွဲသော၊ အာရုံ ရှိသော အရာ ဖြစ်သည်၊ ထိုအရာ၌ စိတ်ကို လှည့်ဆောင်ခြင်း၊ စိတ်ညွတ်ခြင်း၊ စိတ်ကို ဆောင်ခြင်း၊ နှလုံးသွင်းခြင်း၊ စေ့ဆော်မှု၊ တောင့်တခြင်း၊ ဆုတောင်းခြင်း ရှိသလော။ ဤသို့ မဆိုသင့်ပါ… မြေသည် ကံ၏ အကျိုး ဖြစ်သည်၊ မြေသည် သာယာသော ခံစားမှုကို မဖြစ်စေတတ်သော၊ နာကျင်သော ခံစားမှုကို မဖြစ်စေတတ်သော… အာရုံ မရှိသော အရာ ဖြစ်သည်၊ ထိုအရာ၌ စိတ်ကို လှည့်ဆောင်ခြင်း… ဆုတောင်းခြင်း မရှိသလော။ ဟုတ်ပါသည်။ တွေ့ထိမှုသည် ကံ၏ အကျိုး ဖြစ်သည်၊ တွေ့ထိမှုသည် သာယာသော ခံစားမှုကို မဖြစ်စေတတ်သော၊ နာကျင်သော ခံစားမှုကို မဖြစ်စေတတ်သော… အာရုံ မရှိသော အရာ ဖြစ်သည်၊ ထိုအရာ၌ စိတ်ကို လှည့်ဆောင်ခြင်း… ဆုတောင်းခြင်း မရှိသလော။ ဤသို့ မဆိုသင့်ပါ…
