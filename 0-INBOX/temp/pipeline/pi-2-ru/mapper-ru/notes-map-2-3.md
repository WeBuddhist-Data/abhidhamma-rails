## Frame
N-vidhena = «на N видов» without «классификация» (user 2026-11-16), incl. Catubbidhena = на четыре вида, Chabbidhena = на шесть видов (the sample fix script misses these two: "bbidhena"; 5 such values remain in 1-khandhavibhango.mapped.md)
bahuvidhena X-kkhandho = совокупность X на многие виды (as dasavidhena X-kkhandho)
āyatana (heading stem) = сфера восприятия; Dhātu (heading) = элемент
āyatanā / āyatanāni / āyatanānaṃ = сферы восприятия; āyatanaṃ (of X-āyatanaṃ) = сфера
Dasāyatanā / Ekādasāyatanā / Dvādasāyatanāni = десять / одиннадцать / двенадцать сфер восприятия; N dhātuyo = N элементов
āyatanā siyā / dhātuyo siyā = сферы восприятия … иногда / элементы … иногда (as khandhā siyā)
āyatanā anidassana(ā) = сферы восприятия … невидимые; āyatanā sappaṭighā = сферы восприятия … способные к соударению; dhātuyo hetuvippayuttā = элементы не связанные с корнями (plural phrase, Russian order)
