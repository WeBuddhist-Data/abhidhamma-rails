# pi-2 (Vibhaṅga) Pāli→Russian keyword map: what pi-2 adds to the pi-1 conventions

Settled on the sample (preamble, 1-khandhavibhango). Binding base: `..\..\pi-1-ru\mapper-ru\ru-map-conventions.md` (incl. the user decision of 2026-11-14). This file lists only additions and changes. The translation file is the truth; the value is always the word or phrase found in THAT segment's Russian.

## Tooling
- `map_common_pi2_ru.py`: pi-2 paths; re-exports pi-1 `present()`, `CORE`, `CH2`, `MATRIX`, `ch2_value`, `lc`; `KH` (the pi-2 table); `value(kw, kws, table)` = your table → `KH` → pi-1 `CH2`/`MATRIX`; `hetuko_value(pali)`; `EXCEPTIONS` + `allowed_for(part)` (presence-check exceptions with reasons); `build_part`, `verify(part, allowed=...)` (also flags bare prepositions). Importing it writes nothing (no bytecode into the pi-1 folder).
- `map_sample_ru.py`: pattern for a part script: `OVERRIDES[bid][kw]` → context rules (`hetuko_value`, `CHOICES`) → `value()`. Extend `KH` only in your own script (`{**KH, ...}`); do not edit the common module.
- Helpers: `probe_pi2_ru.py PART id …` (Pāli + Russian of segments), `ctx_pi2_ru.py PART kw …` (Pāli words containing a keyword + mapped value), `lookup_prior_ru.py kw …` (values in the approved pi-1/3/4/5 maps), `kwlist_pi2_ru.py PART`.

## Frames
- `Tattha` = здесь (`Tattha katamo X?` = «Что такое здесь X?»).
- **«это называется X»**: `vuccati` / `vuccanti` = называться; `vuccati X` = называться + X in the instrumental as in the text (pi-1 style): vuccati rūpakkhandho = называться совокупностью материальной формы, vuccati vedanā atītā = называться прошлым чувством, vuccanti saṅkhārā = называться формирующими факторами.
- **Classification frames** «Классификация совокупности X на N видов» (user 2026-11-16: the value is WITHOUT «классификация»): `Ekavidhena` = по одному; `Duvidhena` = на два вида; … `Ekādasavidhena` = на одиннадцать видов; `Catuvīsatividhena` = на двадцать четыре вида; `Tiṃsavidhena` / `Tiṃsatividhena` = на тридцать видов; `Bahuvidhena` = на многие виды (lower-case `dasavidhena` of «Evaṃ dasavidhena» the same). `vidhena` alone = вид. `dasavidhena Xkkhandho` = совокупность X на десять видов (whole phrase).
- `Dukamūlakaṃ` «На основе пар»: Duka = пары, mūlakaṃ = основа; Tika = тройки. `Ubhatovaḍḍhakaṃ` «Наращивание с обеих сторон»: Ubhato = с обеих сторон, vaḍḍhakaṃ = наращивание. «(Как подробно изложена тройка благого, так … все тройки)»: kusala = благой, tike = тройка, tikā = тройки, vitthāro = подробно изложенный. «Как разобрано в разделе о материальной форме»: kaṇḍe = раздел, vibhattaṃ = разобранный.
- Headings: vibhaṅgo = разбор, bhājanīyaṃ = разбор, Suttanta = наставления, Abhidhamma = Абхидхамма, Pañhā = вопрос, Pañhāpucchakaṃ = раздел вопросов, Tikaṃ = тройки, Dukaṃ = пары, Khandha (stem) = совокупность, niṭṭhito = завершённый. Preamble: Vibhaṅga / Vibhaṅgapāḷi = подробный разбор («Подробный разбор»), pāḷi = (no direct equivalent).

## Aggregates
- khandho = совокупность, khandhā / khandhānaṃ = совокупности; rūpakkhandho = совокупность материальной формы, vedanā- = совокупность чувств, saññā- = совокупность восприятия, saṅkhāra- = совокупность формирующих факторов, viññāṇa- = совокупность сознания. Stems: rūpa = материальная форма, vedanā = чувство, saññā = восприятие, saṅkhāra / saṅkhārā = формирующие факторы, viññāṇa(ṃ) = сознание.
- Sense consciousnesses (pi-1): cakkhu- зрительное, sota- слуховое, ghāna- обонятельное, jivhā- вкусовое, kāya- осязательное, mano- умственное сознание. `Xsamphassajā` = рождённый контактом X (глаза/уха/носа/языка/тела/ума), `Xsamphassa` = контакт X; `cakkhusamphassajā saññā/vedanā/cetanā` = рождённое контактом глаза восприятие/чувство/намерение (Russian order). paccayā (cakkhusamphassapaccayā) = обусловленный.

## Past / future / present strings (2-3, 2-9, 2-15, 2-21, 2-27)
atīta- прошлый, anāgata- будущий, paccuppanna- настоящий; niruddha прекратившийся, vigata исчезнувший, vipariṇata изменившийся, abbhatthaṅgata полностью угасший, uppajjitvā после возникновения, atītaṃsena категория прошлых, saṅgahita включённый, atītaṃsena saṅgahitaṃ включённый в категорию прошлых; jāta рождённый, nibbatta появившийся, abhinibbatta полностью появившийся, pātubhūta проявившийся, uppanna возникший, uṭṭhita поднявшийся, samuṭṭhita полностью поднявшийся. A fragment from a negated form (anuppannā …) maps to the positive word, which the same segment also has. `rūpaṃ atītaṃ` = прошлая материальная форма (whole phrase, Russian order); upādāyarūpaṃ = материальная форма производная, mahābhūtā = великие элементы, bhūtā = элементы, upādāya = производный.
- «Любая X …, вся вместе, собранная воедино и обобщённая»: Yaṃ kiñci / Yā kāci / Ye keci = любой, tadekajjhaṃ = весь вместе (presence exception), abhisaññūhitvā = собранный воедино, abhisaṅkhipitvā = обобщённый.
- ajjhattaṃ = внутри себя (pi-1), paccattaṃ = собственный, pāṭipuggalika = индивидуальный, parapuggalānaṃ = другие личности. oḷārika грубый, sukhuma тонкий, hīna низший, paṇīta высший; `vedanā oḷārikā` = грубое … чувство (heading «грубое и тонкое чувство»). upādāyupādāya = в сравнении с; daṭṭhabba(ṃ/ā) = следует рассматривать; samāpannassa = войти в медитативное достижение (pi-1; presence exception «вошёл»).
- Dvandva adjectives stay plural as in the Russian: kusalābyākatā = благие и этически неопределённые, kusalākusalā = благие и неблагие, sukhadukkhā(hi) = приятные и болезненные.

## «бывает X, бывает Y» (Abhidhammabhājanīya) and the Pañhāpucchaka predicates
- `atthi` has no keyword; the predicate maps in masculine singular nominative (pi-1 matrix words), whatever the agreement in the text (feminine with «совокупность», neuter with «чувство»): kusalo благой, sahetuko / hetuko имеющий корни, ahetuko не имеющий корней, hetusampayutto связанный с корнями, phassasampayutto связанный с контактом, cittasampayutto связанный с умом, sukhindriyasampayutto связанный со способностью удовольствия, vipākadhammadhammo способный приносить результаты, pahātabbo устраняемый, pahātabbahetuko относящийся к явлениям чьи корни устраняются, ācayagāmī ведущий к накоплению, micchattaniyato предопределённо ведущий к ложному, uppādī / uppādino возникнуть (pi-1), ādhipati находящийся под главенством, kenaci viññeyyo познаваемый тем или иным видом сознания (kenaci = тот или иной, presence exception), sauttaro имеющий над собой высшее, saraṇo сопряжённый с борьбой, Xvippayutta-Yniyo = не связанный с X но подверженный Y (no comma), uttaro (of lokuttaro) = надмирский.
- Fragments: `hetuko` by Pāli context (`hetuko_value`): sa-/ahetuko → имеющий корни; only pahātabbahetuko → чьи корни; only maggahetuko → имеющий корнем. `upādāniyo`: служащий объектом цепляния, or служащий его объектом where the segment only has upādinnupādāniyo. vitakka/vitakko направленная мысль, vicāro удержание мысли, mattaṃ только, ārammaṇo объект, āsava/āsavo/āsavaṃ влечение (āsavā влечения), ogha поток, yoga ярмо, gantha/gantho узы, saṃyojana(ṃ) оковы, sukha счастье, pīti восторг.
- **Finite verb in the text → infinitive** (as pi-1 ^1-584): 2-33, 2-152, 2-153 pahātabba(ṃ/o) = устраняться; 2-33 and 2-153 `-sahagata-` = сопровождаться (X); sappaccayaṃ = иметь условия; viññeyyaṃ / viññeyyā (познаётся / познаются) = познаваться. Where the text quotes a participle («явление, сопровождаемое восторгом», 2-152) the participle is kept. Short adjectives («подвержена», «связана», «омрачена») → full adjective; «не омрачена» → не омрачённый (2-153), «неомрачённой» → неомрачённый.
- siyā = иногда; `khandhā siyā` = совокупности … иногда; na = не; vattabbo / vattabbā = определить (pi-1). `X ceva Y-sampayutto` = являющийся X и связанный с Y (pi-1 cleanup style, singular masc.): hetu ceva hetusampayutto = являющийся корнем и связанный с корнями; plural keyword keeps the plural noun: āsavā ceva āsavasampayuttā = являющийся влечениями и связанный с влечениями. `Rūpakkhandho hetuvippayutto` = совокупность материальной формы … не связанный с корнями.
- Rūpa ekaka list (2-33) = pi-1 ^1-584 values (jarābhibhūtaṃ подвластный старению, ābhibhūtaṃ подвластный, hetukaṃ имеющий корни, gāmī ведущий, āsekkhaṃ завершивший обучение, sekkha обучающийся, viññāṇehi виды сознания …); saha (of cittasahabhu) = (no direct equivalent): the «со-» prefix is not a word (user decision 2026-11-14).
- Rūpa in 2-33/2-5: Xviññeyyaṃ = познаваемый глазом/ухом/носом/языком/телом; Xindriyaṃ = способность глаза/уха/носа/языка/тела; viññatti внешнее выражение; kabaḷīkāro съедаемый, āhāro пища; sutaṃ услышанный, mutaṃ ощущённый, viññātaṃ познанный; 2-33 Aṭṭhavidhena: samphassaṃ = контакт, sukha = счастье (pi-1), dukkha = болезненный.
- Body-contact context «бывает сопровождаемым удовольствием / болью» (2-62, 2-92, 2-121): only `sahagatā/sahagataṃ` is listed there = сопровождаемый. sukhindriya(ṃ) = способность удовольствия, dukkhindriya = способность боли, domanassindriya = способность уныния (pi-1).

## Presence-check exceptions (listed in `EXCEPTIONS`)
tadekajjhaṃ (весь/вся/всё), samāpannassa (войти/вошёл), kenaci (тот или иной/тем или иным), vāyo (ветер/ветра), tejo (огонь/огня), Tika (тройки/троек), viññeyyā (познаваться/познаются).
