## The seven anusayas (pi-2 ^2-949 verbatim; anusaya = सुप्त प्रवृत्ति, feminine)

## Verbs and predicates (anusaya = feminine)
anuseti = सोई रहती है; nānuseti = सोई नहीं रहती
anusenti (anusanti, slip) = सोई रहती हैं; nānusenti = सोई नहीं रहतीं
X sānusayo = X वाला है; X sānusayā = X वाले हैं (negated: वाला नहीं है / वाले नहीं हैं)
X niranusayo = X से मुक्त है; X niranusayā = X से मुक्त हैं (negated: से मुक्त नहीं है / से मुक्त नहीं हैं)
Xṃ pajahati = X को छोड़ता है; nappajahati = X को नहीं छोड़ता; pajahanti = X को छोड़ते हैं; nappajahanti = X को नहीं छोड़ते
Xṃ tadekaṭṭhaṃ pajahati = X को उसके साथ जुड़ी होने के कारण छोड़ता है (pi-2 tadekaṭṭhaṃ = उसके साथ जुड़ा)
Tadekaṭṭhaṃ pajahati. (short answer) = उसके साथ जुड़ी होने के कारण छोड़ता है।
Suggested for 7-06+ (same pattern, not used in 7-01..7-05): parijānāti = X को पूरी तरह समझता है; na parijānāti = X को पूरी तरह नहीं समझता; parijānanti = पूरी तरह समझते हैं; X pahīno = X छोड़ी जा चुकी है; X pahīnā = छोड़ी जा चुकी हैं; X appahīno = X छोड़ी नहीं गई है; appahīnā = छोड़ी नहीं गई हैं.
"Both" form (X ca V Y ca V): anuseti: X भी सोई रहती है और Y भी सोई रहती है; sānusaya: X वाला भी है और Y वाला भी है; niranusaya: X से भी मुक्त है और Y से भी मुक्त है; pajahati: X को भी छोड़ता है और Y को भी छोड़ता है.
Two predicates without ca (X pajahati Y tadekaṭṭhaṃ pajahati) are joined with «और».
"no ca …" clause = opposite polarity of the Pāli verb (approved rule): no ca tassa Y anuseti = पर उसमें Y सोई नहीं रहती; no ca tassa Y nānuseti = पर उसमें Y सोई रहती है; no ca Y sānusayo = पर Y वाला नहीं है; no ca so tato Y pajahati = पर वहाँ वह Y को नहीं छोड़ता.

## Question frames
yassa X anuseti tassa Y anusetīti? = जिस व्यक्ति में X सोई रहती है, क्या उसमें Y सोई रहती है? (terms file pavatti frame)
yattha … tattha … = जिस स्थान पर X …, क्या वहाँ Y …?
yassa yattha … tassa tattha … = जिस व्यक्ति में जिस स्थान पर X …, क्या उसमें वहाँ Y …?
(Kha) … vā pana … = (ख) और …
Kattha X anuseti? = X कहाँ सोई रहती है?
yo X sānusayo so Y sānusayoti? = जो व्यक्ति X वाला है, क्या वह Y वाला है?
yo Xṃ pajahati so Yṃ pajahatīti? = जो व्यक्ति X को छोड़ता है, क्या वह Y को छोड़ता है?
yato … tato … = जिस स्थान के संबंध में कोई X …, क्या वहाँ वह Y …?
yo yato … so tato … = जो व्यक्ति जिस स्थान के संबंध में X …, क्या वह वहाँ Y …?
The quotative -ti is dropped; …pe… = …
(Kha) yattha vā pana…pe…? (abbreviated question) = (ख) और जिस स्थान पर…?
Short predicate answers without subject or place: Mānānusayaṃ pajahati. = अहंकार की सुप्त प्रवृत्ति को छोड़ता है।; Mānānusayena sānusayo. = अहंकार की सुप्त प्रवृत्ति वाला है। (no «कोई»)
Sentence-final "…pe…." = "…।" (" …pe…." = " …।"), e.g. Āmantā …pe…. = हाँ …।

## Answer frames
<who/where> [tassa|tesaṃ|ettha|tattha|tassa tattha|so tato|te tato|tato] X V, no ca <cor> Y V. = <who/where> X V, पर <cor> Y (opposite polarity)।
First-mention correlatives (tassa, tesaṃ, ettha, tattha, tassa tattha, tesaṃ tattha, so, te, tato, so tato, te tato) are not rendered: the person/place phrase already says it.
After "no ca": tassa = उसमें; tesaṃ = उनमें; tattha = वहाँ; tassa tattha = उसमें वहाँ; tesaṃ tattha = उनमें वहाँ; tato = वहाँ वह; so tato = वहाँ वह; te tato = वहाँ वे; (none, nominative subject) = nothing
Place-only answers with sānusaya/niranusaya/pajahati get the subject «कोई»: Rūpadhātuyā arūpadhātuyā tato X sānusayo, no ca tato Y sānusayo. = सूक्ष्म भौतिक लोक और अभौतिक लोक में कोई X वाला है, पर वहाँ वह Y वाला नहीं है।
