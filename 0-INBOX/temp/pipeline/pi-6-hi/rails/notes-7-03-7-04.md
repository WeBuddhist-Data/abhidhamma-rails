## New recurring formulas (for the alignment pass)
- Headings: Sānusayavāro / Sānusayavāra = सुप्त प्रवृत्ति वाला होने का खंड (termbase); (Gha) paṭilomapuggalo = (घ) विपरीत: व्यक्ति; (Ṅa) paṭilomaokāso = (ङ) विपरीत: स्थान; (Ca) paṭilomapuggalokāsā = (च) विपरीत: व्यक्ति और स्थान.
- Closings: Sānusayavāre anulomaṃ. = सुप्त प्रवृत्ति वाला होने के खंड में सकारात्मक।; Sānusayavāre paṭilomaṃ. = … में विपरीत।; Sānusayavāro. = सुप्त प्रवृत्ति वाला होने का खंड।
- Cycle labels: (Ekamūlakaṃ) = (एक मूल पर आधारित); (Dukamūlakaṃ) = (दो मूलों पर आधारित); (Tikamūlakaṃ) = (तीन मूलों पर आधारित); (Catukkamūlakaṃ) = (चार …); (Pañcakamūlakaṃ) = (पाँच …); (Chakkamūlakaṃ) = (छह मूलों पर आधारित).
- sānusayo / niranusayo (termbase): X-ena sānusayo = X वाला (है); X-ena niranusayo = X से मुक्त (है). Several names joined «A, B और C वाला».
- Person: (Ka) yo X sānusayo so Y sānusayoti? = (क) जो व्यक्ति X वाला है, क्या वह Y वाला है? (Kha) yo vā pana … = (ख) और जो व्यक्ति …
- Place: (Ka) yato X sānusayo tato Y sānusayoti? = (क) जिस स्थान पर कोई X वाला है, क्या वहाँ वह Y वाला है? (yato/tato take the yattha/tattha frame; «कोई» supplies the unexpressed subject.)
- Person and place: (Ka) yo yato X sānusayo so tato Y sānusayoti? = (क) जो व्यक्ति जिस स्थान पर X वाला है, क्या वह वहाँ Y वाला है?
- Answers: <person> X sānusayo, no ca Y sānusayo. = <person> X वाला है, पर Y वाला नहीं है।; <person> X ca sānusayo Y ca sānusayo. = <person> X वाला भी है और Y वाला भी है।
  <places> tato X …, no ca tato Y … = <places> कोई X वाला है, पर वहाँ वह Y वाला नहीं है। (first tato not translated)
  <person> <places> so/te tato X …, no ca so/te tato Y … = <person> <places> X वाला है, पर वह/वे वहाँ Y वाला नहीं है / वाले नहीं हैं।
  <person> sabbattha X ca … Y ca … = <person> सब जगह X … भी है और Y … भी है।
  Short answer "Mānānusayena sānusayo." = अहंकार की सुप्त प्रवृत्ति वाला है।
- Persons: Anāgāmī फिर न लौटने वाला; Arahā अर्हत्; Puthujjano साधारण व्यक्ति; Sveva puggalo / Teva puggalā वही व्यक्ति; Dve / Tayo / Cattāro puggalā = दो / तीन / चार प्रकार के व्यक्ति (pi-4 «दो प्रकार के व्यक्ति»).
- Places (every chunk keeps «में», last joined « और »): Kāmadhātuyā dvīsu / tīsu vedanāsu = इंद्रिय-सुखों के लोक की दो / तीन अनुभूतियों में (one chunk); Dukkhāya vedanāya = दुःखद अनुभूति में; rūpadhātuyā सूक्ष्म भौतिक लोक में; arūpadhātuyā अभौतिक लोक में; apariyāpanne = अस्तित्व के लोकों में न समाई हुई परिघटनाओं में; sabbattha = सब जगह.
- "Āmantā …pe…." and "Āmantā…pe…." = हाँ…। (space before …pe… dropped); "X …pe… Y" inside a question = «X… Y».
