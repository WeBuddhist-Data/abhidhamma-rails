## New recurring formulas (for the alignment pass)
- Closings: Bhāvanāvāro. = अभ्यास का खंड।; Āmantā…pe…. = हाँ…।; Dhammayamakaṃ / Indriyayamakaṃ niṭṭhitaṃ. = <chapter title> पूरे हुए।; Yamakapakaraṇaṃ niṭṭhitaṃ. = “प्रश्नों के जोड़े” ग्रंथ समाप्त।; Abhidhammapiṭake (line before ^6-9-229) = अभिधम्म पिटक में
- Cycle labels: (Xindriyamūlakaṃ) = (<faculty> पर आधारित); with a following "." = «(…)।» (^6-10-482).
- Practice verbs with an object (person subject; one verb per clause, each in its own tense; past = ergative «ने», verb invariant):
  - parijānāti: X को पूरी तरह समझता है / समझते हैं / समझा था / समझेगा / समझेंगे; neg. पूरी तरह नहीं समझता …
  - pajahati: X को छोड़ता है / छोड़ते हैं / छोड़ा था / छोड़ेगा / छोड़ेंगे; neg. नहीं छोड़ता …
  - bhāveti: X का अभ्यास करता है / करते हैं / किया था / करेगा / करेंगे; neg. अभ्यास नहीं करता … (genitive «का», as pi-2 «मार्ग का अभ्यास करता है»)
  - sacchikaroti: X का साक्षात्कार करता है …; neg. साक्षात्कार नहीं करता …
- Questions (formulas §11 with the object postposition of the verb): (क) जो व्यक्ति हितकर परिघटना का अभ्यास करता है, क्या वह हानिकर परिघटना को छोड़ता है?; past: जिस व्यक्ति ने … का अभ्यास किया था, क्या उसने …?
- Answers:
  - S O1 V1, no ca O2 V2. = S O1 V1, पर O2 <V2 flipped>। A pronoun is added after «पर» only when the case of the subject changes: present/future -> past «उसने / उन्होंने», past -> present/future «वह / वे» (as 2-02).
  - S O1ñca V1 O2ñca V2. = S O1 का/को भी V1 और [pronoun] O2 का/को भी V2।
  - Dve / Tayo / Cattāro / Pañca / Cha / Satta / Aṭṭha puggalā = दो / तीन / चार / पाँच / छह / सात / आठ व्यक्ति (ergative «… व्यक्तियों ने»)
  - Tayo maggasamaṅgino = मार्ग से युक्त तीन व्यक्ति; Dve / Tayo / Cattāro maggasamaṅgino ṭhapetvā avasesā puggalā = मार्ग से युक्त दो / तीन / चार व्यक्तियों को छोड़कर शेष व्यक्ति; Tayo maggasamaṅgino ca arahantañca ṭhapetvā … = मार्ग से युक्त तीन व्यक्तियों और अर्हत् को छोड़कर शेष व्यक्ति; Aṭṭhamakañca / Anāgāmimaggasamaṅgiñca arahantañca ṭhapetvā … = आठवें स्तर के व्यक्ति / फिर न लौटने के मार्ग से युक्त व्यक्ति और अर्हत् को छोड़कर शेष व्यक्ति
  - Aṭṭhamako = आठवें स्तर का व्यक्ति (erg. आठवें स्तर के व्यक्ति ने); Anāgāmī = फिर न लौटने वाला (erg. फिर न लौटने वाले ने); Anāgāmimaggasamaṅgī = फिर न लौटने के मार्ग से युक्त व्यक्ति
  - Yo aggaphalaṃ sacchikaroti so = जो व्यक्ति सर्वोच्च फल का साक्षात्कार करता है, वह / उसने; Yo aggaphalaṃ sacchākāsi so = जिस व्यक्ति ने सर्वोच्च फल का साक्षात्कार कर लिया है, वह / उसने (termbase sacchākāsi)
  - Ye puthujjanā maggaṃ [na] paṭilabhissanti te = जो साधारण व्यक्ति मार्ग प्राप्त [नहीं] करेंगे, वे / उन्होंने
- Variant on a numeral: Aṭṭha [satta (sī. syā. ka.)] puggalā = आठ [पाठभेद (Sī., Syā., Ka.): satta] व्यक्ति; Tayo maggasamaṅgino [tayo puggalā (pī.)] = मार्ग से युक्त तीन व्यक्ति [पाठभेद (Pī.): tayo puggalā]
