# notes-3: Āyatanayamaka (3-01 … 3-06), new recurring terms and frames
Dvādasāyatanāni = बारह इंद्रिय-क्षेत्र
cakkhāyatana … dhammāyatana = आँख / कान / नाक / जीभ / शरीर / दृश्य रूप / ध्वनि / गंध / स्वाद / स्पर्श / मन / मन के विषयों का इंद्रिय-क्षेत्र (pi-2)
cakkhu / sotaṃ / ghānaṃ / jivhā / kāyo (bare) = आँख / कान / नाक / जीभ / शरीर
rūpaṃ / saddo / gandho / raso / phoṭṭhabbo / mano / dhammo (bare) = रूप / ध्वनि / गंध / स्वाद / स्पर्श / मन / परिघटना
āyatanaṃ / āyatanā (bare) = इंद्रिय-क्षेत्र (plural agreement हैं / वे)
(Kha) āyatanā X? = (ख) क्या इंद्रिय-क्षेत्र, X हैं?
(Kha) nāyatanā na X? = (ख) जो इंद्रिय-क्षेत्र नहीं हैं, क्या वे X नहीं हैं?
X āyatanañceva Xāyatanañca. = X का इंद्रिय-क्षेत्र, इंद्रिय-क्षेत्र भी है और X का इंद्रिय-क्षेत्र भी।
Avasesā āyatanā na Y. = शेष इंद्रिय-क्षेत्र, Y नहीं हैं।
C ṭhapetvā avaseso B, na C. = C को छोड़कर शेष B, C नहीं है।
A B, na C. (A = two or three items) = A, B हैं, पर C नहीं हैं।
Dibbacakkhu paññācakkhu = दिव्य आँख और प्रज्ञा की आँख
Dibbasotaṃ taṇhāsotaṃ = दिव्य कान और तृष्णा की धारा
Sīlagandho samādhigandho paññāgandho = सदाचार की गंध, एकाग्रता की गंध और प्रज्ञा की गंध
Attharaso dhammaraso vimuttiraso = अर्थ का स्वाद, शिक्षा का स्वाद और मुक्ति का स्वाद
(Cakkaṃ bandhitabbaṃ) = (चक्र को जोड़ लेना चाहिए)
(Xāyatanamūlakaṃ) = (X के इंद्रिय-क्षेत्र पर आधारित)
Natthi. = ऐसा कोई नहीं है।
No. = नहीं। (pi-2)
sacakkhukānaṃ / acakkhukānaṃ (+ upapajjantānaṃ) = आँख के साथ / बिना आँख के (जन्म लेने वालों में); likewise sotaka कान, ghānaka नाक, rūpaka भौतिक रूप, cittaka मन
two sa-…-ka = आँख और कान के साथ; two a-…-ka = बिना आँख और कान के; mixed = आँख के साथ पर बिना कान के
Kāmāvacare / Rūpāvacare / arūpāvacare = इंद्रिय-सुखों के लोक में / सूक्ष्म भौतिक लोक में / अभौतिक लोक में
Catuvokāre = चार समूहों वाले अस्तित्व में; Catuvokārānaṃ = चार समूहों वाले अस्तित्व के प्राणियों में
Kāmāvacarānaṃ / Rūpāvacarānaṃ / arūpāvacarānaṃ = इंद्रिय-सुखों के लोक / सूक्ष्म भौतिक लोक / अभौतिक लोक के प्राणियों में
kāmāvacaraṃ upapajjantānaṃ = इंद्रिय-सुखों के लोक में जन्म लेने वालों में
kāmāvacarā cavantānaṃ = इंद्रिय-सुखों के लोक में मरने वालों में
Kāmāvacare parinibbantānaṃ = इंद्रिय-सुखों के लोक में पूर्ण निर्वाण पाने वालों में
Arūpe pacchimabhavikānaṃ = अभौतिक लोक में अंतिम जन्म वालों में
Pacchimabhavikānaṃ (X-ṃ) upapajjantānaṃ = (X में) अंतिम जन्म लेने वालों में
Sabbesaṃ upapajjantānaṃ = सभी जन्म लेने वालों में
Itaresaṃ + group = बाकी + group (बाकी आँख के साथ जन्म लेने वालों में); Itaresaṃ tesaṃ = बाकी सबमें
Ye (ca) X upapajjitvā parinibbāyissanti tesaṃ = (और) जो X में जन्म लेकर पूर्ण निर्वाण पाएँगे, उनमें
… parinibbāyissanti tesaṃ upapajjantānaṃ / cavantānaṃ = …, उनमें से जन्म लेने वालों में / मरने वालों में
rūpāvacaraṃ arūpāvacaraṃ (upapajjitvā) = सूक्ष्म भौतिक लोक या अभौतिक लोक में
several beings/places in a row = "A में, B में और C में"; several locatives in one group = "A और B में"
yo X parijānāti so Y parijānāti? = जो X को पूरी तरह समझता है, क्या वह Y को पूरी तरह समझता है?
parijānittha (question) = जिसने … को पूरी तरह समझा था, क्या उसने …?
parijānissati = पूरी तरह समझेगा
Aggamaggasamaṅgī = सर्वोच्च मार्ग से युक्त व्यक्ति
Ye maggaṃ paṭilabhissanti = जो मार्ग प्राप्त करेंगे
ye ca puthujjanā maggaṃ na paṭilabhissanti = और जो साधारण व्यक्ति मार्ग प्राप्त नहीं करेंगे
avasesā puggalā = शेष व्यक्ति
Uppādavāro. / Nirodhavāro. / Uppādanirodhavāro. (closing) = उत्पन्न होने का खंड। / समाप्त होने का खंड। / उत्पन्न होने और समाप्त होने का खंड।
Pavattivāro niṭṭhito. = प्रक्रिया का खंड पूरा हुआ।
Pariññāvāro. = पूरी तरह समझने का खंड।
Suddhāyatanavāro = केवल इंद्रिय-क्षेत्रों का खंड; Suddhāyatanamūlacakkavāro = केवल इंद्रिय-क्षेत्रों पर आधारित चक्र का खंड
Paccuppannavāro (unnumbered, pariññā) = वर्तमान का खंड (etc. without the number)
yassakaṃ / yatthakaṃ / yassayatthakaṃ (notes) = व्यक्ति वाला खंड / स्थान वाला खंड / व्यक्ति और स्थान वाला खंड
multi-variant bracket = [पाठभेद: <Pāli> (Syā.), <Pāli> (Sī., Ka.)] (pi-5 style)
