### Pavattivāra: person / place frames [new]
(Ka) yassa X V tassa Y V-ti? = (क) जिस व्यक्ति में X V, क्या उसमें Y V?
(Kha) yassa vā pana Y V tassa X V-ti? = (ख) और जिस व्यक्ति में Y V, क्या उसमें X V?

(Kha) yattha vā pana … = (ख) और जिस स्थान पर …
(Ka) yassa yattha X V tassa tattha Y V-ti? = (क) जिस व्यक्ति में जिस स्थान पर X V, क्या उसमें वहाँ Y V?
(Kha) yassa vā pana yattha … tassa tattha … = (ख) और जिस व्यक्ति में जिस स्थान पर …, क्या उसमें वहाँ …?
Answers:
<beings> tesaṃ X V, no ca tesaṃ Y V. = <beings>-वालों में X V, पर उनमें Y (V with the opposite polarity)।
<beings> tesaṃ tattha X V, no ca tesaṃ tattha Y V. = <beings>-वालों में वहाँ X V, पर उनमें वहाँ Y (opposite polarity)।
<place> tattha X V, no ca tattha Y V. = <place> X V, पर वहाँ Y (opposite polarity)।
<beings/place> … X ca V Y ca V. = … X भी V और Y भी V।
"no ca … V" is always rendered by flipping the polarity: no ca tesaṃ Y uppajjati = पर उनमें Y उत्पन्न नहीं होता; no ca tesaṃ Y nuppajjati = पर उनमें Y उत्पन्न होता है.
tesaṃ = उनमें; tāsaṃ (women) = उनमें; tattha = वहाँ; tassa = उसमें; itaresaṃ = बाकी सबमें

uppajjati = उत्पन्न होता है; nuppajjati / na uppajjati = उत्पन्न नहीं होता [pi-1/2 उत्पन्न होना]
uppajjittha = उत्पन्न हुआ था; nuppajjittha / na uppajjittha = उत्पन्न नहीं हुआ था
uppajjissati = उत्पन्न होगा; nuppajjissati / na uppajjissati = उत्पन्न नहीं होगा
nirujjhati = समाप्त होता है; na nirujjhati = समाप्त नहीं होता [pi-1/2 समाप्त होना]
nirujjhittha = समाप्त हुआ था; na nirujjhittha = समाप्त नहीं हुआ था
nirujjhissati = समाप्त होगा; na nirujjhissati = समाप्त नहीं होगा
Feminine singular subject (क्षमता, सुप्त प्रवृत्ति): उत्पन्न होती है / उत्पन्न नहीं होती; उत्पन्न हुई थी / उत्पन्न नहीं हुई थी; उत्पन्न होगी / उत्पन्न नहीं होगी; समाप्त होती है / समाप्त नहीं होती; समाप्त हुई थी / समाप्त नहीं हुई थी; समाप्त होगी / समाप्त नहीं होगी
Plural subject (uppajjanti …, masculine): उत्पन्न होते हैं / उत्पन्न नहीं होते; उत्पन्न हुए थे / उत्पन्न नहीं हुए थे; उत्पन्न होंगे / उत्पन्न नहीं होंगे; समाप्त होते हैं / समाप्त नहीं होते; समाप्त हुए थे; समाप्त होंगे
Participles: uppajjamāna = उत्पन्न होता हुआ; uppanna = उत्पन्न हो चुका [pi-1/2]; nirujjhamāna = समाप्त होता हुआ; niruddha = समाप्त हो चुका; atikkantakāla = जिसका समय बीत चुका [new]
Anusaya / practice verbs: anuseti = सोई रहती है (anusaya = सुप्त प्रवृत्ति, fem.) [pi-2 सोया रहना]; nānuseti = सोई नहीं रहती; pajahati = छोड़ता है; nappajahati = नहीं छोड़ता; pahīna = छोड़ा जा चुका [pi-2]; appahīna = छोड़ा न गया [new]; parijānāti = पूरी तरह समझता है [pi-2]; bhāveti = अभ्यास करता है [pi-1/2]; sacchikaroti = साक्षात्कार करता है [pi-1/2]; past -ittha = …ा था (e.g. parijānittha = पूरी तरह समझा था), future -issati = …ेगा

## Key terms
dhamma = परिघटना [pi-1/2]; kusala / akusala = हितकर / हानिकर [pi-1/2]; abyākata = नैतिक रूप से अनिर्धारित [pi-1/2]
nāma (mentality) = मानसिक पक्ष [pi-1/2]; mūla / hetu (as a root) = मूल [pi-1/2] (but hetu = हेतु in the ten-names list)
khandha = समूह; rūpakkhandha = भौतिक रूप का समूह; vedanā = अनुभूति; saññā = पहचान; saṅkhārā = मानसिक रचनाएँ; viññāṇa = चेतना [pi-1/2]
rūpa (matter) = भौतिक रूप [pi-1/2]; rūpa (bare word in the paṇṇattivāra pair) = रूप [new]
saṅkhāra (bare word, and Saṅkhārayamaka) = रचना; kāyasaṅkhāra = शरीर की रचना [pi-2]
āyatana = इंद्रिय-क्षेत्र; dhātu = तत्व; sacca = सत्य; citta = मन; indriya = क्षमता; anusaya = सुप्त प्रवृत्ति [pi-1/2]
puggala = व्यक्ति [pi-1/2]; okāsa = स्थान [new]
uddesa = सूची [pi-4/5]; niddesa = व्याख्या [pi-1/2]; mātikā = मूल सूची [pi-1/2]
paṇṇatti = शब्दावली [new]; padasodhana = शब्दों की जाँच [new]; cakka = चक्र [pi-2]; suddha- = केवल [new]; pavatti = प्रक्रिया [new]
anuloma / paccanīka = सकारात्मक / नकारात्मक [new]
ṭhapetvā = छोड़कर; avasesā = शेष; ekato = एक साथ; sahajāta = के साथ उत्पन्न [pi-1/2]
