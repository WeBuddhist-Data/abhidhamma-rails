## Termbase doubts (termbase not changed)
1. **tehi dhammehi has no entry** (H3). The 138 «ထိုသဘောတရားတို့နှင့်» keep «တို့», while the items and te dhammā have «များ» in the same segments. The gloss of dhammehi vippayuttā («standing apart from such states») could be read as covering the tehi clause too. If the user wants one marker, «ထိုသဘောတရားများနှင့်», a single generator-frame patch would change all 138 uniformly: the saṅgaha (ch5 / 6), sampayutta (ch10) and vippayutta (ch8 / 11) frames together, not only the vippayutta frames. Not done: no termbase term decides it.
2. **No own entries for the privatives** Anuppannā / Anuppannehi «မဖြစ်ပေါ်သေးသော» and apariyāpannā / apariyāpannehi «ဘဝဘုံတို့၌ အကျုံးမဝင်သော». They are covered only through the decision reasons, as fragments of uppannā / uppannehi / pariyāpanna, and are the 5 ARTEFACT rows.
3. **ādi** has only «စသည်». The attributive «စသည့်» before a noun (Phassādisattakaṃ) is the same word (INFLECTION row); listing it would make the entry complete.
4. **maccu across books:** pi-3 «သေခြင်း» (approved as built) vs pi-2's review term «သေဆုံးခြင်း» (pi-2 synonym list). No shared sentence, so identity is not affected. It is a deliberate cross-book difference.
5. **The loose adherence test** passes dukkha's fragment «နာကျင်» (adukkhamasukha «မနာကျင်», 5 uses) only through the stemming of «နာကျင်မှု». The decision names this fragment, so it is not a miss, but the test does not separate it.
