## Formulas
atītaṃ / anāgataṃ / paccuppannaṃ (neuter, as subject) = quá khứ / tương lai / hiện tại [new]
atītaṃ rūpaṃ / atītaṃ viññāṇaṃ / atītā vedanā / atītā saññā / atītā saṅkhārā = vật chất quá khứ / thức quá khứ / cảm giác quá khứ / tri giác quá khứ / các tạo tác quá khứ (same pattern with tương lai, hiện tại) [new]
khandhā / khandho = các khối / khối [core]
khandhā dhātu āyatanaṃ (āyatananti) = các khối, yếu tố, lĩnh vực nhận biết [core terms]
Xti? (X khandhāti, X āyatananti, X dhātūti) = Có phải X là các khối / lĩnh vực nhận biết / yếu tố không? [sample Q]
X atthīti? / X natthīti? = Có phải X tồn tại không? / Có phải X không tồn tại không? [sample atthi]
X khandhā X atthīti? = Có phải X là các khối, X tồn tại không? (no «và» added)
X āyatanaṃ…pe… (no question, after …pe…) = X là lĩnh vực nhận biết…
atītānāgatā khandhā dhātu āyatanaṃ natthi cete = các khối, yếu tố, lĩnh vực nhận biết quá khứ và tương lai, chúng không tồn tại [new; cete = ca ete per aṭṭhakathā ^5-231]
[khandhadhātuāyatananti (syā.)] = [khác chính tả (Syā.): khandhadhātuāyatananti] (compound vs separate words)
