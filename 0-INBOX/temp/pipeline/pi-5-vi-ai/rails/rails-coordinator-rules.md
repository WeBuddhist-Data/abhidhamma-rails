# pi-5 rails: coordinator rules (binding for every chapter agent, 2026-11-21)

These extend vi-rails-brief.md. They carry over the lessons of the zero-shot run (the user-approved harmonise decisions), expressed as rules, not wording.

- "Āmantā?" (with a question mark) = «Đúng vậy?» as written.
- ruhiruppādaka = «kẻ làm chảy máu» (nothing added).
- punabbhava = «sự hiện hữu mới» (pi-2); upapatti / upapajjati = tái sinh.
- Vagga close: "Tassuddānaṃ –" = one fixed string for every vagga (set it in the first vagga chapter you do, then copy; if another rails chapter is finished, copy its string byte for byte); the closing vagga name line = the vagga heading wording with a full stop; each kathā name in its heading, its closing line and the uddāna uses the same wording; a kathā name already used in an earlier finished chapter keeps that wording.
- Set in rails ch9 (copy byte for byte): "Tassuddānaṃ –" = «Tóm tắt của chương này –»; the closing vagga line "<N>vaggo" = «Chương thứ N.» (Paṭhamavaggo «Chương thứ nhất.»); "Mahāvaggo." = «Chương lớn.»; natthi «không tồn tại» beside atthi «tồn tại» in the existence theses (ch5-ch9).
- Set in rails ch13 (copy byte for byte): "Mahāpaṇṇāsako." = «Nhóm năm mươi lớn.»; "Tassāpi uddānaṃ –" = «Tóm tắt của nhóm này nữa –»; "Dutiyo / Tatiyo / Catuttho paṇṇāsako." = «Nhóm năm mươi thứ hai. / thứ ba. / thứ tư.».
- Set in rails ch18 (copy byte for byte): "Tassuddānaṃ –" on the line right after a fifty-group close ("Dutiyo / Tatiyo / Catuttho paṇṇāsako.", "Khuddako aḍḍhapaṇṇāsako.") = «Tóm tắt của nhóm này –» (it sums up the group, not the chapter); after a vagga close it stays «Tóm tắt của chương này –». gati in a kathā name / uddāna «cõi tái sinh» (ch16 «Bàn về sáu cõi tái sinh»).
- saṃvara = «sự thu thúc» everywhere (user-approved), also inside phrases («sự (không) thu thúc năng lực mắt …»), even where a termbase phrase entry still says «sự phòng hộ» (set in ch20; the termbase is aligned later).
- Fifty-group closes ("Mahāpaṇṇāsako.", "Dutiyo / Tatiyo / … paṇṇāsako.", "Tassāpi uddānaṃ –"): one frame for all; copy from the first finished chapter that has one.
- Where two finished rails chapters disagree, follow the pi-1 … pi-4 wording if there is one, otherwise the sample, otherwise the earlier chapter, and list the clash in your notes.
- Where a pi-1 / pi-2 fixed formula renders a word differently from the termbase for this book, the termbase wins; list it.
