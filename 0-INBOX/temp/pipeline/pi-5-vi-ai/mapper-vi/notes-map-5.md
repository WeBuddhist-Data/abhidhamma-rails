# notes-map-5 (5-sabbamatthitikatha): new recurring keywords and values
sabbaṃ = tất cả (Sabbamatthī «tất cả đều tồn tại»); Sabbena (sabbena sabbaṃ) = theo mọi cách
headings: yutti = Lập luận, vāda = học thuyết, kāla = thời gian, sodhanā = Sự làm sáng tỏ (sodhana = sự làm sáng tỏ as written), pada = thuật ngữ, samodhāna = sự gộp chung, sādhanaṃ = Chứng cứ, arahanta = bậc A-la-hán
atīta / anāgata / paccuppanna as the NOUN («quá khứ tồn tại») = quá khứ / tương lai / hiện tại; as the attribute = thuộc quá khứ … («thức thuộc quá khứ», pi-2); heading compounds = «<X> quá khứ» (atītañāṇa = hiểu biết quá khứ, atītakkhandha = khối quá khứ, atītacakkhu = mắt … quá khứ)
«<subject> <predicate>» keywords (… atthi / nvatthi / jahati / na jahati / niccaṃ / aniccaṃ / niruddhaṃ / jātaṃ / ajātaṃ / nirujjhamānaṃ) = subject first, contiguous else « … » («rūpaṃ atthi» = vật chất … tồn tại, not the closest «tồn tại … vật chất» of the next clause); map_5_vi.subject_predicate
atthi = tồn tại; nvatthi = không tồn tại; Atītaṃ atthi = quá khứ tồn tại; atītaṃ niruddhaṃ = quá khứ đã chấm dứt
sañjātaṃ = đã sinh thành; atthaṅgataṃ = đã biến mất; ajātaṃ (own a-) = chưa sinh ra
niccaṃ = thường còn, dhuvaṃ = bền vững, sassataṃ = trường tồn, adhuvaṃ = không bền vững, aniccaṃ = vô thường; jahati = dứt bỏ, na jahati = không dứt bỏ (ch4)
nvātītaṃ atītaṃ = cái không phải là quá khứ là quá khứ (also nvānāgataṃ anāgataṃ, no paccuppannaṃ paccuppannaṃ)
participles with «khi»: nirujjhamānaṃ = khi đang chấm dứt, rajjamānaṃ = khi đang được nhuộm, paññāpayamāno = khi mô tả; katvā = khi coi (sample karitvā «khi xem»)
samabhāge = ngang nhau; tajjāte = cùng một loại; vatthaṃ = vải; odātaṃ = trắng (KV «màu trắng» where the text says so)
yogaṃ (ayogaṃ) = sự kết hợp; ottappaṃ (anottappaṃ) = biết ghê sợ tội lỗi; hetuka (ahetukavādā) = có nguyên nhân; paṭikuṭṭhā (appaṭikuṭṭhā) = bị … phản đối; sokaṃ (asokaṃ) = sầu muộn
anottappī = không biết ghê sợ tội lỗi (5-292) / sự không biết ghê sợ tội lỗi (5-291 saanottappī «có sự …», override); diṭṭhiko (sadiṭṭhiko) = có quan điểm
vatthuṃ = chỗ dựa; dhammaṃ = đối tượng của ý (the āyatana list); ñāṇaṃ = hiểu biết (no «sự» in the text); ñāṇena ñāṇakaraṇīyaṃ = hiểu biết … việc của hiểu biết; parijānāti = hiểu biết trọn vẹn; pajahati = dứt bỏ; sacchikaroti = tự mình chứng nghiệm (ch4)
Arahato = bậc A-la-hán; Anāgāmissa = bậc không trở lại; Sotāpannassa = bậc vào dòng; Puthujjanassa = người phàm phu (ch4 puthu / jana)
māno = sự kiêu mạn (the text writes «sự»); oḷāriko = ở dạng thô; aṇu (aṇusahagato) = nhỏ nhiệm, atīto aṇusahagato = ở dạng nhỏ nhiệm thuộc quá khứ; apāya = cõi khổ, gamanīyo = dẫn đến; vata = nghi thức in sīlabbata (override ^5-291, as ch4)
body: hatthā / hattha = bàn tay, pādā = bàn chân, pabbā = khớp, kucchi = bụng; ādāna cầm lên, nikkhepanaṃ đặt xuống, abhikkama đi tới, samiñjana co, pasāraṇaṃ duỗi; jighacchā sự đói, pipāsā sự khát
chedana / bhedana = bị cắt / bị đập vỡ; sādhāraṇo = thứ chung; kākehi quạ, gijjhehi kền kền, kulalehi diều hâu; visaṃ chất độc, satthaṃ dao kiếm (not pi-1 «thanh gươm»), aggi lửa
bandhituṃ = trói; bandhanena = sự giam giữ; bandhanehi = dây trói; addu cùm, rajju dây thừng, saṅkhalika xích sắt, gāma làng, nigama thị trấn, nagara thành phố, kaṇṭha cổ, pañcamehi thứ năm
catupaññāsa = năm mươi bốn; chasaṭṭhi = sáu mươi sáu; rājūnaṃ = vua; sammukhībhāvo = cùng hiện diện đối mặt nhau
sammuddho / sammāsammuddho (Pāli slip for sambuddho, rendered as meant) = bậc Tự Giác Ngộ / bậc Tự Giác Ngộ Hoàn Toàn; sambuddhānaṃ / sammāsambuddhānaṃ the same
bahiddhā = ở bên ngoài bản thân (pi-1 / pi-2; KV «bên ngoài» only for 5-228)
niruttipathā …: pathā = phạm vi, adhivacana = tên gọi, nirutti = cách diễn đạt, saṅkhā = cách gọi, paññatti = sự định danh; saṅkiṇṇa = lẫn lộn, asaṅkiṇṇā = không lẫn lộn, asaṅkiṇṇapubbā = trước đây chưa từng lẫn lộn
samaṇehi sa-môn, brāhmaṇehi bà-la-môn, viññūhi có trí; vādā = người theo học thuyết (as vādī); natthika = hư vô; vassa = Vát-sa; garahitabbaṃ = nên chê trách
nindā / byārosa / upārambha = bị chê bai / bị công kích / bị chỉ trích; bhayā = sợ
phagguno = Phả-cầu-na; nandako = Nan-đa-ka; buddhe = vị Phật; atīte = thuộc quá khứ; papañce sự suy diễn lan man, vaṭume lối mòn, vaṭṭe vòng xoay, vītivatte đã vượt qua; paññāpeyya = có thể mô tả được
cakkhuṃ / jivhā = con mắt / cái lưỡi where the text has the classifier (override ^5-296), else mắt / lưỡi
kabaḷīkāre thức ăn, āhāre dưỡng chất, nandī sự thích thú, patiṭṭhitaṃ được thiết lập, virūḷhaṃ phát triển, avakkanti sự hình thành, nāmarūpassa phần tinh thần và vật chất, jarāmaraṇaṃ sự lão hóa và sự chết, sañcetanāya chủ ý (manosañcetanāya)
