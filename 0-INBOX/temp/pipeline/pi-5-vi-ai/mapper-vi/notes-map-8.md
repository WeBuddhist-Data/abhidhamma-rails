# notes-map-8 (8-satipatthanakatha): new recurring keywords and values
satipaṭṭhāna / satipaṭṭhānaṃ / satipaṭṭhānā = sự thiết lập tỉnh thức; paṭṭhāna / paṭṭhānaṃ / paṭṭhānā = sự thiết lập (pi-2); sati = tỉnh thức inside «sự thiết lập tỉnh thức» only (heading), else sự tỉnh thức (pi-1 / pi-2)
sabbe dhammā satipaṭṭhānā «tất cả các hiện tượng là các sự thiết lập tỉnh thức»: dhammā satipaṭṭhānā = hiện tượng là các sự thiết lập tỉnh thức (inner «là các» kept, as notes-map-6); dhammā sati = hiện tượng là sự tỉnh thức; Sati satipaṭṭhānā = sự tỉnh thức là sự thiết lập tỉnh thức
kāyagatāsati / kāyagatāsatiṃ = sự tỉnh thức hướng về thân; gatā (member) = hướng về; ānāpāna (ānāpānassati) = hơi thở vào và hơi thở ra
X-ānussati «sự nhớ lại X»: anussati = sự nhớ lại; buddha Đức Phật, dhamma Giáo Pháp, sīla giới hạnh, cāga sự rộng lượng, devatā chư thiên, maraṇa sự chết, upasama sự lắng dịu
ekāyana / ekāyano = duy nhất («con đường duy nhất»); khaya = sự diệt tận (notes-map-4); māno = sự kiêu mạn, ottappaṃ (of anottappaṃ) = biết ghê sợ tội lỗi (notes-map-2)
ārabbha = lấy … làm đối tượng where no ārammaṇa keyword claims «đối tượng» («lấy tất cả các hiện tượng làm đối tượng mà đứng vững»; pi-1 «lấy … làm» beside ārammaṇaṃ); santiṭṭhati = đứng vững; Sabbaṃ dhammaṃ = mọi hiện tượng (sabbaṃ = mọi); samohitā = được kết hợp
sutta quotes: amataṃ sự bất tử, paribhuñjanti thọ hưởng, paṭilabhanti có được, āsevanti thực hành, bhāventi tu tập, bahulīkaronti làm đi làm lại; visuddhiyā được thanh lọc, samatikkamāya vượt qua, atthaṅgamāya làm biến mất, adhigamāya chứng đắc («để» frame dropped); paridevānaṃ sự than khóc, dukkha (dukkhadomanassānaṃ) sự khó chịu; ñāyassa = phương pháp đúng đắn; yadidaṃ = tức là
the seven treasures: ratanassa / ratanānaṃ = báu vật; rañño = vị vua, cakkavattissa = chuyển luân, rañño cakkavattissa = vị vua chuyển luân («vị» kept as the text writes it; sample «vua» where the text has no «vị»); cakka bánh xe, hatthi voi, assa ngựa, maṇi ngọc, itthi người nữ, gahapati gia chủ, pariṇāyaka vị cố vấn
bojjha = giác ngộ, aṅga = chi phần, bojjhaṅga / sambojjhaṅga = chi phần giác ngộ, satisambojjhaṅga(-o) = chi phần giác ngộ là sự tỉnh thức (pi-2); balā = sức mạnh (map_2_vi); arahato = bậc A-la-hán, sambuddhassa (member) = bậc Tự Giác Ngộ, sammāsambuddhassa = bậc Tự Giác Ngộ Hoàn Toàn
