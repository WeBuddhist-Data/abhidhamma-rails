# pi-5 keyword map: coordinator rules (binding for every chapter agent, added 2026-11-21)

These extend vi-mapper-brief.md and vi-map-conventions-pi5.md.

- Subject + predicate keywords ("rūpaṃ atthi", "viññāṇaṃ jahati", "rāgo atthi" …): subject first, as the Vietnamese clause has it («vật chất … tồn tại»), never a span that joins the verb to the next clause's subject. Reuse map_5_vi.subject_predicate.
- A Vietnamese word that stands only in the translated note after the colon of a variant bracket (e.g. «cần tham khảo Chú giải», «hợp lý hơn») is a listed exception in ALLOWED with the reason, as map_5_vi.py does.
- Participles keep «khi» / «trong khi», gerunds «sau khi» (map 4, map 5); fragments that lost a negative prefix take the positive part.
- vata = «nghi thức» inside sīlabbata, «chắc chắn» in «vata re».
- One keyword with two renderings inside one segment: take the first, list it in your notes as CROSSCHECK.
- Optative verbs (-eyya): the bare verb, «có thể» is frame (pi-4 jāneyya; map 12). Map 5's «có thể … được» is aligned at the cross-check.
- Inner connective words that sit between the members in the text («là», «nhờ», «về», «rằng») stay in a two-word value (sample rule).
- Run python with -B (no __pycache__).
