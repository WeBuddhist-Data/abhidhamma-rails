## New recurring formulas (for the alignment pass)
- (evaṃ gaṇetabbaṃ) = (इस तरह गिनना चाहिए); Evaṃ … vibhajitabbā = इस तरह … का विश्लेषण करना चाहिए.
- iminā kāraṇena = इस तरीके से; X pañhā kātabbā = X प्रश्न करने चाहिए; paripuṇṇaṃ = परिपूर्ण.
- X-sadisaṃ (another triad) = «X वाले तीन के वर्गीकरण के समान»; anulomasahajātasadisaṃ = सकारात्मक क्रम के
  सह-उत्पत्ति-कारण के समान; nahetusadisaṃ = मूल-कारण के अभाव के समान; anantarasadisaṃ = निकटता-कारण के समान.
- Xmūlake (item series) = «X परिघटना से शुरू होने वाली शृंखला में» (termbase).
- ahetukaṃ X ekaṃ khandhaṃ = «मूल से रहित, X एक समूह»; one-word X after एक (एक हीन समूह), longer X before it.
- Two adjectives on one noun (object + time, ārammaṇa + item) joined by a comma: «अतीत के विषय वाले, अतीत के समूहों».
- Lists of visible-triad adjectives: «A, B तथा C» (तथा before the last when a member already has «और»).
- saddhaṃ upanissāya dānaṃ deti … = «श्रद्धा के प्रबल आश्रय से दान देता है, सदाचार ग्रहण करता है, उपवास-व्रत का
  पालन करता है»; mānaṃ jappeti, diṭṭhiṃ gaṇhāti = अहंकार पालता है, दृष्टि ग्रहण करता है; X patthayamāno = X की
  कामना करते हुए; vaṇṇasampadā = रंग-रूप की संपन्नता; mātaraṃ jīvitā voropeti = माता की जान लेता है.
- aniccānupassanā, dukkhānupassanā, anattānupassanā = अनित्यता का अवलोकन, दुःख का अवलोकन और आत्मा से रहित होने का
  अवलोकन (the last two built from members: termbase has only the first).
- paro = दूसरा व्यक्ति; atītaṃ viññāṇañcāyatanaṃ = अतीत के अनंत चेतना के क्षेत्र (पर); paṭisandhicitta =
  पुनर्जन्म का मन; vuṭṭhāna with adjective = «X वाले बाहर आने के लिए».
- pañcavokāre = पाँच समूहों वाले अस्तित्व में; niṭṭhānapadā = समाप्ति के पद (pariyosānapadā = अंतिम पद).
- (avipākaṃ-4) / (savipākaṃ-5) = (कर्म-फल-कारण रहित-4) / (कर्म-फल-कारण सहित-5).
- Nahetutikaṃ = मूल-कारण के अभाव के साथ तीन कारणों का मेल; Hetusabhāgaṃ = मूल-कारण के साथी कारण.
- "बाद में उत्पन्न, X समूह" takes a comma when X itself is «उत्पन्न …» or long.
