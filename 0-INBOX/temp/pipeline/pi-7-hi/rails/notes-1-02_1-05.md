## Termbase misfits
- uppādeti (उत्पन्न करना) in «tathāgatassa lohitaṃ uppādeti»: «खून उत्पन्न करता है» is not Hindi; wrote «खून बहाता है».
- karoti (करना) in «ekāgārikaṃ karoti»: «डाका करना» unidiomatic; wrote «एक ही घर में डाका डालता है».
- kātabbā / kātabbaṃ: «शामिल करना चाहिए» (harmonise-notes allow it with this object).
