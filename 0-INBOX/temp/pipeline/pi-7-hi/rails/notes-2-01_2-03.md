## New recurring formulas (for the alignment pass)

### Triad items (pi-1 1-matika wording; adjective agrees: वाला / वाले / वाली)
- savitakkasavicāra = आरंभिक विचार और सतत विचार वाला
- avitakkavicāramatta = आरंभिक विचार से रहित, केवल सतत विचार वाला (pi-1 comma kept)
- avitakkaavicāra = आरंभिक विचार और सतत विचार दोनों से रहित
- pīti- / sukha- / upekkhāsahagata = उल्लास / सुख / समभाव के साथ होने वाला
- dassanena / bhāvanāya pahātabba = सत्य-दर्शन से / मानसिक अभ्यास से छोड़ा जाने वाला
- nevadassanena nabhāvanāya pahātabba = न सत्य-दर्शन से, न मानसिक अभ्यास से छोड़ा जाने वाला
- Frames follow the kusalattika pattern: «X परिघटना और Y परिघटना पर निर्भर होकर X और Y परिघटनाएँ …»;
  dative item lists «X परिघटना और Y परिघटना के लिए». Coordinated adjectives on one noun: «उल्लास के साथ होने वाले
  और सुख के साथ होने वाले तीन समूह».
- Item before «ekaṃ khandhaṃ»: «X वाले एक समूह पर निर्भर होकर» (number after a participial item, as pañcaviññāṇasahagata).
- ahetuka / vipāka + item: «मूल से रहित, X वाले …», «कर्म-फल रूपी, X वाले …» (comma, as sample ahetukaṃ vipākābyākataṃ).

### Frames and bodies
- vitakko / vicāro = आरंभिक विचार / सतत विचार; X-ā cetanā = X वाला इरादा; X-ā adhipati = X वाली प्रधानता.
- Sampayuttavāra frame «X dhammaṃ sampayutto Y dhammo» = «X परिघटना से जुड़कर Y परिघटना» (formulas file).
- Chains with interleaved notes/numbers: the verb goes after the last condition (sample rule), e.g.
  «… आश्रय-कारण से… (मूल-कारण के समान) प्रबल आश्रय-कारण से… तीन… कर्म-कारण से उत्पन्न होती है (…)».
- Bare stems in a chain (āhāra…pe… indriya… jhāna…) = the ablative «आहार-कारण से… क्षमता-कारण से…».
- Short vippayutta sentences extended: «Khandhe ca vicārañca vippayuttapaccayā» = «समूहों और सतत विचार पर अलगाव-कारण से».

### Pañhāvāra prose
- X-ena cittena = «X वाले मन से»; dānaṃ datvā … taṃ X-ena cittena paccavekkhati = «S.GIFT उस पर X वाले मन से पुनः विचार करता है».
- X-ā jhānā vuṭṭhahitvā, maggā vuṭṭhahitvā, phalā vuṭṭhahitvā = «X वाले ध्यान से उठकर, मार्ग से उठकर, फल से उठकर».
- ariyā X-e pahīne kilese = «आर्य … X वाले, छोड़े जा चुके मन के क्लेशों पर»; ariyā = आर्य.
- OBJ aniccato … vipassanti assādenti abhinandanti = «OBJ को S.ANICCA अंतर्दृष्टि से देखते हैं, उनका रस लेते हैं, उनमें आनंद लेते हैं».
- OBJ garuṃ katvā assādeti abhinandati = «OBJ को महत्व देकर उसका/उनका रस लेता है, उसमें/उनमें आनंद लेता है».
- taṃ ārabbha vitakko uppajjati = «उसे विषय बनाकर आरंभिक विचार उत्पन्न होता है»; X-e khandhe ārabbha Y-ā khandhā uppajjanti =
  «X वाले समूहों को विषय बनाकर Y वाले समूह उत्पन्न होते हैं».
- cuticitta / upapatticitta / bhavaṅga / āvajjanā / vuṭṭhāna / anuloma (moment) / parikamma / phalasamāpatti =
  मृत्यु का मन / जन्म का मन / जीवन-धारा / मन को विषय की ओर मोड़ना / बाहर आना / अनुरूपता / प्रारंभिक तैयारी / फल की ध्यान-अवस्था.
- X-assa jhānassa parikammaṃ = «X वाले ध्यान की प्रारंभिक तैयारी»; dutiyassa jhānassa parikammaṃ dutiye jhāne vicārassa =
  «दूसरे ध्यान की प्रारंभिक तैयारी दूसरे ध्यान में सतत विचार के लिए».
- kusalākusalaṃ / kiriyaṃ (moment) = «हितकर और हानिकर मन» / «केवल क्रिया रूपी मन» (sample adds मन to kiriya).
- vipākamanoviññāṇadhātu / kiriyamanoviññāṇadhātuyā / vipākamanodhātuyā = कर्म-फल रूपी मन की चेतना का तत्व /
  केवल क्रिया रूपी मन की चेतना के तत्व के लिए / कर्म-फल रूपी मन के तत्व के लिए; pañcannaṃ viññāṇānaṃ = पाँच प्रकार की चेतना के लिए.
- Strong support: X-aṃ saddhaṃ upanissāya Y-ena cittena dānaṃ deti = «X वाली श्रद्धा के प्रबल आश्रय से Y वाले मन से दान देता है»;
  dānaṃ deti, sīlaṃ samādiyati, uposathakammaṃ karoti, jhānaṃ / vipassanaṃ / maggaṃ / abhiññaṃ / samāpattiṃ uppādeti, mānaṃ jappeti,
  diṭṭhiṃ gaṇhāti = दान देता है, सदाचार ग्रहण करता है, उपवास-व्रत का पालन करता है, ध्यान / अंतर्दृष्टि / मार्ग / उच्च ज्ञान /
  ध्यान-अवस्था उत्पन्न करता है, अहंकार पालता है, दृष्टि ग्रहण करता है.
  Crime list: जीव की हत्या करता है, बिना दिया हुआ लेता है, झूठ बोलता है, चुगली की बात बोलता है, व्यर्थ बकवास करता है,
  सेंध लगाता है, डाका डालता है, एक ही घर में डाका डालता है, राह में घात लगाता है, पराई स्त्री के पास जाता है,
  गाँव पर हमला करता है, कस्बे पर हमला करता है, संघ में फूट डालता है.
  saddhā… sīlaṃ… sutaṃ… cāgo… paññā… = श्रद्धा… सदाचार… सुना-सीखा ज्ञान… त्याग… प्रज्ञा… (before upanissāya oblique:
  सुने-सीखे ज्ञान); datives each «… के लिए…»; a comma after the subject list before the first dative.
- Labels: sahajātā/-o/-aṃ, purejātaṃ, pacchājātā/-aṃ, āhāraṃ, indriyaṃ, nānākkhaṇikā, ārammaṇa- / vatthupurejātaṃ =
  सह-उत्पत्ति, पूर्व-उत्पत्ति, पश्चात्-उत्पत्ति, आहार, क्षमता, भिन्न क्षण, विषय रूपी / आधार रूपी पूर्व-उत्पत्ति (formulas file).
  «purejātaṃ vatthu / cakkhuṃ» without a dash = adjective «पहले उत्पन्न आधार / आँख».
- Comma before a dative group that starts with an item, with vipāka, or with saddhāya … patthanāya (readability).

### Headings
- Vitakkattikaṃ / Pītittikaṃ / Dassanenapahātabbattikaṃ = harmonise-notes names; «X niṭṭhitaṃ.» = «X समाप्त।».
- Atthi-avigatapaccayā = उपस्थिति-कारण और अविलीनता-कारण; Natthivigatāvigatapaccayā = अनुपस्थिति-कारण, विलीनता-कारण और अविलीनता-कारण;
  Aññamañña-nissayapaccayā = परस्पर-कारण और आश्रय-कारण; Naadhipati-naāsevanapaccayā = …का अभाव और …का अभाव;
  X-paccayādi = «X-कारण आदि», naX-paccayādi = «X-कारण का अभाव आदि»; 1-4. Paccayānulomādi = 1-4. कारणों का सकारात्मक क्रम आदि.
- Numbers beyond nine: Hindi number words; «sabbattha n» = «हर जगह n»; «sabbe n» = «सभी में n».

## Termbase misfits / no entry
- ekāgārikaṃ karoti: karoti = «करना», but «डाका करना» is not Hindi; wrote «एक ही घर में डाका डालता है».
- pisuṇaṃ bhaṇati: «चुगली» + «बोलना» → «चुगली की बात बोलता है».
- chandarāgo (no entry): «चाह-राग» (chanda चाह + rāga राग); Sakapariggahe / parapariggahe (no entry): «अपनी / पराई संपत्ति के प्रति».
- vuṭṭhāna with an item adjective: «समभाव के साथ होने वाले बाहर आने के लिए» (termbase noun, no added word).
