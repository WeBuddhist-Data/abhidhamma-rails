## New recurring formulas
- X dhammaṃ paccayā = X परिघटना के कारण; X dhammaṃ saṃsaṭṭho / ekaṃ khandhaṃ saṃsaṭṭhā = … से घुल-मिलकर
- X ca Y ca dhammā Z dhammassa … = X और Y परिघटनाएँ, Z परिघटना के लिए …
- X eko khandho tiṇṇannaṃ khandhānaṃ = X वाला एक समूह तीन समूहों के लिए; ca-lists of datives repeat «के लिए»
- upanissāya = «X के प्रबल आश्रय से»: dānaṃ deti दान देता है, sīlaṃ samādiyati सदाचार ग्रहण करता है,
  uposathakammaṃ karoti उपवास-व्रत का पालन करता है, jhānaṃ / vipassanaṃ / maggaṃ / abhiññaṃ / samāpattiṃ uppādeti
  ध्यान / अंतर्दृष्टि / मार्ग / उच्च ज्ञान / ध्यान-अवस्था उत्पन्न करता है, mānaṃ jappeti अहंकार पालता है,
  diṭṭhiṃ gaṇhāti दृष्टि ग्रहण करता है, pāṇaṃ hanati जीव की हत्या करता है, saṅghaṃ bhindati संघ में फूट डालता है,
  attānaṃ ātāpeti paritāpeti pariyiṭṭhimūlakaṃ dukkhaṃ paccanubhoti स्वयं को तपाता है, कष्ट देता है, खोज के कारण
  होने वाला दुःख भोगता है
- X-paccavekkhaṇaṃ = «X पर हुआ पुनर्विचार» (termbase); X paccavekkhati = «X पर पुनः विचार करता है»
- cuticittaṃ / upapatticittassa = मृत्यु का मन / जन्म के मन के लिए; vuṭṭhānassa = बाहर आने के लिए;
  X āvajjanāya = X मन को विषय की ओर मोड़ने के लिए; paṭhamassa jhānassa parikammaṃ = पहले ध्यान की प्रारंभिक तैयारी
- cittasamaṅgissa: «X Y मन से युक्त व्यक्ति के मन को जानता है» (parittārammaṇaparitta… = सीमित विषय वाले सीमित मन)
- sakabhaṇḍe / parabhaṇḍe chandarāgo = अपनी / पराई वस्तुओं के प्रति चाह-राग; sakapariggahe / parapariggahe =
  अपने / पराए परिग्रह के प्रति चाह-राग (not in the termbase)
- atthappaṭisambhidā = अर्थ का विश्लेषणात्मक ज्ञान; saṃsaya (note) = संदेह (kept apart from vicikicchā संशय)
