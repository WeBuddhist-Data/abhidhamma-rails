## 1. Workflow and tool (READ-ONLY for parts 1–5: call it, do not edit it)

Files per part K (all in this folder): `decisions-partK.txt` (your hand-written tag table) → `partK-senses.md` (output). Part 1 contains the 91 sample headwords: copy their lines from decisions-sample.txt unchanged.

```
python -I -X utf8 -B senses_tool_vi.py todo   --part K               # headwords still without a decision line
python -I -X utf8 -B senses_tool_vi.py prior  --part K [all] [lo hi] # todo (or all) headwords of the part, rows lo..hi: agg row
                                                                     # + [pi-5 vi] [pi-4 vi] [pi-3 vi] [pi-2 vi] [pi-1 vi] [pi-6 en]
python -I -X utf8 -B senses_tool_vi.py prior  <hw> [<hw> ...]        # same for named headwords
python -I -X utf8 -B senses_tool_vi.py words  <hw> [<value>]         # per Vietnamese value, the Pāli tokens with the stem in its segments
python -I -X utf8 -B senses_tool_vi.py show   <hw> [<value>] [<max segs>] [<width>]   # ids + Pāli/Vietnamese line pairs
python -I -X utf8 -B senses_tool_vi.py build  --part K               # builds partK-senses.md, then verifies (`sample --part K` = the same)
python -I -X utf8 -B senses_tool_vi.py verify --part K               # also fails on any CR in the output
python -I -X utf8 -B senses_tool_vi.py reuse  --part K               # lines reusing a pi-1 … pi-5 Vietnamese tag verbatim, and a pi-6 English tag
```

- `prior --part K` prints 7 lines per headword: page it with a row range (`prior --part 2 all 1 40`, then `41 80` …), or pipe it through `Where-Object { $_ -notmatch '\(none\)$' }`. Never redirect it to a file.
- In PowerShell an empty argument is dropped: write `-` for "any value" (`show Rūpadhātuṃ - 0` = ids only). Yamaka segments are short pairs; a width of 200–300 is enough.
- `show` / `words` read AI_translation\pali\pi-6_split_chapters and AI_translation\vietnamese\pi-6-vietnamese-plain-zeroshot_split_chapters and the pi-6 map. The sample had 0 " / " → " và " rewrites and 0 shared candidates.

## 2. Tags: which source

1. **[pi-5 vi], then [pi-4 vi], [pi-3 vi], [pi-2 vi], [pi-1 vi]**: copy the approved Vietnamese tag verbatim when pi-6 has the same headword in the same sense with the same (or a «sự» / «có» / classifier / tense / head-noun variant of the same) Vietnamese value. Their splits stay binding (dukkha, rūpadhātu, puggala, hetu …). Sample: 23 headwords have a prior Vietnamese line; 17 reuse a tag verbatim; 2 adapt it (hetu: pi-5 gloss 'cause, reason' + its place in the hetuvāra series, §4; saṅkhārā: pi-5 gloss + 'formations in general in the Saṅkhārayamaka pairs'); Mūlaṃ keeps the pi-5 gloss 'root, a root condition' + its place in the series (user fix, §4); 4 had another value or meaning there (Nāmā pi-5 «tên»; paccayo pi-5 «làm điều kiện»; sambhavo pi-2 «sinh ra»; kusalahetū pi-1 / pi-2 «gốc rễ thiện», replaced by the user's «nguyên nhân thiện» of 2026-11-22).
2. **Adapt only the example or the grammar label** where the prior example does not occur in the Yamaka (pi-5 anulomaṃ / paccanīkaṃ 'direct order of argument' / 'opponent-first' are debate methods: in the Yamaka write `direct order, the positive half of a section (heading)` / `opposite order, the negated half of a section (heading)`; pi-5 puggalā «hạng người» 'dve puggalā': name a Yamaka use).
3. **[pi-6 en] word for word** when pi-1 … pi-5 Vietnamese have no line (or a line for another value or meaning) and the English tag names the same meaning as the Vietnamese value: Yamakapāḷi `title of this whole book`, Mūlayamakaṃ `title of the chapter on roots`, aññamaññamūlā `each serving as root for the other`, aññamaññamūlakā `each stemming from the other as a root`, Mūlakanayo `the method dealing with what stems from a root`. NOT the hetuvāra-series tags `the Nth of ten synonyms for a root`: they give the place only, not the meaning (user fix 2026-11-22, §4). The English tags carry no grammar label: copy them as they are.
4. **Do NOT copy a pi-6 English tag that flattens a distinction the Vietnamese makes**; write the family tag of §4 instead:
   - one English tag for gốc rễ / cội rễ / bắt nguồn từ gốc rễ / bắt nguồn từ cội rễ: every Xmūla- form is `a root that is skilful` (unskilful …), every -mūlamūla- form `a root of a root, in the method of that name`;
   - eka- forms: `the first of ten synonyms for a root, or a mental root of action` (wrong for «có cùng một gốc rễ»);
   - the X + series compounds (kusalahetū, kusalanidānā, kusalasamuṭṭhānā, kusalārammaṇā, kusalasamudayā): `skilful, karmically good (adjective)` (glosses only kusala);
   - kusalamūlasahajātā dhammā `states that are skilful`; every hetuvāra-series word `the Nth of ten synonyms for a root` (place only; Samuṭṭhānāhārārammaṇā `the seventh`, though it holds the 6th–8th);
   - two English senses for one Vietnamese value (kusalā / kusalaṃ «thiện», saṅkhārā «tạo tác», kusalapaccayā): one Vietnamese sense, one tag.
   - English tags built on "neutral" for abyākata: use `ethically indeterminate` (vietnamese-style.md).
- Forbidden in a tag: ": ", "; ", braces, Vietnamese letters, a bare English hint (`verify` checks all of them).

## 3. One sense or several: pi-6 decisions

Merge (one sense; candidates most frequent first):
- **Tense / polarity variants of one verb form** (map-coordinator-rules.md: the polarity of the verb's first rendering in the segment): uppajjissati «sẽ sinh khởi / sẽ … sinh khởi»; uppajjittha «đã sinh khởi / chưa từng sinh khởi»; nirujjhittha «đã chấm dứt / chưa từng chấm dứt»; nirujjhissati(-nti) «sẽ chấm dứt / sẽ … chấm dứt»; parijānittha, parijānissati, parijānissanti «vẫn sẽ … / sẽ …»; pajahissanti, nappajahissanti «vẫn sẽ dứt bỏ / sẽ không dứt bỏ»; bhāvittha, bhāvessati, bhāvessanti, sacchikarittha, sacchikarissati(-nti), paṭilabhissanti, upapajjissati. The -ti question form of each takes the same tag with its label.
- **Position variants**: kusalā / akusalā / abyākatā dhammā «hiện tượng X / hiện tượng … X» (pi-5 tags, verbatim); the plane-beings «chúng sinh trong cõi X / cõi X» (Kāmāvacarānaṃ, Rūpāvacarānaṃ, Arūpānaṃ, Pañcavokārānaṃ); Itaresaṃ / itaresaṃ «người khác / chúng sinh khác»; upapajjitvā «sau khi tái sinh / tái sinh».
- **Predicate vs subject of the -aṃ adjectives = ONE sense (sample decision)**: kusalaṃ «thiện» (predicate «na kusalaṃ», 6-1-51) / «hiện tượng thiện» (subject «Kusalaṃ ṭhapetvā …», 6-9-26, 6-9-30); kusalañca the same. «hiện tượng» is the head noun Vietnamese supplies for the substantivised neuter, as pi-5 Kusalaṃ «thiện / điều thiện» and the pi-4 «người X / X» rule. Tag: the pi-1 / pi-2 / pi-5 kusalaṃ tag verbatim. Expected: akusalaṃ, abyākataṃ «hiện tượng …» (only the subject form attested) take the pi-5 Akusalaṃ / pi-1 pattern tag; nāmaṃ «phần tinh thần» = pi-1 / pi-2 `mentality, the mental side of name-and-form (nominative sg.)`.
- **One Vietnamese value for two English senses → one tag**: saṅkhārā «tạo tác / sự tạo tác» (aggregate in the Khandhayamaka, formations in general and the three formations in the Saṅkhārayamaka 6-6-1, 6-6-4 …); kusalā, akusalā, abyākatā (English 'states' vs 'adjective').
- Letter case / heading vs closer: Mūlayamakaṃ and every <X>yamakaṃ «Các cặp câu hỏi về …» / «các cặp câu hỏi về …»; Āyatanayamakaṃ, Dhātuyamakaṃ … the same.

Split (real meaning differences; the earlier books' tags):
- **dukkha**: dukkhaṃ / Dukkhañca / dukkhanti «khổ đau» (Saccayamaka, the truth) vs «sự khó chịu» (Indriyayamaka, the faculty): the two pi-5 dukkhaṃ tags (`suffering in general, as in 'dukkhaṃ ariyasaccaṃ' …` / `pain, painful feeling of mind or body, …`), label changed for -ñca / -ti.
- **rūpadhātu**: «yếu tố hình sắc» (Dhātuyamaka, element) vs «cõi hình sắc» (Anusayayamaka, plane): pi-5 rūpadhātu tags. Rūpadhātuṃ has BOTH values in one line (6-4-10 / 6-4-11 vs 6-7-332 …): two senses.
- **hetu**: «nguyên nhân» (the hetuvāra series, sample tag) vs «gốc rễ» (root condition: Sahetukaṃ / Ahetukaṃ «có / không có gốc rễ», separate headwords; pi-5 / pi-2 hetu root tag adapted: `root, a root condition, as in sahetuka and ahetuka (…)`).
- **samuṭṭhāna**: Xsamuṭṭhānaṃ beside rūpaṃ «do … sinh ra» (pi-1 samuṭṭhānaṃ tag adapted) vs X + series word «nguồn gốc» (kusalasamuṭṭhānā, nāmasamuṭṭhānā: series tag).
- **mūla «gốc rễ» vs mūlamūla «cội rễ»**: different headwords; never give a -mūlamūla- form the plain root tag.
