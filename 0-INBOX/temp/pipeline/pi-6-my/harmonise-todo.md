- A2 Quote marks only where the Pāli has them: check every group's added “…” (e.g. anaññātaññassāmīti in ch9-10a «“မသိရသေးသည်ကို သိရတော့မည်”»; the sota gloss) against the Pāli and the earlier books' rendering of the same word; follow pi-1 / pi-2 for the faculty name.

## B. Consistency (one form per item book-wide)
- B1 Time / moment phrases attached to person groups (uppādakkhaṇe, bhaṅgakkhaṇe, sabbesaṃ, tesaṃ upapajjantānaṃ / cavantānaṃ …): two styles exist (the ch. 5 style «… သူ အားလုံးတို့၏ … ခဏ၌၊ …», used by ch2-02-4-5, ch9-10a, ch10b, ch10c; and the ch6-8 style «… ခဏ၌ ရှိသူ အားလုံးတို့၊ …», ch6-8 and parts of 10-10 / 10-11). Use the ch. 5 style book-wide; identical Pāli = identical Burmese.
- B2 uppādakkhaṇe «ဖြစ်ခြင်း ခဏ» / bhaṅgakkhaṇe «ပြိုပျက်ခြင်း ခဏ» (pi-5 ^5-366, binding) stay; the vāra headings keep uppāda «ဖြစ်ပေါ်ခြင်း» (approved sample). Make sure every group has exactly these.
- B3 tāsaṃ (fem., after itthīnaṃ): one form: «ထိုမိန်းမတို့» (the antecedent is women; clearer for a plain reader). ch10b / ch10c have «ထိုသူတို့».
- B4 After a relative clause («ye ca … tesaṃ X-antānaṃ»): «…တို့အနက်» (majority) vs «ထဲမှ» (ch6-8): use «အနက်».
- B5 Plural «ကြ»: one rule book-wide: «ကြ» where the Pāli verb is plural, never where it is singular (ch9-10a adds it in the Dhammayamaka; check the other groups follow the same rule). Bare short answers keep the number of their Pāli verb.
- B6 «ထိုသူတို့ပင်နှင့်» (ch6-8, 10 lines): a plainer form if one exists in the other groups for the same Pāli.
- B7 sota pun (Dibbasotaṃ taṇhāsotaṃ …): ch3 and ch2-02-4-5 both use «“သောတ” (နား သို့မဟုတ် ရေစီး)»: keep one form everywhere it occurs (coordinator: kept as the agreed form; the plain «နား» would make "the stream of craving an ear"). Check A2 for its quote marks: keep them, the word is cited as a word.
- B8 Planes as places: kāmāvacara «ကာမဘုံ», rūpāvacara «သိမ်မွေ့သော ရုပ်ဘုံ», arūpāvacara / arūpa (place) «ရုပ်မရှိသော ဘုံ»: one form each in every group; adjectival uses (of citta) as pi-1.
- B9 Person types and attributes: sa-X-ka / a-X-ka «X ရှိလျက် / X မရှိဘဲ», sahetuka «အမြစ် ရှိလျက်» (check: hetu is «အကြောင်း» in the hetuvāra list — decide per sense and log), ñāṇasampayutta, somanassena / upekkhāya «…နှင့်အတူ», na itthīnaṃ «မိန်းမ မဟုတ်ဘဲ», the women frame, -samaṅgī, nirodhasamāpanna, the path / fruit persons, Aṭṭhamaka, Anāgāmī: one form each book-wide.
- B10 «yassa cittassa anantarā»: two renderings by syntax (person group «မိမိ စိတ်၏ …» vs correlative «အကြင်စိတ်၏ … ၊ ထိုစိတ်၏ …»): keep the split only where the Pāli syntax differs; identical Pāli = identical Burmese.
- B11 The 22 faculties, the seven anusayas, the khandha / āyatana / dhātu / sacca names and bare words: one form each, = pi-1 / pi-2 final.
- B12 Headings, vāra / naya / uddesa / niddesa names, colophons, the «(Xmūlakaṃ)» notes, chapter names and the book end: one pattern book-wide; mahāvāra «ဖော်ပြချက်ကြီး», paṭiloma = paccanīka «အငြင်းပြ ပုံစံ».
- B13 pariññā / bhāvanā verbs: parijānāti «ပိုင်းခြား သိ», pajahati «ပယ်», bhāveti «ပွားများ», sacchikaroti «မျက်မှောက်ပြု», in every tense and polarity, one form each (incl. the negative's position).
- B14 Unsure readings to keep consistent (no change unless groups differ): yato / tato as place (ch7a), tadekaṭṭhaṃ pajahati (ch7a), sakkāya, dassetvā «ဖြတ်သန်း» (ch10b / ch10c), avaseso kāyo.
