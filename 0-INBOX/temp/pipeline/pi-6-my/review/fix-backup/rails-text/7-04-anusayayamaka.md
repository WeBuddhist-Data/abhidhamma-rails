(ခ) တစ်ဖန် အကြင်သူသည် အကြင်နေရာ၌ ဘဝရာဂ ကိန်းအောင်းခြင်း မရှိသူ ဖြစ်၏၊ ထိုသူသည် ထိုနေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သလော။
ပုဂ္ဂိုလ် သုံးယောက်တို့သည် နာကျင်သော ခံစားမှု ဟူသော ထိုနေရာ၌ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း မရှိသူများ ဖြစ်ကြသည်၊ သို့သော် ထိုသူတို့သည် ထိုနေရာ၌ မုန်းတီးမှု ကိန်းအောင်းခြင်း မရှိသူများ မဟုတ်ကြ။ ထိုပုဂ္ဂိုလ်တို့သည်ပင် ကာမဘုံရှိ ခံစားမှု နှစ်ပါး ဟူသော ထိုနေရာ၌ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း မရှိသူများ ဖြစ်ကြသည်၊ သို့သော် ထိုသူတို့သည် ထိုနေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်း မရှိသူများ မဟုတ်ကြ။ ထိုပုဂ္ဂိုလ်တို့သည်ပင် ဘဝဘုံတို့၌ အကျုံးမဝင်သော အရာ ဟူသော ထိုနေရာ၌ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း မရှိသူများ ဖြစ်ကြသည်၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း မရှိသူများ ဖြစ်ကြသည်။ ရဟန္တာသည် နေရာတိုင်း၌ ဘဝရာဂ ကိန်းအောင်းခြင်း မရှိသူ ဖြစ်သည်၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်။
(က) အကြင်သူသည် အကြင်နေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်၏၊ ထိုသူသည် ထိုနေရာ၌ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်း မရှိသူ ဖြစ်သလော။

ပုဂ္ဂိုလ် နှစ်ယောက်တို့သည် နာကျင်သော ခံစားမှု ဟူသော ထိုနေရာ၌ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း မရှိသူများ ဖြစ်ကြသည်၊ သို့သော် ထိုသူတို့သည် ထိုနေရာ၌ မုန်းတီးမှု ကိန်းအောင်းခြင်း မရှိသူများ မဟုတ်ကြ။ ထိုပုဂ္ဂိုလ်တို့သည်ပင် ကာမဘုံရှိ ခံစားမှု နှစ်ပါး ဟူသော ထိုနေရာ၌ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း မရှိသူများ ဖြစ်ကြသည်၊ သို့သော် ထိုသူတို့သည် ထိုနေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း မရှိသူများ မဟုတ်ကြ။ ထိုပုဂ္ဂိုလ်တို့သည်ပင် သိမ်မွေ့သော ရုပ်ဘုံနှင့် ရုပ်မရှိသော ဘုံ ဟူသော ထိုနေရာ၌ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း မရှိသူများ ဖြစ်ကြသည်၊ သို့သော် ထိုသူတို့သည် ထိုနေရာ၌ မာန ကိန်းအောင်းခြင်း မရှိသူများ မဟုတ်ကြ။ ထိုပုဂ္ဂိုလ်တို့သည်ပင် ဘဝဘုံတို့၌ အကျုံးမဝင်သော အရာ ဟူသော ထိုနေရာ၌ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူများ ဖြစ်ကြသည်၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း မရှိသူများ ဖြစ်ကြသည်။ အနာဂါမ်သည် ကာမဘုံရှိ ခံစားမှု နှစ်ပါး၊ သိမ်မွေ့သော ရုပ်ဘုံနှင့် ရုပ်မရှိသော ဘုံ ဟူသော ထိုနေရာ၌ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ သို့သော် ထိုသူသည် ထိုနေရာ၌ မာန ကိန်းအောင်းခြင်း မရှိသူ မဟုတ်။ ထိုပုဂ္ဂိုလ်သည်ပင် နာကျင်သော ခံစားမှုနှင့် ဘဝဘုံတို့၌ အကျုံးမဝင်သော အရာ ဟူသော ထိုနေရာ၌ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်။ ရဟန္တာသည် နေရာတိုင်း၌ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်။

ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ သို့သော် ထိုသူသည် ထိုနေရာ၌ မာန ကိန်းအောင်းခြင်း မရှိသူ မဟုတ်။ ထိုပုဂ္ဂိုလ်သည်ပင် နာကျင်သော ခံစားမှုနှင့် ဘဝဘုံတို့၌ အကျုံးမဝင်သော အရာ ဟူသော ထိုနေရာ၌ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်။ ရဟန္တာသည် နေရာတိုင်း၌ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်။
(က) အကြင်သူသည် အကြင်နေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်၏၊ ထိုသူသည် ထိုနေရာ၌ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်း မရှိသူ ဖြစ်သလော။
အနာဂါမ်သည် နာကျင်သော ခံစားမှု ဟူသော ထိုနေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ သို့သော် ထိုသူသည် ထိုနေရာ၌ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်း မရှိသူ မဟုတ်။ ထိုပုဂ္ဂိုလ်သည်ပင် ဘဝဘုံတို့၌ အကျုံးမဝင်သော အရာ ဟူသော ထိုနေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်။ ရဟန္တာသည် နေရာတိုင်း၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်။
(ခ) တစ်ဖန် အကြင်သူသည် အကြင်နေရာ၌ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်း မရှိသူ ဖြစ်၏၊ ထိုသူသည် ထိုနေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သလော။ ဟုတ်ပါသည်။ (ငါးပါးကို အခြေခံ၍) ^6-7-130

(က) အကြင်သူသည် အကြင်နေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း၊ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်၏၊ ထိုသူသည် ထိုနေရာ၌ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်း မရှိသူ ဖြစ်သလော။
အနာဂါမ်သည် နာကျင်သော ခံစားမှု ဟူသော ထိုနေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း၊ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ သို့သော် ထိုသူသည် ထိုနေရာ၌ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်း မရှိသူ မဟုတ်။ ထိုပုဂ္ဂိုလ်သည်ပင် ဘဝဘုံတို့၌ အကျုံးမဝင်သော အရာ ဟူသော ထိုနေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း၊ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်။ ရဟန္တာသည် နေရာတိုင်း၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း၊ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်၊ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သည်။
(ခ) တစ်ဖန် အကြင်သူသည် အကြင်နေရာ၌ အမှန်ကို မသိမှု ကိန်းအောင်းခြင်း မရှိသူ ဖြစ်၏၊ ထိုသူသည် ထိုနေရာ၌ ကာမရာဂ ကိန်းအောင်းခြင်းလည်း၊ မုန်းတီးမှု ကိန်းအောင်းခြင်းလည်း၊ မာန ကိန်းအောင်းခြင်းလည်း၊ အယူ ကိန်းအောင်းခြင်းလည်း၊ ယုံမှားမှု ကိန်းအောင်းခြင်းလည်း၊ ဘဝရာဂ ကိန်းအောင်းခြင်းလည်း မရှိသူ ဖြစ်သလော။ ဟုတ်ပါသည်။ (ခြောက်ပါးကို အခြေခံ၍)
