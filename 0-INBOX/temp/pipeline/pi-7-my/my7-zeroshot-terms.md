## 4. Frames (by section, order and polarity)

- paṭiccavāra: «X-aṃ dhammaṃ paṭicca Y-o dhammo uppajjati Zpaccayā» = «X သဘောတရားကို မှီ၍ Y သဘောတရားသည် Zဟူသော အကြောင်းကြောင့် ဖြစ်ပေါ်သည်»; negative «naZpaccayā» = «… Zဟူသော အကြောင်းကြောင့် မဟုတ်ဘဲ ဖြစ်ပေါ်သည်»
- a chain «… uppajjati A… B… C – …» keeps one verb, after the last condition: «… A-ကြောင့်… B-ကြောင့်… C-ကြောင့် ဖြစ်ပေါ်သည် – …»
- pucchāvāra: «Siyā X paṭicca Y uppajjeyya Zpaccayā» = «X ကို မှီ၍ Y သည် Z-ကြောင့် ဖြစ်ပေါ်နိုင်သလော»; plural uppajjeyyuṃ = «ဖြစ်ပေါ်နိုင်ကြသလော»
- the explanation «ekaṃ khandhaṃ paṭicca dve khandhā, dve khandhe paṭicca eko khandho» = «အစုအဝေး တစ်ပါးကို မှီ၍ အစုအဝေး နှစ်ပါး၊ အစုအဝေး နှစ်ပါးကို မှီ၍ အစုအဝေး တစ်ပါး»
- link words: paṭicca = «Xကို မှီ၍»; nissāya = «Xကို မှီ၍»; paccayā = «Xကြောင့်»; sahajāto = «Xနှင့်အတူ ပေါ်ပေါက်သော»; saṃsaṭṭho = «Xနှင့် ရောနှောသော»; sampayutto = «Xနှင့် ယှဉ်တွဲသော»; sampayuttā = «Xနှင့် ယှဉ်တွဲသော»; ārabbha = «Xကို အာရုံပြု၍»
- verbs: uppajjati = ဖြစ်ပေါ်သည်; uppajjanti = ဖြစ်ပေါ်ကြသည်; uppajjeyya = ဖြစ်ပေါ်နိုင်သလော; uppajjeyyuṃ = ဖြစ်ပေါ်နိုင်ကြသလော
- prefixes: okkantikkhaṇe = သန္ဓေ သက်ဆင်းသော ခဏ၌; paṭisandhikkhaṇe = ပဋိသန္ဓေ နေသော ခဏ၌; ahetukapaṭisandhikkhaṇe = အမြစ် မရှိသော ပဋိသန္ဓေ နေသော ခဏ၌; arūpe = ရုပ်မရှိသော ဘုံ၌
- pañhāvāra: «X-o dhammo Y-assa dhammassa Zpaccayena paccayo» = «X သဘောတရားသည် Y သဘောတရားအား Zဟူသော အကြောင်းဖြင့် အကြောင်း ဖြစ်သည်» (pi-5 ^5-716: «ရှေးရှေး ကုသိုလ် သဘောတရားတို့သည် နောက်နောက် ကုသိုလ် သဘောတရားတို့အား ချက်ချင်း နောက်၌ ဖြစ်စေခြင်းဟူသော အကြောင်းဖြင့် အကြောင်း …»)
- coordination «X Yñca» / «X ca Y ca» = «Xလည်းကောင်း၊ Yလည်းကောင်း» (case marker inside); terms on one noun «kusalo ca abyākato ca dhammā» = «ကုသိုလ် သဘောတရားနှင့် … သဘောတရားတို့»
- aññamaññaṃ = အချင်းချင်း; kesañci (after a recipient) = «…တို့အနက် အချို့အား»; kiñci kāle = အချို့သော အချိန်၌; -pi = «…လည်း»

## 5. Counting frames

- «Hetuyā tīṇi» = «အမြစ်ဟူသော အကြောင်း၌ သုံးခု»; «Nahetuyā tīṇi» = «အမြစ်ဟူသော အကြောင်း မဟုတ်ခြင်း၌ သုံးခု»
- «Hetupaccayā ārammaṇe tīṇi» = «အမြစ်ဟူသော အကြောင်းကြောင့်၊ အာရုံဟူသော အကြောင်း၌ သုံးခု» («၊» between the given conditions and the first count)
- ghaṭanā «Hetu-sahajāta-…nti tīṇi» = «အမြစ်၊ အတူ ပေါ်ပေါက်ခြင်း ဟူသော ပေါင်းစပ်ချက်၌ သုံးခု»; with a following count «…nti naārammaṇe tīṇi» = «အမြစ်၊ အတူ ပေါ်ပေါက်ခြင်း ဟူသော ပေါင်းစပ်ချက်နှင့် အာရုံဟူသော အကြောင်း မဟုတ်ခြင်း၌ သုံးခု»
