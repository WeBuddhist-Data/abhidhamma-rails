## Decisions worth a look
- rūpataṇhā appears twice in the lobha string: first (with arūpataṇhā, nirodhataṇhā) = craving for fine-material existence; second (in the six-object list) = craving for visible forms. Identical Pāli, different English, because the senses differ.
- sārāga = passion (lobha string), while the approved alobha string has asārāgo = non-lust; rāga = lust is needed for rāgo in the same string.
- sīla in sīlabbata = rules (not "morality"), so the definition reads "purification comes through rules … observances". The 4-01 builder (in progress) uses "rites and rituals" and "purity"; one of the two must change.
- Tattha = "Of these" here; the 4-01 builder uses "Therein". For the consistency pass.
- dosa string: āghāta = resentment, paṭighāta = repugnance, paṭigha = aversion, paṭivirodha = hostility; the 4-01 builder starts "annoyance of the mind … resentment, aversion, opposition, irritation". For the consistency pass.
- diṭṭhigata = being caught in views (4-01 builder: holding a view).
