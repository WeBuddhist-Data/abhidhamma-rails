## How the engine works (for the consistency pass)
- The model's 2-01 engine (F.translate_cu) is used unchanged; the Rūpakaṇḍa frames are (regex, function) pairs in

- Frames: «Katamaṃ taṃ rūpaṃ X?» = «X ရုပ် ဟူသည် အဘယ်နည်း။»; «idaṃ taṃ rūpaṃ X.» = «ဤသည်မှာ X ရုပ် ဖြစ်သည်။» (the 2-01
  question / closer words); «Atthi rūpaṃ X» / «atthi X» = «X ရုပ် ရှိသည်» (the 2-01 «X hoti» verb); «Yaṃ taṃ rūpaṃ X, taṃ
  Y» = «X ရုပ်၊ ထိုရုပ်သည် Y ရုပ် ဖြစ်သည်»; «taṃ atthi Y» = «ထိုရုပ်တွင် Y ရုပ် ရှိသည်»; «yañca rūpaṃ X» = «X ရုပ်လည်း»;
  «yaṃ / yo vā panaññampi atthi …» = «… အခြား … ရှိသမျှလည်း» (as the model's «ye vā pana … aññepi atthi»).
- The sense definitions (3-02, 3-03): one generic rule reads «yena / yāya / yamhi / yaṃ / yā / yo W1 ADJ W2 ADJ VERB»,
  finds which word is the organ and which the object and their cases (instrumental «ဖြင့်», locative «၌», subject «သည်»,
  object «ကို»), puts the instrumental / locative phrase first and «ထို» («that») before the relative's word; the
  «nissāya … ārabbha» clauses, the organ / object heads with their lists of kinds and the «X petaṃ» runs have their own rules.

### Fixed sentences and phrases

Katame dhammā abyākatā = ကုသိုလ်လည်း မဟုတ်၊ အကုသိုလ်လည်း မဟုတ်သော သဘောတရားများ ဟူသည် အဘယ်တို့နည်း
Kusalākusalānaṃ dhammānaṃ vipākā kāmāvacarā rūpāvacarā arūpāvacarā apariyāpannā vedanākkhandho saññākkhandho saṅkhārakkhandho viññāṇakkhandho = ကုသိုလ်နှင့် အကုသိုလ် သဘောတရားတို့၏ အကျိုး ဖြစ်သော၊ ကာမဘုံနှင့် ဆိုင်သော၊ သိမ်မွေ့သော ရုပ်ဘုံနှင့် ဆိုင်သော၊ ရုပ်မရှိသော ဘုံနှင့် ဆိုင်သော၊ ဘဝဘုံတို့၌ အကျုံးမဝင်သော ခံစားမှု အစုအဝေး၊ မှတ်သိမှု အစုအဝေး၊ ပြုပြင်ဖန်တီးမှု အစုအဝေး၊ သိစိတ် အစုအဝေး
ye ca dhammā kiriyā neva kusalā nākusalā na ca kammavipākā = ပြုရုံမျှသာ ဖြစ်သော၊ ကုသိုလ်လည်း မဟုတ်၊ အကုသိုလ်လည်း မဟုတ်၊ ကံ၏ အကျိုးလည်း မဟုတ်သော သဘောတရားများလည်း
sabbañca rūpaṃ = ရုပ် အားလုံးလည်း
asaṅkhatā ca dhātu = ပြုပြင်ဖန်တီးထားခြင်း မရှိသော ဓာတ်လည်း
ime dhammā abyākatā = ဤသဘောတရားများသည် ကုသိုလ်လည်း မဟုတ်၊ အကုသိုလ်လည်း မဟုတ်သော သဘောတရားများ ဖြစ်ကြသည်
Tattha katamaṃ sabbaṃ rūpaṃ = ထိုတို့အနက် ရုပ် အားလုံး ဟူသည် အဘယ်နည်း
Cattāro ca mahābhūtā, catunnañca mahābhūtānaṃ upādāya rūpaṃ = မူလဓာတ်ကြီး လေးပါးလည်းကောင်း၊ မူလဓာတ်ကြီး လေးပါးကို မှီ၍ ဖြစ်သော ရုပ်လည်းကောင်း
idaṃ vuccati sabbaṃ rūpaṃ = ဤသည်ကို ရုပ် အားလုံးဟု ခေါ်သည်
ayaṃ vuccati vācā = ဤသည်ကို စကားဟု ခေါ်သည်
Diṭṭhaṃ sutaṃ mutaṃ viññātaṃ rūpaṃ = မြင်ရသော၊ ကြားရသော၊ နမ်း မြည်း ထိတွေ့ရသော၊ သိရသော ရုပ်
Rūpāyatanaṃ diṭṭhaṃ, saddāyatanaṃ sutaṃ, gandhāyatanaṃ rasāyatanaṃ phoṭṭhabbāyatanaṃ mutaṃ, sabbaṃ rūpaṃ manasā viññātaṃ rūpaṃ = အဆင်းအရောင် အာရုံခံ နယ်ပယ်သည် မြင်ရသောအရာ၊ အသံ အာရုံခံ နယ်ပယ်သည် ကြားရသောအရာ၊ အနံ့ အာရုံခံ နယ်ပယ်၊ အရသာ အာရုံခံ နယ်ပယ်၊ အထိအတွေ့ အာရုံခံ နယ်ပယ်တို့သည် နမ်း မြည်း ထိတွေ့ရသောအရာ၊ ရုပ် အားလုံးသည် မနောဖြင့် သိရသော ရုပ် ဖြစ်သည်
Yo āyatanānaṃ ācayo, so rūpassa upacayo = အာရုံခံ နယ်ပယ်တို့၏ စုပုံခြင်း၊ ထိုအရာသည် ရုပ်၏ တိုးပွားခြင်း ဖြစ်သည်
Yo rūpassa upacayo, sā rūpassa santati = ရုပ်၏ တိုးပွားခြင်း၊ ထိုအရာသည် ရုပ်၏ ဆက်လက်ဖြစ်ပေါ်ခြင်း ဖြစ်သည်
manāpiyo phoṭṭhabbo sukhasamphasso kāyaviññeyyaṃ rūpaṃ = စိတ်နှင့် တွေ့သော၊ ထိတွေ့ရ သာယာသော အထိအတွေ့သည် ကိုယ်ဖြင့် သိနိုင်သော ရုပ် ဖြစ်သည်
amanāpiyo phoṭṭhabbo dukkhasamphasso kāyaviññeyyaṃ rūpaṃ = စိတ်နှင့် မတွေ့သော၊ ထိတွေ့ရ နာကျင်သော အထိအတွေ့သည် ကိုယ်ဖြင့် သိနိုင်သော ရုပ် ဖြစ်သည်
yaṃ vā panaññampi atthi rūpaṃ yamhi yamhi janapade tesaṃ tesaṃ sattānaṃ mukhāsiyaṃ dantavikhādanaṃ galajjhoharaṇīyaṃ kucchivitthambhanaṃ = ဒေသ အသီးသီး၌ ထိုထို သတ္တဝါတို့၏ ခံတွင်းဖြင့် စားရသော၊ သွားဖြင့် ဝါးရသော၊ လည်ချောင်းမှ မျိုချရသော၊ ဝမ်းကို ပြည့်စေသော အခြား ရုပ် ရှိသမျှလည်း
yāya ojāya sattā yāpenti = သတ္တဝါတို့ အသက် ရှင်သန်ကြရာ ဖြစ်သော အဆီအနှစ်
Rūpakaṇḍe paṭhamabhāṇavāro = ရုပ် အခန်း၌ ပထမ ရွတ်ဖတ်ရန် အပိုင်း
Rūpakaṇḍaṃ niṭṭhitaṃ = “ရုပ် အခန်း” ပြီးဆုံးပြီ
