## Mātikā items (approved strings, grammatical adaptations only)
- Question «Katame dhammā T?» = «T-string သဘောတရားများ ဟူသည် အဘယ်တို့နည်း။» (the F.KATAME_KUSALA pattern).
- Closer «– ime dhammā T.» = «– ဤသဘောတရားများသည် T-string သဘောတရားများ ဖြစ်ကြသည်။»; kusalā / akusalā are noun
  predicates: «ဤသဘောတရားများသည် ကုသိုလ် ဖြစ်ကြသည်» (= F.IME_KUSALA) / «… အကုသိုလ် ဖြစ်ကြသည်».
- Singular subjects (Pīti, Sukhaṃ, Nibbānaṃ, Cittaṃ, Parāmāso, Ākiñcaññāyatanaṃ, Vitakkasahajāto vicāro, So eva …):
  «T-string သဘောတရား» + «ဖြစ်သည်» (Pāli singulars uppannaṃ, savitakkasavicāro … mapped to the plural keys).
- The «kho pana» pairs (na hetū sahetukā, āsavavippayuttā sāsavā …) = «X-string သဘောတရားများအနက် Y-string»
  (from the Mātikā «ထို့ပြင် X သဘောတရားများအနက် Y-သည်တို့လည်း»).
- «ceva … ca» / «ceva no ca» = CEVA / CEVANO unchanged.
- siyā T = «တစ်ခါတစ်ရံ T-string သဘောတရားများ ဖြစ်ကြသည်»; na T (free) = «T-string သဘောတရားများ မဟုတ်ကြ»; where
  «na T» is itself a Mātikā key (na pītisahagatā, na upekkhāsahagatā, na dassanena pahātabbā …) that string is used.
- na vattabbā A-tipi, B-tipi = «A-string သဘောတရားများဟုလည်းကောင်း၊ B-string … ခေါ်ဆို၍ မရ» (one negation for the one
  «na»); a single «A-ti» = «A-string သဘောတရားများဟု ခေါ်ဆို၍ မရ».
- Bare terms in a subject list (Rūpāvacarā, arūpāvacarā, apariyāpannā, Kāmāvacarā) = T-string + «သဘောတရားများ».
- 1418 «Rūpāvacarā, arūpāvacarā, kusalābyākatā»: the shared qualifier comes first: «ကုသိုလ်နှင့် ABY-string၊
  RUPA-string သဘောတရားများ၊ ARUPA-string သဘောတရားများ».
- Clause separators in a predicate («, », «; », « ») are all «၊ ».

## Main choices (one-line reasons)
- Neuter kusalaṃ / akusalaṃ / vipāko / kiriyā in the lists = «ကုသိုလ်စိတ် / အကုသိုလ်စိတ် / ကံ၏ အကျိုး ဖြစ်သော စိတ် /
  ပြုရုံမျှသာ ဖြစ်သော စိတ်»: bare «ကုသိုလ်» reads «merit»; English and Marathi also add «mind» (minor clarification).
- cittuppāda = «စိတ် ဖြစ်ပေါ်မှု» (one root with the 2-01 heading «စိတ် ဖြစ်ပေါ်ခြင်း»); counted with «ပါး».
- bhūmi = «ဘုံ»: catūsu bhūmīsu X = «ဘုံ လေးပါးရှိ X».
- -ato with a number = «X-အနက်» (from among); kusalato ca vipākato ca kiriyato ca after a jhāna = «ကုသိုလ်အဖြစ်လည်းကောင်း၊
  ကံ၏ အကျိုးအဖြစ်လည်းကောင်း၊ ပြုရုံမျှသာအဖြစ်လည်းကောင်း» (as wholesome, resultant, functional).
- Jhāna-method compounds (as English and Marathi): rūpāvacara-tika-catukka-jjhānā = «… ဈာန် လေးပါး ခွဲနည်းအရ ဈာန်
  သုံးပါးနှင့် ဈာန် ငါးပါး ခွဲနည်းအရ ဈာန် လေးပါး»; catukkapañcakajjhānā = «ဈာန် လေးပါး ခွဲနည်းနှင့် ဈာန် ငါးပါး
  ခွဲနည်းအရ ဈာန်များ»; pañcakanaye = «ဈာန် ငါးပါး ခွဲနည်းအရ». The checker counts the two method numbers too.
- X ca / Xñca in a list = «X-လည်း»; two ca-items with no comma (rūpañca nibbānañca) = «X-နှင့် Y».
- ṭhapetvā = the 2-01 «X-ကို ချန်ထား၍», pre- or post-posed in the Pāli; etthuppanna = «ထိုတို့၌ ဖြစ်ပေါ်သော»;
  descriptive uppanna = «ဖြစ်ပေါ်သော» (the triad term uppannā stays «ဖြစ်ပေါ်ပြီးသော»).
- kiriyā = «ပြုရုံမျှသာ ဖြစ်သော», vicikicchā = «ယုံမှားသံသယ», uddhacca = «ယောက်ယက်ခတ်မှု», diṭṭhigata = «အယူမှား»:
  aligned with the 2-02/03 and 2-04/05 agents (their chapters define these cittas; both agree). domanassa
  «စိတ်ဆင်းရဲမှု» and paṭigha «မုန်းတီးမှု» are the same as theirs.
- paṭigha (aversion) = «မုန်းတီးမှု», kept apart from the Mātikā paṭigha (impact) «ထိခိုက်မှု».
- rāga = «ရာဂ» (kāmarāga «ကာမရာဂ», bhavarāga «ဘဝရာဂ»), kept apart from bhavataṇhā «ဘဝကို တပ်မက်မှု»; note the
  2-02/03 agent wrote kāmarāga as «ကာမကို တပ်မက်မှု» in one phrase (for the consistency pass).
- diṭṭhi (bare, in the cluster lists) = «အယူ» (sample); diṭṭhigata = «အယူမှား».
- kāyagantha = «ကိုယ်ကို ချည်နှောင်သော အထုံး», members «X ဟူသော …»; idaṃsaccābhinivesa = «ဤအယူသာ အမှန်ဖြစ်သည်ဟူ၍
  စွဲမြဲစွာ ယူခြင်း» (no «ဟု», which the checker counts as a quote marker).
- sāmaññaphala = «ရဟန်းအဖြစ်၏ ဖိုလ်» (ဖိုလ် is the everyday partner of မဂ်); arahattaphala = «ရဟန္တာ ဖိုလ်».
- The formless āyatanas: «အဆုံးမရှိသော ကောင်းကင် / သိစိတ် နယ်ပယ်», «ဘာမျှ မရှိသော နယ်ပယ်», «မှတ်သိမှု ရှိသည်လည်း
  မဟုတ်၊ မရှိသည်လည်း မဟုတ်သော နယ်ပယ်» (neva / na / a = three negations); āruppa = «ရုပ်မရှိသော ဈာန်».
- siyā = «တစ်ခါတစ်ရံ» (in some cases); niyogā … natthi = «အမြဲတမ်း … ဟူ၍ မရှိ».
- Teva X / Tāneva X = «ထို X-များသည်ပင်»; So eva parāmāso = «ထို မှားယွင်းသော ယူဆမှုသည်ပင်».
- Yattha dve tayo X ekato uppajjanti = «X နှစ်ပါး သုံးပါး တစ်ပြိုင်နက် ဖြစ်ပေါ်ကြရာ၌» (literal; the clause is the
  subject before «– ime dhammā»).
- uppajjati clauses: subject + «သည်» (two or more subjects «တို့သည်»; a «-လည်း … -လည်း» subject takes no marker).
- 11 / 12 = «ဆယ့်တစ် / ဆယ့်နှစ်» (new number words); dvepañcaviññāṇāni = «ငါးပါးစီ ရှိသော သိစိတ် နှစ်စု».

## Unsure Pāli / for the reviewer
- 1387 «kāmāvacarakusalassa vipākato ca kiriyato ca pañca» read as «five each» («ငါးပါးစီ», as Marathi); the count
  fits the later lists (pīti: five resultant, five functional).
- cittahetukaṃ = «စိတ်ကို အမြစ်ပြုသော»: hetu = root everywhere in this track, but the sense here is «caused by mind».
- avasesaṃ akusalaṃ = «ကြွင်းသော အကုသိုလ်စိတ်»: the remainder includes mental factors; «စိတ်» follows the list rule.
- «Yattha … ekato uppajjanti – ime dhammā …» (where two or three roots arise together – these …): kept literal.
- kāyaviññatti / vacīviññatti = «ကိုယ် / နှုတ်ဖြင့် ရည်ရွယ်ချက်ကို ပြခြင်း», ākāsadhātu «ကောင်းကင် ဓာတ်», āpodhātu
  «ရေ ဓာတ်», kabaḷīkāro āhāro «စားသောက်ရသော အာဟာရ»: the Rūpakaṇḍa agent may choose other words.
