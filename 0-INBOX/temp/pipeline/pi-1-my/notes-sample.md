## Main choices (one-line reasons)
- dhamma (phenomenon) = သဘောတရား, plural သဘောတရားများ. Ordinary readers take it as "nature, state, phenomenon".
  Rejected: bare တရား (reads as "the Teaching" or "a sermon": တရားနာ, တရားဟော); ဓမ္မ (Pāli, also "Teaching");
  ဖြစ်စဉ် (modern "event / process"); အရာ (any thing, too vague).
- kusala = ကုသိုလ်, akusala = အကုသိုလ်: established, everyday words.
- abyākata = ကုသိုလ်လည်း မဟုတ်၊ အကုသိုလ်လည်း မဟုတ်သော ("neither wholesome nor unwholesome"), not a feeling word.
- Book title Dhammasaṅgaṇī = သဘောတရားများကို စုစည်းရေတွက်ခြင်း ("gathering and counting the phenomena", from
  saṃ + gaṇ). Abhidhammapiṭake = အဘိဓမ္မာပိဋကတွင် ("in the Abhidhamma Piṭaka"), as in the other languages.
- Namo tassa … = my own wording from the Pāli (tassa = ထို, bhagavā = မြတ်စွာဘုရား, arahant = ရဟန္တာ,
  sammāsambuddha = "who fully and by himself knew the truth"); no full stop, as in the Pāli.
- Mātikā = ခေါင်းစဉ်စာရင်း ("list of headings / topics"). Not မာတိကာ: in everyday Burmese that means a book's
  table of contents. Tika = သုံးမျိုးတွဲ (set of three kinds), duka = နှစ်မျိုးတွဲ.
- How names stay plain: every triad / dyad term is a descriptive Burmese clause ending in «…သော» before
  သဘောတရားများ ("phenomena that …"); no bare Pāli compound in Burmese script. The Pāli loans kept (ကုသိုလ်,
  ကိလေသာ, ပီတိ, ဥပေက္ခာ, ဘာဝနာ, သစ္စာ, မဂ်, ဈာန်, သတိ, သီလ, ဉာဏ်, သံဝေဂ, ကံ, ရုပ်, စိတ်, အတ္တ, လောက, ဓာတ်,
  ဒုစရိုက်, အတိတ် / အနာဂတ် / ပစ္စုပ္ပန်, ကာမဘုံ, သုတ္တန်, အဘိဓမ္မာ) are everyday Burmese words.
- Group names: gocchaka = «N-တို့၏ အစု» ("cluster of N"): hetu = အမြစ် (root), āsava = စိတ်အစွန်းအထင်း (stains
  of the mind), saṃyojana = နှောင်ကြိုး (binding ropes), gantha = အထုံး (knots), ogha = ရေအလျဉ် (torrents),
  yoga = ထမ်းပိုး (yokes), nīvaraṇa = အတားအဆီး (obstacles), parāmāsa = မှားယွင်းသော ယူဆမှု (wrong
  supposing), upādāna = စွဲလမ်းမှု (clinging), kilesa = ကိလေသာ. Cūḷantara / Mahantara = ကြားညှပ်
  နှစ်မျိုးတွဲ အစုငယ် / အစုကြီး ("the small / large in-between dyad group"); Piṭṭhiduka = နောက်ဆုံး
  နှစ်မျိုးတွဲများ ("the last dyads"); Abhidhammaduka- / Suttantikaduka-mātikā = အဘိဓမ္မာ / သုတ္တန်
  နှစ်မျိုးတွဲ ခေါင်းစဉ်စာရင်း. Mātikā niṭṭhitā = “ခေါင်းစဉ်စာရင်း” ပြီးဆုံးပြီ (title in quotes).
- Dyad patterns (cluster N): X = N ဖြစ်သော; no X = N မဟုတ်သော; sa-X / X-iya = N၏ အာရုံ ဖြစ်နိုင်သော ("can be
  the object of N", the sense of sāsava, saṃyojaniya … parāmaṭṭha, saṃkilesika); a-X-iya = N၏ အာရုံ
  မဖြစ်နိုင်သော; X-sampayutta = Nနှင့် ယှဉ်တွဲသော; X-vippayutta = Nနှင့် ကင်းကွာသော ("separated from");
  «X ceva … Y ca» = «X-လည်း ဖြစ်၊ Y-လည်း …» ("both … and"); «Y ceva … no ca X» = «Y-…သော်လည်း N မဟုတ်»
  ("… but not N"); «X kho pana dhammā Ypi / Y'pi» = «ထို့ပြင် X သဘောတရားများအနက် Y-သည်တို့လည်း။ / Y'-သည်တို့လည်း။»
  ("moreover, among the X phenomena, those that are Y; also those that are Y'").
- Negation rule (one rule book-wide): a free Pāli na / no / neva that negates a whole term = «(…သည်) မဟုတ်»
  ("it is not that …"); a privative a- / an- = «မ» before the verb (မရှိ, မဖြစ်, မမြင်နိုင်). So
  «na kāmāvacarā» = ကာမဘုံနှင့် ဆိုင်သည် မဟုတ်သော, but «anidassanā» = မမြင်နိုင်သော. The double forms keep two
  negations: «neva A na B» = «A-လည်း … မဟုတ်၊ B-လည်း … မဟုတ်သော»; «a-A-a-B» = «A-လည်း မ…၊ B-လည်း မ…သော».
  Exception: «kenaci na viññeyyā» (na inside the term) = …စိတ်ဖြင့် မသိနိုင်သော.
- vedanā = ခံစားမှု (not ဝေဒနာ: in everyday Burmese ဝေဒနာ means pain / illness); sukha = သာယာ, dukkha = နာကျင်
  (not ချမ်းသာ / ဆင်းရဲ, which in everyday speech also mean "rich / poor"); adukkhamasukha = မနာကျင် မသာယာသော.
  The same sukha word in «sukhasahagatā» = သာယာမှုနှင့်အတူ ဖြစ်သော.
- vitakka = စတင်ကြံစည်မှု ("initial thinking"), vicāra = ဆက်လက်သုံးသပ်မှု ("continued examining").
- dassanena = သစ္စာကို မြင်ခြင်းဖြင့် ("by seeing the truth", minor clarification, as in Marathi);
  bhāvanāya = ဘာဝနာ ပွားများခြင်းဖြင့်; pahātabba = ပယ်ရမည့် (negated: ပယ်ရမည် မဟုတ်, avoiding မပယ်ရ, which
  reads as "must not abandon").
- upādiṇṇa = ကံကြောင့် ဖြစ်သော ("produced by kamma"); vipāka = ကံ၏ အကျိုး ဖြစ်သော; vipākadhamma = အကျိုး
  ပေးတတ်သော.
- sekkha / asekkha = ကျင့်ကြံဆဲသူ၏ / ကျင့်ကြံမှု ပြီးဆုံးသူ၏ ("of one still training / whose training is
  complete"); not the Pāli သေက္ခ.
- -ārammaṇa = «X-ကို အာရုံပြုသော» ("taking X as object"); paritta / mahaggata / appamāṇa = အကန့်အသတ် ရှိသော /
  ကြီးမြတ်သော / အတိုင်းအဆ မရှိသော.
- sauttara / anuttara = ထိုထက် သာလွန်သည် ရှိသေးသော / မရှိသော ("there is still / there is nothing higher than
  it"); saraṇa / araṇa = ပဋိပက္ခ ရှိသော / မရှိသော.
- vijjā = အမှန်သိမြင်မှု, avijjā = အမှန်ကို မသိမှု: not ဝိဇ္ဇာ, which in everyday Burmese means an occult adept
  (weikza). ñāṇa = ဉာဏ်.
- nāma / rūpa (suttantika) = စိတ်ပိုင်း / ရုပ်ပိုင်း (not နာမ်, which also means "noun").
- samatha / vipassanā = စိတ်ငြိမ်သက်ခြင်း / ထိုးထွင်းသိမြင်ခြင်း (plain); paggāha = စိတ်ကို မြှင့်တင်ခြင်း,
  kept apart from padhāna = ကြိုးပမ်းအားထုတ်ခြင်း (lesson vīriya vs padhāna).
- hiri / ottappa = ဒုစရိုက်ကို ရှက်မှု / ကြောက်ရွံ့မှု; their negatives with «မ».
- āyatana = အာရုံခံ နယ်ပယ် ("sense domain"); paṭiccasamuppāda = အကြောင်းအကျိုး ဆက်စပ်ဖြစ်ပေါ်ပုံ.
- sassata / uccheda views: the subject အတ္တ ("self") is added as minor clarification (as in Marathi); bhava /
  vibhava views = ဘဝ ဆက်လက် တည်ရှိသည် / ပျောက်ကွယ်သည်ဟူသော အယူ. diṭṭhi = အယူ throughout.
- Suttantika «X ca» pairs: the listing «ca» is not rendered (each line is a plain noun phrase + «။»); «-pi» in
  the cluster closers is rendered «လည်း» (it carries meaning: "also").
- Variant labels: [စာလုံးပေါင်းကွဲ (Sigla): …] for spelling or sandhi only (ṇ / n, ā-sandhi, split
  «nevācayagāmino nāpacayagāmino», paṭisandhāro); [ပါဌ်ကွဲ (Syā.): suttantamātikā] for the different word.
  Several sigla: «(Sī., Syā.)», as in the English and Marathi tracks.
- Typography: every item and colophon ends with «။»; «၊» inside clauses; no dash (the Pāli has none here), no
  «?», no «।», no «:-»; Unicode NFC, code points only U+1000–U+104F.

## Unsure Pāli / for the reviewer
- āsava = စိတ်အစွန်းအထင်း: my coinage for "taints"; the Pāli loan အာသဝေါ is known to religious readers but not
  plain. Please confirm or prefer another.
- ogha = ရေအလျဉ် ("torrent") and gantha = အထုံး ("knot"): plain images; check they read naturally in «…တို့၏ အစု».
- cetasika = စိတ်၏ အဖော် ("companion of mind"): plain, but the reviewer may prefer စေတသိက်.
- kāmāvacara / rūpāvacara / arūpāvacara = ကာမဘုံ / သိမ်မွေ့သော ရုပ်ဘုံ / ရုပ်မရှိသော ဘုံ «နှင့် ဆိုင်သော»;
  the established ရူပဘုံ / အရူပဘုံ were judged less plain.
- upekkhā = ဥပေက္ခာ (kept: known from the four brahmavihāra; the everyday phrase ဥပေက္ခာပြု = "ignore" is a risk).
- saṃvega = သံဝေဂ (kept: the ordinary Burmese word; no plain word carries the sense).
- cittasaṃsaṭṭhasamuṭṭhāna-: read as "mixed with mind and arising from mind" (as in the English / Marathi).
- «khaye ñāṇaṃ» left without "of the defilements" (the Pāli has none).

## Checker notes (for later agents)
- check_sample.py counts a Burmese negation as the syllable «မ» followed by a letter that does not close it
  (asat «်» or stack «္», with an optional «့» before the asat), plus «အကုသိုလ်» = 1 and the abyākata phrase = 1.
  NOT_NEG lists words with a free «မ» that is not a negation (now: ကာမ); add new ones there (e.g. a Pāli loan
  like နမော is safe, ဆုံးမ is not: avoid it or add it).
- Pāli weights: double forms (nevavipāka…, adukkhamasukha …) = 2; abyākata = 1; asekkha, anāgata, apacaya,
  aparanta = 0 (not rendered as negations).
- Numbers: Pāli tika / duka (and number words) against Burmese number + classifier (မျိုး, ပါး, ခု …);
  «တစ်စုံတစ်ခု» (some) and «သူတစ်ပါး» (others) are idioms, not numbers.
