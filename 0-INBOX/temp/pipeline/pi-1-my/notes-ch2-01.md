## Main choices (one-line reasons)
- Frames: «Katamo … tasmiṃ samaye X hoti?» = «ထိုအချိန်၌ ရှိသော X ဟူသည် အဘယ်နည်း။» (plural ရှိကြသော … အဘယ်တို့နည်း);
  «Yo tasmiṃ samaye A B C –» = «ထိုအချိန်၌ ရှိသော A၊ B၊ C –» (the relative is not rendered separately, the Burmese
  attributive carries it); closer «ayaṃ / idaṃ …» = «ဤသည်မှာ ထိုအချိန်၌ ရှိသော X ဖြစ်သည်။»; «X hoti» in the factor
  lists = «X ရှိသည်» («there is X»). Modern literary endings (သည်), no nissaya style.
- Opening: Burmese order puts the six objects first («…ကို အာရုံပြု၍ဖြစ်စေ», «vā» rendered by «ဖြစ်စေ»), then
  the qualifiers, then «ကာမဘုံနှင့် ဆိုင်သော ကုသိုလ်စိတ်သည် … ဖြစ်ပေါ်လာသော အချိန်၌». «သို့မဟုတ်» (or) is avoided
  everywhere: it contains a «မ» syllable that is not a negation. yaṃ yaṃ vā panārabbha = «မည်သည့်အရာကို
  အာရုံပြု၍ဖြစ်စေ» («taking anything at all as object»).
- ye vā pana … aññepi atthi paṭiccasamuppannā arūpino dhammā = «… အခြား သဘောတရားများ ရှိသမျှလည်း» («whatever other
  … there are, too»); paṭiccasamuppanna = «အကြောင်းတို့ကို မှီ၍ ဖြစ်ပေါ်လာသော», arūpino = the sample's «ရုပ် မဟုတ်သော».
- phassa = တွေ့ထိမှု; saññā = မှတ်သိမှု (not သညာ, everyday «sense, consciousness»); cetanā = စေ့ဆော်မှု (not
  စေတနာ, everyday «goodwill»); viññāṇa = သိစိတ် (not ဝိညာဉ်, popular «soul»); mano = မနော (everyday word for mind);
  saṅkhāra = ပြုပြင်ဖန်တီးမှု (one root with the sample's saṅkhatā); khandha = အစုအဝေး (kept apart from the
  sample's gocchaka «အစု»; ခန္ဓာ reads as «body» to plain readers).
- indriya = «X၏ စွမ်းရည်» (faculty), bala = «X၏ စွမ်းအား» (power, as the sample's paṭisaṅkhānabala); ဣန္ဒြေ rejected
  (everyday «composure»). sammā- = မှန်ကန်သော (sammādiṭṭhi = မှန်ကန်သော အယူ; diṭṭhi = အယူ as in the sample).
- Pāli loans kept because they are everyday Burmese: ပီတိ, ဝီရိယ, သမာဓိ, ပညာ, သတိ, ဥပေက္ခာ, လောဘ, ဒေါသ, မောဟ, ဈာန်,
  မဂ်, အာဟာရ, ဓာတ်, ဆန္ဒ, လက္ခဏာ, ရတနာ, ပြာသာဒ်.
- alobha / adosa / amoha = «လောဘ / ဒေါသ / မောဟ မရှိခြင်း»; anabhijjhā = «သူ့ဥစ္စာကို မလိုချင်ခြင်း»; abyāpāda =
  «ဖျက်ဆီးလိုစိတ် မရှိခြင်း» (each privative = one «မ»).
- kāya- (kāyapassaddhi …) = «စိတ်၏ အဖော်တို့» (the mental «body»: the text itself defines it by the feeling,
  perception and formation aggregates; minor clarification, as in Marathi); citta- = «စိတ်».
- vedanā list: sāta = «နှစ်သက်ဖွယ်ကောင်း» (agreeable) kept apart from the locked sukha = «သာယာ»; vedayita =
  «ခံစားရခြင်း» kept apart from vedanā = «ခံစားမှု»; cetasika (adjective) = «စိတ်ပိုင်းဆိုင်ရာ» (the noun stays the
  sample's «စိတ်၏ အဖော်»); cetosamphassaja = «စိတ်၏ တွေ့ထိမှုမှ ဖြစ်ပေါ်သော»; tajjāmanoviññāṇadhātu = «သက်ဆိုင်ရာ
  မနော သိစိတ် ဓာတ်» («the corresponding …»); «neva sātaṃ nāsātaṃ» keeps three negations.
- Synonym endings: -nā / -ā = «…ခြင်း»; -ttaṃ = «…(ထား)သော အဖြစ်»; -bhāvo = «…သော သဘော».
- Numbers: «eko phasso» = «တွေ့ထိမှု တစ်ပါး»; counted groups with ပါး (the ငါးပါးသီလ classifier) throughout;
  pañcaṅgika jhāna / magga = «အင်္ဂါ ငါးပါး ရှိသော ဈာန် / မဂ်».
- Headings: Cittuppādakaṇḍa = «စိတ် ဖြစ်ပေါ်ခြင်း အခန်း» (kaṇḍa = အခန်း); Padabhājanī / Padabhājanīyaṃ = «ပုဒ်အလိုက်
  ခွဲခြမ်း ဖော်ပြချက်»; Koṭṭhāsavāra = «အစုအပိုင်းအလိုက် ဖော်ပြချက်»; Suññatavāra = «ဆိတ်သုဉ်းကြောင်း ဖော်ပြချက်»;
  bhāṇavāra = «ရွတ်ဖတ်ရန် အပိုင်း»; «Paṭhamaṃ cittaṃ» = «ပထမ စိတ်» (ORD of the sample).
- mahākusala = «ကြီးကျယ်သော ကုသိုလ်» (kept apart from the sample's mahaggata = «ကြီးမြတ်သော»).
- sasaṅkhārena = «တိုက်တွန်းမှုဖြင့်» («with prompting»): a different sense from saṅkhāra = formation.
- hiri / ottappa definitions (sentences): «ရှက်ထိုက်သည့်အရာကို ရှက်ခြင်း၊ ယုတ်မာသော အကုသိုလ် သဘောတရားတို့ကို
  ကျူးလွန်ခြင်းကို ရှက်ခြင်း» (samāpatti here = engaging in, committing).
- Variant labels as in the Marathi track: spelling for viriya-, -ppassaddhi, -ujjukatā, ussoḷhi, irīyanā,
  adūsanā adūsitattaṃ, paṭippassa-, thapetvā; different word for sañcetayitattaṃ.

## Unsure Pāli / for the reviewer
- mano = «မနော» and mānasa = «စိတ်နှလုံး», hadaya = «နှလုံးသား», paṇḍara = «ကြည်လင်သောအရာ» (the mind as «clear»):
  the citta list needs ten distinct mind words; please check they read naturally.
- khandha = «အစုအဝေး» instead of the religious loan ခန္ဓာ; indriya = «စွမ်းရည်»; saññā = «မှတ်သိမှု»;
  cetanā = «စေ့ဆော်မှု»: plain choices that a religious reader may want as loans.
- mahākusala = «ကြီးကျယ်သော ကုသိုလ်»: the everyday «မဟာကုသိုလ်» was not used (its «မ» counts as a negation in the
  checker; it could be added to NOT_NEG if the reviewer prefers it).
- «ထိုအချိန်၌ ရှိသော လောဘ မရှိခြင်း» (question / closer of alobha) reads «the absence of greed present at that
  time»: grammatical but heavy; a loan «အလောဘ» would be lighter but not plain.
- Suññatavāra = «ဆိတ်သုဉ်းကြောင်း ဖော်ပြချက်» («exposition of emptiness»): literal; the section lists the factors
  as bare phenomena.
- nikkama / parakkama / uyyāma (vīriya list) are near-synonyms; rendered «ရှေ့သို့ တိုးထွက်ခြင်း / ရဲရင့်စွာ
  ကြိုးစားခြင်း / ထကြွ ကြိုးစားခြင်း» from their roots (out-going, stepping forward, rising up).
